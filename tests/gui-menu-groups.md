# Production GUI menu groups

The hosted Release/Sokol GUI check verifies the canonical top-level menu
groups, the eight Microdrive drive groups and Drive 1 actions, Compatibility
Tools and Peripherals contents, and visible Machine model and speed choices.
It selects 128K and 400% through the GUI and confirms both through the live
Control Port status. The workflow captures the menus for visual inspection and
terminates the application after the check.
