# Production GUI keyboard command actions

The manually dispatched hosted workflow builds and launches the production
Release/Sokol GUI under Xvfb. It activates the keyboard command menu with F1,
navigates with Up/Down, Enter, and Escape, and confirms cancellation, all seven
speed choices, 48K/128K model changes, pause/resume, and reset while paused
through the live Control Port status. The test terminates the application after
the run; its proof pins every driver fixture hash.
