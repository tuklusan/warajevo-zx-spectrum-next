# CR-0221 Implement Interface-1 ROM-Facing Paging

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Represent external Interface-1 ROM presence and validated identity without
  embedding or publishing ROM bytes.
- Distinguish the preserved old and new Interface-1 ROM variants explicitly.
- Expose Interface-1 ROM bytes through the machine address map only while
  `INTERFACE1` owns the networking mode.
- Represent and validate the active Interface-1 ROM page deterministically.
- Restore the normal 48K/128K ROM mapping after leaving `INTERFACE1`.
- Reject missing, malformed, incompatible, or unsupported ROM requests before
  mutating the machine context.
- Keep control-latch behavior, machine-visible Interface-1 registers, and
  Microdrive/ZX Net devices in their ordered follow-on CRs.
- Preserve canonical serialization/hash participation for the ROM identity,
  presence, and active page when those fields are admitted by the state layer.

## Upstream Completeness Gate

Re-read every Interface-1 activation, ROM load, variant-selection, paging, and
snapshot-restore path in the preserved `SPECSIM.ASM`, including `OPTIONE`,
`ZXI1P`, `ZXI1OLD`, `SETZXI1`, `TESTZXI1`, and the ROM file read/seek logic.
Reconcile those findings with `MDRIVE.ASM`, the frozen companion specification,
and architecture sections 24.1, 24.2, 24.4, 25, 29, 36, 39, and 49.1.
Confirm that no DOS handle, host path, or unlicensed ROM bytes enter the core,
and that old/new ROM identity and page mapping are not collapsed into one
undifferentiated flag.

## Upstream Discovery

The preserved implementation loads Interface-1 ROM material externally,
checks presence and variant, copies the selected page into the machine-visible
area, and reports controlled errors when required ROM material is absent. The
current C machine has only the ordinary ROM state and no Interface-1 ROM
identity, page, or mapping boundary. The public ROM provenance policy forbids
adding ROM binaries to tracked project objects.

## Disposition

- Add external-ROM identity/presence/page state and deterministic mapping APIs:
  `IMPLEMENT_NOW`.
- Preserve external-ROM-only and no-publication policy: `IMPLEMENT_NOW`.
- Interface-1 control latch/registers, Microdrive, and ZX Net: `DEFERRED`.
- Snapshot format extensions that require the completed Interface-1 state layer:
  `DEFERRED` to the serialization CR while preserving atomic rejection.
- Architecture #3 routed EAR/MIC behavior: `DEFERRED`.

## Zero-Gap Exit Scan

Before closure, rescan all ROM load/identity helpers, memory-read and bus-map
paths, networking-mode transitions, snapshot validation, serialization/hash
fields, and tests. Verify old/new identities, active-page behavior, disabled
mapping, missing/incompatible ROM atomicity, and absence of tracked ROM bytes.

## Evidence and Exit Gates

- Exact-SHA CODE, DOCUMENTATION, and independent bootstrap reviews pass with
  zero confirmed findings.
- Static repository gates and `git diff --check` pass locally; no local build or
  test is performed.
- Remote Linux, Windows 10/11, Intel Mac, and hosted matrix validation pass.
- A second upstream zero-gap scan is recorded before closure.
