# CR-0171 Preflight: External Windows Tool Discovery and Installer Evidence

Status: CLOSED

## Objective

Make the remote Windows build harness discover valid compiler and linker
installations on the designated tool drive, and provide safe, auditable
installer diagnostics without touching project source or running local builds.

## Functional Inventory

- Discover Visual Studio installations under the configured Windows tool drive.
- Add the matching MSVC library directory to the remote linker environment.
- Report compiler and CRT-library evidence from the remote tool installation.
- Provide parser-validated elevated installer launch and safe stale-temp cleanup.
- Skip cleanup while an installer process is active.
- Keep all project-generated diagnostics under the project-local test-artefacts tree.

## Upstream Discovery

No emulator runtime behavior is changed by this maintenance CR. Inspect the
existing remote harness and workflow rules as the authoritative project
reference before implementation.

## Upstream and Existing-Gate Comparison

This is harness infrastructure rather than migrated emulator behavior. Compare
the implementation with the existing remote-only, parser-first, private-
evidence, and no-local-build workflow gates. No upstream runtime behavior is
changed; retain the CR-0167 and CR-0170 architecture scopes unchanged.

## Disposition

Implement only external tool discovery and installer evidence support. Do not
change compiler selection policy beyond recognizing the designated tool drive,
and do not run builds or tests locally.

## Zero-Gap Exit Scan

Confirm both default-drive and designated-tool-drive discovery, failed and
successful installer states, active-installer cleanup protection, and exact
remote evidence binding. Close only after serialized CODE and DOCUMENTATION
reviews, reachable-lab validation, hosted matrix validation, and clean gates.

## Verification Plan

- Static repository gates and diff inspection locally only.
- Serialized CODE and DOCUMENTATION reviews.
- Parser-first Windows tool verification and installer-state evidence.
- Remote Linux, Windows 11, and Windows 10 smoke validation.
- Hosted platform matrix and exact-run publication gate.
