# CR-0199 Implement AY Register-Select and Data-Write Timing

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Add deterministic 128K AY-3-8912 register-selection state for registers 0 through 15.
- Decode the 128K register-select port `$FFFD` and data port `$BFFD`, including their address aliases.
- Timestamp register-select and data-write events in the canonical master-tick domain.
- Store the written 8-bit value in the selected AY register without host-audio coupling.
- Keep the 48K path and unrelated I/O behavior unchanged.
- Defer tone, noise, envelope, mixer generation, serialization, and PCM integration to ordered CRs.

## Upstream Completeness Gate

Compare the preserved 128K AY state and `$FFFD`/`$BFFD` port paths with the new
device state, bus dispatch, event records, and tests. Confirm that this CR does not
silently implement later AY synthesis or snapshot behavior.

## Upstream Discovery

The preserved reference stores a 16-byte AY register image and the selected register
state as part of 128K machine/snapshot state. The architecture requires all register
changes to be master-timestamped; the current bus layer is the correct dispatch
boundary for the two 128K AY ports.

## Disposition

- AY register selection, data writes, and deterministic event records: `IMPLEMENT_NOW`.
- Tone/noise/envelope/mixer synthesis and state serialization: `DEFERRED`.
- 48K AY behavior: `DEFERRED` because the initial AY target is 128K only.

covered and no synthesis or later-state behavior is silently included.
