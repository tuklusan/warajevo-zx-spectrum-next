# CR-0096 Preflight: Timed Port-FE Border Changes

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Expose the 3-bit Spectrum border color as a deterministic timed ULA event
driven by port-FE writes, preserving every mid-line and cross-line transition
on the canonical master-tick timeline.

## Functional Inventory

- Decode border bits 0-2 from each ULA-selected port-FE write.
- Ignore BRIGHT, MIC, and beeper bits for border color.
- Record the write master tick and resulting logical border color.
- Preserve transitions in order, including repeated writes and same-tick writes.
- Make the current border state queryable without host presentation state.
- Reset border state deterministically and retain it through serialization policy.
- Cover writes during active display, border, blanking, and frame-wrap regions.
- Keep pixel decoding, FLASH, floating bus, screenshots, and GPU presentation
  assigned to later tickets.

## Upstream Completeness Gate

Architecture sections 15.4, 17.2, 18, 36, and 44 require border output to be
derived from timed ULA state rather than one final frame color. Rescan the
preserved port-FE output path, border bit handling, timing trace, raster
coordinates, and same-edge ordering. Every scoped rule must be implemented,
tested, or assigned to a named later task.

## Upstream Discovery

The preserved reference and current port-FE implementation establish the ULA
write boundary and timestamped output state. The missing slice is a canonical
border-only timeline that separates border color from MIC/beeper output while
remaining independent of the host renderer.

## Disposition

Add a bounded deterministic border event history and current-color API to the
core, populated by the existing timed port-FE write path. Use logical 3-bit
values only. Tasks 083-095 retain ownership of floating bus, raster samples,
pixel/color/FLASH semantics, diagnostics, and Phase-4 acceptance.

## Zero-Gap Exit Scan

Before closure, rescan preserved port-FE and border paths, reset/serialization
behavior, exact master-tick recording, same-tick ordering, and later-task
assignments. Confirm no scoped border behavior remains implicit or lost.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux build/test with active-display, mid-line, repeated-write, and
  frame-wrap border fixtures plus the complete pinned corpus.
- Hosted platform smoke across the supported matrix.
- Repeat border event traces across supported hosts and compare canonical
  values, ordering, and serialized state.
