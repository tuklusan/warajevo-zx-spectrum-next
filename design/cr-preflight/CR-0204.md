# CR-0204 Implement AY Tone Generators

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Implement three independent AY tone dividers for channels A, B, and C.
- Derive each 12-bit tone period from the register pairs R0/R1, R2/R3, and R4/R5.
- Treat a zero period as the minimum one AY-clock period.
- Advance tone state from emulated master ticks through a deterministic integer
  clock accumulator, never from host audio callbacks or wall time.
- Toggle each channel output after its selected period and expose period and
  logical output state for later mixer work.
- Reset divider counters, outputs, and clock phase deterministically.
- Preserve 48K isolation and keep noise, envelope, mixer, and serialization
  behavior outside this CR.

## Upstream Completeness Gate

Rescan the preserved AY register-write and sound-generation paths for channel
count, tone-register pairing, 12-bit masking, zero-period behavior, divider
phase, and output transitions. Compare every discovered tone-only behavior with
the new core API; assign noise, envelope, host delivery, and snapshot behavior
to their named later tasks rather than silently importing them.

## Upstream Discovery

The preserved implementation stores three tone periods and advances oscillator
state from emulated sound processing. The portable core already owns the AY
register image and the seven-megahertz integer master-tick domain. This CR uses
the frozen four-master-tick AY-clock quantum as a rational integer accumulator;
the later mixer and audio-sampling CRs consume the resulting logical levels.

## Disposition

- Three tone dividers, period decoding, output toggles, and master-tick phase:
  `IMPLEMENT_NOW`.
- Noise generation: `DEFERRED_WITH_CR` to Task 190.
- Envelope generation and register edge cases: `DEFERRED_WITH_CR` to Task 191.
- AY mixing, PCM, and serialized AY phase: `DEFERRED_WITH_CR` to Tasks 192-193.
- 48K AY behavior and non-base 128K variants: `CONTROLLED_SCOPE`.

## Zero-Gap Exit Scan

Before closure, rescan the upstream oscillator paths, all six tone-period
registers, zero-period handling, divider phase, reset behavior, and the
master-tick relationship. Confirm every tone behavior is implemented and
covered, with no noise, envelope, mixer, or snapshot behavior included.
