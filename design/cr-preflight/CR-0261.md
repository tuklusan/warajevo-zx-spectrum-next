# CR-0261 Add Model-Aware Debugger Memory Pointer and Page Controls

Status: CLOSED

## Functional Inventory

- Expose the debugger’s bounded memory pointer and current page configuration.
- Support certified 48K and 128K profiles through one shared machine boundary.
- Validate page, bank, ROM, and address inputs before any mutation.
- Preserve failure atomicity, pause/access policy, traceability, and the
  one-live-machine rule.
- Keep pointer presentation and command widgets outside the deterministic core.

## Upstream Discovery

- Re-read the complete `MEMPT`, `MEMPAGE`, `MEMSHAD`, `NOSETROM`, and
  `SETMMUEND` routine families in `SPECMON.ASM`.
- Compare pointer, shadow, ROM, bank, and error behavior with the existing
  memory access and 128K paging APIs.
- Re-read Architecture 1 sections 41, 44, and 49.2 and UI Architecture 2
  sections 21 and 45.
- Inventory all current memory/page readers and writers and classify each as
  the single shared boundary or explicitly host/UI-only.

## Disposition

| Surface | Disposition | Reason |
|---|---|---|
| Bounded pointer inspection | IMPLEMENT_NOW | Required monitor workflow |
| 128K page/bank configuration | IMPLEMENT_NOW | Required model-aware control |
| ROM and invalid-page writes | REJECT_ATOMICALLY | Memory safety invariant |
| Existing paging dispatch | PRESERVE_AND_DELEGATE | Single hardware owner |
| UI pointer widgets | UI_BOUNDARY | Presentation is not core state |

## Zero-Gap Exit Scan

Before closure, compare every accepted and rejected pointer/page branch with a
regression case for both profiles, including ROM, range, invalid-page, locked
paging, and read-only failures. Confirm no second page mapping or unchecked
bank access is introduced.

## Required Evidence

- Shared bounded API and focused model-aware pointer/page regressions.
- Updated Phase-11 matrix naming the passing regression.
- Serial CODE, TEST_ARTIFACT, and DOCUMENTATION reviews for the exact commit.
- Remote lab and hosted matrix validation with inspected manifests and private
  closure evidence.
