# CR-0074 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Implement the 48K address map: read-only ROM at `0000-3fff` and writable RAM
  at `4000-ffff`, routed through the machine bus.
- Add explicit machine-owned ROM and RAM storage/access contracts without
  embedding copyrighted ROM bytes.
- Preserve CPU bus tracing and exact access address/value behavior; defer
  contention, ULA visibility, paging, floating bus, and device port behavior.

## Upstream Discovery

Architecture sections 12 and 29 require bus-routed memory and externally
supplied ROM handling. Preserved Warajevo host memory mechanisms are reference
inputs only; their DOS allocation and paging assumptions are not portable
implementation contracts.

## Zero-Gap Exit Scan

Re-scan the bus path, 48K profile, memory accesses, ROM protection boundaries,
and preserved reference memory mapping. Close only when every `0000-ffff`
access has an explicit 48K disposition and later paging/contention behavior is
not silently implemented here.

## Disposition

Implement a machine-owned 16 KiB externally supplied ROM region at
`0000-3fff` and a 48 KiB writable RAM region at `4000-ffff`. Preserve direct
array access exclusively for deterministic fixture/image setup while requiring
all emulated CPU and bus accesses to use the protected machine access path.

## Closure Evidence

Closure status: CLOSED

The CR-0076 fixture-state reconciliation completed the map's validation
boundary without weakening loaded-ROM protection. The final bus-path scan
found every CPU/bus memory access routed through the machine accessors, with
`0000-3fff` protected after a valid external ROM load and `4000-ffff`
writable. Paging, contention, ULA visibility, floating bus, and device ports
remain explicitly deferred.

Linux remote run `CR0076-FIXTURE-ROM-LINUX-R2` passed CTest and all 1,356
pinned Fuse vectors with zero unresolved, unexpected, or silent-skipped cases;
the direct project-owned ROM-map test installs a ROM and proves both read-only
ROM and writable RAM behavior. Hosted repository-gates `33517003481` and
platform-smoke `33517003505` passed on Linux x64/ARM64, Windows x64, and macOS
ARM64/Intel.

DOCUMENTATION review passed without confirmed findings.
