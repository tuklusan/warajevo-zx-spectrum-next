# CR-0160 Preflight: Speed-Invariant Tape Timing

Status: CLOSED

## Objective

Prove and complete the tape timing contract across runtime speed settings.
Emulated tape edges must retain their canonical master-time positions while
host wall-clock playback changes with pacing. This CR extends normal playback
only; it does not add parsers, instant loading, or host audio behavior.

## Functional Inventory

- Keep each tape segment duration measured in canonical master ticks.
- Ensure headless advancement produces the same EAR edge sequence at every
  configured runtime speed.
- Keep runtime speed changes out of the deterministic core and tape state.
- Ensure host pacing may scale wall-clock delay without scaling emulated tape
  durations.
- Preserve motor-off, rewind, end-of-tape, and no-media behavior across speed
  changes.
- Add headless fixtures comparing edge ticks and ULA EAR reads for representative
  speeds, including audible and muted host-speed boundaries.
- Keep tape timing independent of GUI, Sokol, wall clock, and file handles.

## Upstream Completeness Gate

Review the upstream loader, tape position, timing, and runtime-speed paths in
`WARAJEVO.PAS`, `LOADER.ASM`, `SPECCOMP.ASM`, `TSZ80.ASM`, and `Z80_C.ASM`.
Preserve every applicable observable rule: normal loading consumes emulated
waveform time, pulse lengths are not host-speed values, and any accelerated
path remains separate from normal playback. Record any behavior not applicable
to this portable core as a later ordered task rather than silently omitting it.

## Upstream Discovery

CR-0159 established canonical master-time tape advancement and ULA EAR
visibility. The remaining ordered gap is proving that host runtime speed does
not alter those emulated durations while host pacing remains free to scale wall
clock. No additional normal-playback behavior is authorized by this CR.

## Disposition

Implement only speed-independent tape timing tests and the smallest core/API
adjustment required by those tests. Defer TAP/TZX/WAV parsing, SAVE/MIC output,
instant loading, trap detection, and networking ownership.
