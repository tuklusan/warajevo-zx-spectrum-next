# CR-0179: Control Lossy Historical Snapshot State

Status: CLOSED

## Objective

Define a shared representability check for historical snapshot writers. A
legacy SNA or Z80 writer must report a controlled error when active WZSN-only
deterministic state cannot be encoded, rather than silently discarding it.
This CR adds the policy boundary and state predicate only; the ordered legacy
format writer work remains owned by its existing tasks.

## Functional Inventory

- Identify deterministic WZSN state absent from historical SNA/Z80 formats.
- Treat active networking mode as non-representable historical state.
- Treat non-default tape loading mode as non-representable historical state.
- Provide one reusable validation API for future SNA/Z80 writers.
- Return `WZ_RESULT_UNSUPPORTED_OPERATION` without mutating machine state.
- Keep the canonical WZSN serializer lossless and unchanged in behavior.
- Preserve headers, banned-word checks, private artefact rules, and remote-only
  build/test policy.

## Upstream Discovery

The preserved upstream source provides historical snapshot behavior but no
WZSN-native networking mode or canonical state format. Its snapshot fields do
not encode these new deterministic controls; upstream is therefore a source
for legacy field coverage, not a source for this new policy API.

## Upstream and Existing-Gate Comparison

Section 25 requires historical formats to be used only when the selected state
is representable and requires a controlled error when it is not. Section 24.1
and the canonical state contract identify networking mode as deterministic
machine state. The current checkout has no SNA/Z80 writer entry point, so this
CR must establish the shared predicate without creating an unreviewed writer.

## Disposition

- `IMPLEMENT_NOW`: representability enum/API and checks for WZSN-only state.
- `PRESERVE`: canonical WZSN serialization, atomic failure, and legacy field
  ownership by the ordered SNA/Z80 tasks.
- `DEFER`: SNA/Z80 byte layout, compression, paging, and writer integration.

## Zero-Gap Exit Scan

Re-scan Sections 24 and 25, `design/media-format-support.md`, the complete
state model, and all current snapshot entry points. Confirm every currently
known WZSN-only deterministic field is either represented by the historical
format or causes the shared controlled error, and confirm no historical writer
is silently introduced.

## Verification Plan

- Static repository gates and diff checks locally only.
- Exact-SHA CODE and DOCUMENTATION reviews.
- Remote smoke on available approved machines.
- Hosted matrix validation across all configured lanes and publication-gate.
