# CR-0209 Complete 128K SNA Snapshot Load and Save

Status: CLOSED

## Functional Inventory

- Load the existing 128K SNA layout without changing its historical byte format.
- Restore the 128K CPU-visible memory mapping from all eight RAM banks, including
  the three primary SNA pages and the five trailing pages.
- Restore the 7FFD paging latch, selected RAM bank, screen bank, ROM bank, and
  paging lock exactly as represented by the SNA state.
- Restore the SNA CPU registers, interrupt state, border state, and TR-DOS
  indicator according to the implemented machine model and documented scope.
- Restore AY register and deterministic generator state where the SNA format
  carries no such fields by preserving the target machine's reset/default AY
  state; do not invent historical bytes or alter the SNA layout.
- Save a live 128K machine into the exact SNA layout, including all RAM banks,
  paging state, CPU state, and border state, while rejecting unsupported state
  atomically.
- Keep load and save failure atomic: malformed input or an invalid machine must
  not publish partial image or machine state.
- Add deterministic round-trip, bank-isolation, paging-lock, register, malformed
  input, and capacity tests.

## Disposition

- Live 128K SNA load/save integration and exact state tests: `IMPLEMENT_NOW`.
- Historical SNA byte layout changes or invented AY/TR-DOS fields:
  `FORBIDDEN`; retain the existing format contract.
- Full TR-DOS execution semantics, ROM-bank emulation, and unrelated network
  device state: `DEFERRED_WITH_CR` unless already represented by the model.
