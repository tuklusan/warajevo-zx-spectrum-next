# CR-0050 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Keep each external-review request within its fixed input budget.
- Preserve immutable hashes for every reviewed source and requested context.
- Retain exact bounded source evidence centered on the reported location.
- Avoid serializing full resolved context twice in a falsification request.
- Fail closed when bounded evidence cannot establish a verdict.
- Add a remote-runnable regression proving an oversized requested source is bounded.

## Upstream Discovery

Authority: `design/deepseek-review-gate.md` sections Candidate And Proof Pipeline,
Time And Failure Policy, and External Reviewer Adapter.

The reference implementation contains no portable external-review pipeline.
Current project authority requires bounded candidate sharding and forbids silent
truncation. This repair is project-specific infrastructure, not an upstream
behavior migration.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Immutable context identity | IMPLEMENT_NOW | Existing SHA-256 source identity fields |
| Bounded transmitted context | IMPLEMENT_NOW | Review input ceiling and CR-0042 failure telemetry |
| Full source recovery | RETAINED_OUTSIDE_PROMPT | Private telemetry and immutable Git objects |
| Inadequate evidence | FAIL_CLOSED | Existing inconclusive verdict behavior |

## Zero-Gap Exit Scan

A second scan of the normal and bootstrap review paths confirms this scope affects
only normal falsification request construction. Discovery, immutable packet
creation, receipt validation, and bootstrap review remain unchanged.
