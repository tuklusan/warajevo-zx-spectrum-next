# CR-0099 Preflight: Canonical Native Raster Buffer

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Implement a profile-sized, headless native raster/event buffer that stores the
frozen logical sample encoding and can be retrieved without Sokol, GPU, host
window, or presentation dependencies.

## Functional Inventory

- Allocate or bind storage using profile raster dimensions, not hard-coded
  48K dimensions in generic code.
- Provide deterministic initialization, clear, indexed write, and indexed
  read operations with bounds checking.
- Preserve one logical sample per native raster-clock position.
- Reject reserved sample values and invalid coordinates in a controlled way.
- Keep buffer contents independent of host RGB/pixel formats and wall clock.
- Expose complete-frame retrieval for headless tests and later presentation.
- Define ownership/lifetime and failure behavior without hidden global state.
- Keep ULA timing, pixel decoding, FLASH, and host presentation in their
  separate ordered tickets.

## Upstream Completeness Gate

Architecture sections 16.1, 16.2, 16.3, 19, 36, and 51 require a complete
logical native raster independent of presentation. Rescan preserved display
behavior, profile geometry, sample encoding, border/blanking semantics, and
host boundaries. Every scoped buffer behavior must be implemented, tested, or
assigned to a named later task.

## Upstream Discovery

The preserved implementation is a behavioral reference, while the current
core now freezes raster dimensions and logical sample values. The missing slice
is portable storage and access for a complete frame without graphics coupling.

## Disposition

Add an explicit buffer API backed by caller-owned storage, with deterministic
clear/read/write and validation. Tasks 086-095 retain ownership of pixel/color
decoding, FLASH, diagnostics, and Phase-4 acceptance.

## Zero-Gap Exit Scan

Before closure, rescan raster geometry, sample encoding, invalid values,
ownership, complete-frame retrieval, and later-task assignments. Confirm no
host-specific or private-struct dependency remains.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux build/test with complete-frame, bounds, clear, and invalid-value
  fixtures plus the complete pinned corpus.
- Hosted platform smoke across the supported matrix.
- Repeat frame contents and dimensions across supported hosts.
