# CR-0082 Preflight: Frozen 48K Contention Model

Status: CLOSED

## Objective

Implement the evidence-backed 48K PAL contention model in the bus and machine
timing layer, without embedding Spectrum-specific contention decisions in CPU
opcode implementations.

## Functional Inventory

- Identify contended memory addresses and the exact contention delay pattern.
- Identify contended and uncontended I/O phases, including port-FE access.
- Apply delay at the bus request’s correct master-tick position before the
  externally visible operation completes.
- Preserve request address, value, direction, and inserted delay in traces.
- Keep CPU instruction semantics independent of the contention table.
- Make contention profile-defined and deterministic across hosts.
- Reset and serialize all contention-relevant timing state, if any.
- Preserve same-edge ordering among contention, ULA output, interrupts, and
  observer/trace events.
- Reject invalid requests safely without out-of-bounds table access.

## Upstream Completeness Gate

Compare the preserved reference timing logic and all project architecture

are sections 13, 14, 36, 44, and 51 of
`design/warajevo-zx-spectrum-next-architecture.md`, task 068 in
`design/wzsn-architectures-1-2-developer-tasks.md`, and the preserved source
under `reference/original-warajevo/source`.

## Upstream Discovery

Before implementation, scan the reference timing and video routines, project
bus request dispatch, machine profiles, trace records, and current tests.
Record every contention address class, phase, delay, and ordering dependency
here with an exact source location or evidence-table citation.

The authoritative 48K reference states that an even port-FE access is
contended while the ULA supplies its result. It freezes the RAM window at
`0x4000..0x7fff`,
the first contended cycle at T-state `14335`, and the delay pattern at
`6,5,4,3,2,1,0,0`. It also defines I/O patterns from the port high byte and
bit 0: no/low-bit-clear `N:1,C:3`, no/low-bit-set `N:4`, high/low-bit-clear
`C:1,C:3`, and high/low-bit-set `C:1,C:1,C:1,C:1`. These values are recorded
in `design/machine-timing-evidence.md` and sourced to the 48K technical
reference linked there.

The upstream/evidence scan found no legacy Warajevo contention routine to
port; the preserved reference source contains the legacy ULA I/O behavior,
while the authoritative 48K technical reference supplies the timing tables.
All discovered 48K memory and I/O cases are implemented in the bus timing
layer. The 128K-specific contention start and paging rules remain deferred to
the later 128K CR, as required by the disposition.

## Disposition

Implement only the frozen 48K PAL contention behavior discovered in the
authoritative evidence. Defer 128K-specific paging/contention and later raster
fetch refinements to their named CRs. Do not hide unsupported behavior behind
silent skips or host-time heuristics.

## Zero-Gap Exit Scan

After implementation, repeat a line-by-line scan of all discovered upstream
timing paths, evidence tables, changed bus/profile/CPU code, traces, and tests.
Classify every behavior as implemented here, explicitly deferred to a named
later CR, or proven inapplicable. No unclassified behavior permits closure.
