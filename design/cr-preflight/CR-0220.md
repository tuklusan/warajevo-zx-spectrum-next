# CR-0220 Add Networking-Mode Transition Atomicity Tests

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Exercise `NONE` to `INTERFACE1` cold reconfiguration and the return to
  `NONE` on both supported 48K and 128K profiles.
- Exercise idempotent selection of the active mode.
- Exercise rejected `EAR_MIC` activation from both `NONE` and `INTERFACE1`.
- Prove rejected requests preserve the complete observable machine state used
  by this phase, not only the networking-mode enum.
- Keep the test deterministic and independent of host pause/run state.

## Upstream Completeness Gate

Rescan the preserved `SPECSIM.ASM` and `MDRIVE.ASM` transition/activation
paths, plus architecture sections 24.1, 24.6, 36, 39, and 49.1. Confirm that
the tests cover the architecture-required cold transition, reserved-mode
boundary, and atomic failure semantics without asserting future Architecture
#3 router behavior or dirty-media policy that belongs to later tickets.

## Upstream Discovery

CR-0219 added profile, reset, idempotence, and mode checks, but its rejected
`EAR_MIC` assertion checks only the mode after failure. The architecture
requires no partial state mutation, so this CR adds explicit stale-memory and
master-tick preservation checks around rejected requests from both valid modes.

## Disposition

- Add explicit full-state failure-atomicity assertions: `IMPLEMENT_NOW`.
- Preserve the core implementation from CR-0219.
- Dirty media, Interface-1 devices, and Architecture #3 routing: `DEFERRED`.

## Zero-Gap Exit Scan

Before closure, rescan the transition test and all public mode APIs. Verify
both profiles, both valid directions, idempotence, both rejected-mode entry
points, and preservation of observable state on every rejected request.

## Evidence and Exit Gates

- Exact-SHA CODE, DOCUMENTATION, and independent bootstrap reviews pass with
  zero confirmed findings.
- Static repository gates and `git diff --check` pass locally; no local build or
  test is performed.
- Remote Linux, Windows 10/11, Intel Mac, and hosted matrix validation pass.
- A second upstream zero-gap scan is recorded before closure.
