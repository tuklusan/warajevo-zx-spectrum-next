# CR-0290 Remote-safe Recent projection

Status: IN_PROGRESS
Priority: medium
Execution order: architecture_2_phase_12m
Blocking: no

## Functional Inventory

- Preserve the local Recent list and its dynamic host paths.
- Expose the stable `file.recent` group identity to remote discovery.
- Never expose Recent entry paths, counts, or path-bearing arguments through the
  remote projection.
- Keep every local Recent entry bound to `file.open_run`.
- Keep the projection independent of deterministic machine state and remote
  command execution.

## Upstream And Architecture Discovery

- UI Architecture Sections 7.1, 8.2, 35.2, 39.1, and 45.3 require the
  `file.recent` group to remain discoverable while suppressing dynamic host
  paths from remote records.
- The legacy Start workflow provides local filename convenience only; it does
  not create a remotely addressable command for each filename.
- CR-0289 owns local Recent storage. This CR adds only the explicit projection
  boundary for task 287.
- No deterministic core, transport, local/hosted harness, or wrapper changes
  are allowed.
