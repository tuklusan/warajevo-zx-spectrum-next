# CR-0055 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Preserve `SCF` S/Z/PV, clear H/N, and set C.
- Establish undocumented X/Y sourcing across every pinned `0x37` vector.
- Retain ordinary primary instruction fetch timing and PC/R progression.
- Remove only `37_2` from the pinned unresolved baseline when it passes on all
  approved remote platforms.

## Upstream Discovery

The legacy `SCF` handler preserves its existing flag register bits. The pinned
Fuse vector `37_1` confirms that behavior when prior F supplies X/Y; vector
`37_2` has A=`0xff` and F=`0x00`, and expects F=`0x29`. The complete behavior
therefore requires the combined undocumented X/Y source indicated by the full
pinned vector set, not either partial source alone. Re-scan all `0x37` cases
and the adjacent `CCF` handler before implementation.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| SCF documented flags | RETAINED_EXISTING | Legacy handler and existing vectors |
| SCF X/Y combined source | IMPLEMENT_NOW | Fuse `37_1` and `37_2` |
| CCF behavior | RECHECK_ONLY | Adjacent special-flag handler |
| Other primary flag instructions | FOLLOW_ON_CR | Complete-corpus backlog |

## Zero-Gap Exit Scan

Re-scan every pinned `0x37` vector and the legacy dispatch target after the
edit. The CR may close only when `37_1` and `37_2` pass on Linux, Windows 10,
and Windows 11, `37_2` is removed from the unresolved baseline, and no
unexpected complete-corpus failure appears.
