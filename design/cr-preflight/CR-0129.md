# CR-0129 Preflight: Complete 40-Key Spectrum Keyboard Matrix

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Implement the complete deterministic 40-key Spectrum keyboard matrix model
behind the normalized input boundary, preserving authentic eight-row scan
semantics and keeping host key identities outside the core.

## Functional Inventory

- Represent all eight active-low rows with five keys per row.
- Map every normalized Spectrum key to exactly one matrix position.
- Support independent key ownership and simultaneous keys across rows.
- Return the correct active-low result for each selected row during a matrix scan.
- Preserve authentic behavior for multiple selected rows and no selected rows.
- Keep matrix state deterministic and independent of host/UI types.
- Provide direct tests covering every row and every key, including press/release.

## Upstream Completeness Gate

Inspect the preserved upstream keyboard constants, row masks, scan routine,
normalization tables, and existing core keyboard APIs before implementation.
Record every key position, active-low convention, row-selection rule, and
multiple-row behavior; compare the resulting inventory against the architecture
and the existing 48K matrix implementation. No unexplained upstream behavior
may remain outside this CR's disposition.

## Upstream Discovery

The preserved implementation defines eight active-low five-key rows in the
standard Spectrum order: SHIFT/Z/X/C/V, A/S/D/F/G, Q/W/E/R/T, 1/2/3/4/5,
0/9/8/7/6, P/O/I/U/Y, ENTER/L/K/J/H, and SPACE/SYMBOL SHIFT/M/N/B.
The ULA combines every selected row by a bitwise AND, so simultaneous row
selection and unselected-row behavior are retained explicitly.

## Disposition

Extend the core-neutral matrix model and its scan API. Reuse the existing
normalized key boundary and do not add host key codes, UI dependencies, Kempston
state, ghosting policy, or timestamp assignment to this CR.

## Zero-Gap Exit Scan

Close only after every one of the forty keys is represented and scan-tested,
active-low and multi-row semantics are evidenced, upstream comparison finds no
unresolved gap, and remote plus hosted validation passes.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
