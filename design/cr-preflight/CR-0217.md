# CR-0217 Resolve Interface 1 ROM Test and Redistribution Handling

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Keep Interface-1 ROM bytes out of tracked public source, documentation,
  releases, hosted artifacts, and the private test-media publication path.
- Define external user-supplied ROM injection as the only initial runtime path.
- Define explicit old/new Interface-1 ROM identities and byte-length/hash
  validation before activation.
- Make missing, wrong-length, wrong-hash, and incompatible ROM errors
  controlled and atomic.
- Permit tests to use operator-provided ROMs on remote test machines without
  copying them back into this repository.
- Preserve disassemblies as reference-only material with their provenance and
  applicable rights intact.

## Upstream Completeness Gate

Reconcile `SPECSIM.ASM` ROM presence/variant/activation paths (`ZXI1P`,
`ZXI1OLD`, `OPTIONE`, `SETZXI1`, `ZXI1.ROM`) with the core architecture ROM
policy, `NOTICE.md`, `LICENSE.txt`, the ROM-disassembly provenance record, and
the remote/hosted artifact rules. Confirm no test or packaging path embeds or
publishes ROM bytes, and that both old/new variant identities have an explicit
source or deferred status.

## Upstream Discovery

The preserved source expects an external `ZXI1.ROM`, tracks presence and old-ROM
selection separately, and rejects missing ROM input during Interface-1 setup.
The repository contains no Interface-1 ROM binaries; it contains reference
disassemblies only. Existing project policy already excludes firmware bytes
unless redistribution rights are established.

## Disposition

- External operator-supplied ROM loading and identity verification:
  `IMPLEMENT_NOW` in the later device/runtime CR.
- Public repository/runtime distribution of ROM bytes: `PROHIBITED`.
- Reference disassemblies and source provenance: `REFERENCE_ONLY`.
- Old/new ROM byte acquisition and exact hashes: `DEFERRED` until legally
  supplied test fixtures are available; the interface must represent both
  identities without inventing bytes.
- Hosted CI without operator-provided ROMs: controlled skip/unavailable result,
  never a false conformance pass.

## Zero-Gap Exit Scan

Before closure, independently scan the complete preserved ROM activation and
snapshot-restore paths, all repository firmware policy, reference inventories,
remote harness staging, artifact uploads, and package checks. Confirm ROM bytes
cannot enter tracked or hosted public artifacts and every missing/incompatible
input path is deterministic and non-mutating.

## Evidence and Exit Gates

- Exact-SHA CODE, DOCUMENTATION, and independent bootstrap reviews pass with
  zero confirmed findings.
- Static repository gates and `git diff --check` pass locally; no local build or
  test is performed.
- Remote tests prove external-ROM staging and cleanup without publishing bytes.
- Hosted checks prove the no-ROM path is controlled and not claimed as ROM
  conformance.
- A second upstream zero-gap scan is recorded before closure.
