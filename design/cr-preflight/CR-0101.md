# CR-0101 Preflight: INK/PAPER/BRIGHT Interpretation

Status: CLOSED

## Objective

Freeze and expose complete Spectrum attribute interpretation for INK, PAPER,
and BRIGHT, mapping every attribute combination and bitmap state to canonical
logical color indices.

## Functional Inventory

- Decode INK bits 0-2 and PAPER bits 3-5 independently.
- Apply BRIGHT bit 6 to the selected color only.
- Select INK/PAPER from each MSB-first bitmap pixel.
- Cover all 256 attribute bytes and both bitmap states.
- Preserve FLASH bit 7 as input state without applying phase in this ticket.
- Reject invalid pixel positions deterministically.
- Keep logical values independent of host RGB, presentation, and wall time.

## Upstream Completeness Gate

Architecture sections 16.3, 17.1, 17.3, 36, and 51 require complete
attribute semantics before FLASH and raster acceptance. Rescan preserved
attribute/display paths, bit layout, bitmap ordering, BRIGHT behavior, and
host boundaries. Every scoped rule must be implemented, tested, or assigned
to a named later task.

## Upstream Discovery

The preserved reference supplies the legacy attribute representation. The
current core already decodes individual pixels; this ticket expands that
behavior into a complete independently testable attribute contract while
leaving FLASH phase separate.

## Disposition

Add a pure attribute decoder and exhaustive table-driven tests. Keep FLASH
phase, raster materialization, diagnostics, and host palette conversion in
their ordered later tickets.

## Zero-Gap Exit Scan

Before closure, rescan attribute bit layout, all byte combinations, bitmap
selection, BRIGHT expansion, FLASH preservation, invalid inputs, and later
task assignments. Confirm no scoped color interpretation is implicit.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux build/test with exhaustive attribute fixtures and the complete
  pinned corpus.
- Hosted platform smoke across the supported matrix.
- Repeat logical results across supported hosts.
