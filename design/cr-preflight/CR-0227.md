# CR-0227 Deterministic Microdrive Position and Visibility

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Track active motor, mounted cartridge image, sector index, header/data phase,
  byte position, and GAP visibility deterministically.
- Expose bounded read-only visibility of the 15-byte header and 528-byte data
  block without host wall-clock or file access.
- Advance sector position with explicit wrap at the validated cartridge length.
- Reject inactive, unmounted, invalid-sector, and exhausted reads atomically.
- Preserve write, checksum, cache, and flush behavior for later CRs.

## Upstream And Workflow Completeness Gate

The complete upstream `MDRIVE.ASM` status, data, timer, `NEXT`, and `MOTOR`
paths were read and cross-checked with companion-spec sections 6 through 8.
The preserved state includes motor selection, sector, header/data phase, bounded
pointer, GAP state, and validated cartridge length.

## Upstream Discovery

`MOTOR` accepts exactly one selected motor and initializes cartridge length;
`NEXT` wraps the sector at the validated length. `MDV_IN` exposes buffered bytes
only in read mode, while status transitions distinguish GAP from header/data
visibility. This CR implements deterministic read visibility only.

## Disposition

- Portable transport state and sector wrap: `IMPLEMENT_NOW`.
- Header/data bounded visibility: `IMPLEMENT_NOW`.
- GAP/checksum generation, writes, cache, and flush: defer to later CRs.

## Zero-Gap Exit Scan

Re-read the complete scoped upstream paths and verify no motor, sector,
header/data, wrap, inactive-device, or bounded-read behavior is omitted.

## Exit Gates

- Static gates and `git diff --check` pass locally; no local build or test.
- CODE, DOCUMENTATION, and independent bootstrap reviews pass.
- Remote and hosted validation pass with private evidence retained.
