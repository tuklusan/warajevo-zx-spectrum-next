# CR-0239 Malformed MDR and Invalid Device Transition Fuzzing

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Exercise malformed, truncated, undersized, oversized, and non-sector-aligned
  MDR inputs through image validation.
- Exercise invalid Microdrive motor, write-mode, erase-mode, read, write,
  mount, flush, and discard transitions without allowing state corruption.
- Exercise invalid and boundary ZX Net transitions, including collection,
  claim, read, write-bit, and finish-write paths.
- Use deterministic seeded data so every failure is reproducible across the
  four lab boxes and all hosted matrix lanes.
- Assert controlled return codes and bounded post-operation state; no malformed
  input may publish an out-of-range sector, offset, phase, buffer position, or
  buffer length.
