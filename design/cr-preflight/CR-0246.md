# CR-0246 Implement Controlled Register Mutation

Status: CLOSED

## Functional Inventory

- Permit register edits only through the shared debugger facade over the one
  live `wz_machine_t`; never create debugger-owned CPU state.
- Require the explicit paused/safe-state access mode before mutation and reject
  mutation attempts while read-only or running.
- Validate the complete candidate `wz_z80_state_t` before publishing any field,
  preserving atomic failure with no partial register update.
- Support the main and alternate register banks, index registers, counters,
  interrupt state, and halt state already represented by the canonical Z80
  state type.
- Emit deterministic traceability for accepted and rejected mutation requests
  without entering host metadata into canonical machine state.
- Preserve null-argument and invalid-mode result behavior and keep existing
  inspection and memory-read behavior unchanged.

- `src/core/wz_debugger.h`, `src/core/wz_debugger.c`, `src/core/wz_machine.h`,

upstream register mutation and restore routine named above, access-mode
transitions, validation/error boundaries, trace emission, and neighboring
