# CR-0245 Implement Read-Only CPU Register Inspection

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Return the complete main and alternate Z80 register banks, index registers,
  stack/program counters, memory pointer, interrupt state, and halt state.
- Return associated canonical machine context needed by the debugger view
  without creating a second machine state.
- Reject null arguments deterministically and preserve read-only behavior.
- Reuse existing mapped memory boundaries for byte and bounded block inspection;
  reject address-wrap requests rather than silently changing the address.

- Architecture 1 sections 41 and 44.
- UI Architecture 2 section 21.

- Preserved `reference/original-warajevo/source/src/spectrum-kernel/SPECMON.ASM`
  register display and `STOREREG`/`BACKREG` workflows.
- Existing `wz_machine_t`, `wz_z80_state_t`, and memory accessors.
