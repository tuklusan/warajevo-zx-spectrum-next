# CR-0280 Machine And Media Status Panel

Status: IN_PROGRESS
Priority: HIGH
Execution order: ARCHITECTURE_2_PHASE_12D
Blocking: NO

## Functional Inventory

- Add the optional View status-panel toggle through the shared UI command path.
- Present model, emulation speed/audio state, pause/run state, tape state, all
  eight Microdrive states, networking mode, and remote-control state.
- Use live shared state and stable labels without obsolete host trivia or a
  second source of machine truth.
- Preserve machine state and emulated time when opening, closing, or refreshing
  the panel; keep the workflow keyboard-operable.

## Upstream And Architecture Discovery

- UI Architecture Sections 18.2 and 25 define the panel contents and View
  toggle; the legacy reference supplies status concepts but does not define the
  modern semantic panel contract.
- Existing layout state already carries several status fields, while the
  command registry and peripheral state remain the authoritative sources for
  the completed fields.
- No deterministic core, host transport, harness, or wrapper changes are
  permitted; this is a presentation projection only.
