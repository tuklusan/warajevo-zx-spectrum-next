# CR-0107 Preflight: Raster Diagnostic Dumps

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Add deterministic pixel/sample-level diagnostic comparison helpers for failed
raster tests, reporting the first differing sample and corresponding timing
coordinate without changing emulated state.

## Functional Inventory

- Compare canonical raster buffers without host RGB or presentation dependencies.
- Report first differing linear sample index and x/y coordinate.
- Report expected and actual sample values and the associated master-tick context.
- Handle equal buffers, invalid dimensions, null storage, and length mismatch safely.
- Keep diagnostics bounded and side-effect free.

## Upstream Completeness Gate

Rescan the preserved reference raster/video diagnostics, timing tables, and
failure-reporting paths for first-divergence semantics. Any behavior not covered
here must be assigned to a later numbered task before implementation.

## Upstream Discovery

The preserved reference exposes timing/display evidence and diagnostic paths,
but the new core contract must remain independent of presentation and file I/O.
This CR narrows the migration to deterministic first-divergence reporting.

## Disposition

Add a core comparison/result contract with no file I/O and a test-only formatter
or fixture as appropriate. Preserve canonical sample encoding and explicit
coordinate/timing conversion.

## Zero-Gap Exit Scan

Before closure, rescan mismatch ordering, frame boundaries, invalid input,
overflow, sample values, timing context, and state non-mutation. Confirm no
scoped diagnostic rule remains implicit.
