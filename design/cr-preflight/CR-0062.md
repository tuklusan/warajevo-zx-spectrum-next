# CR-0062 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Decode primary opcode `E3` as `EX (SP),HL`, exchanging the two bytes at SP
  with HL while preserving SP, flags, all unrelated registers, and interrupt
  state.
- Read the stack word before either replacement write, then write the original
  register-pair bytes back to the same two stack addresses in documented byte
  order, including 16-bit address wrap at SP plus one.
- Preserve the primary instruction's one opcode fetch, PC/R progression, and
  19 T-state duration without introducing I/O cycles.
- Decode `DD E3` as `EX (SP),IX` and `FD E3` as `EX (SP),IY`; preserve HL for
  those forms, retain prefix fetch accounting, and apply their 23 T-state
  duration.
- Remove exactly `e3`, `dde3`, and `fde3` from the pinned unresolved baseline.
  Replace the existing unsupported-opcode and failing-trace test sentinels that
  currently use E3 with an unrelated unimplemented opcode before asserting the
  new behavior.

## Upstream Discovery

The preserved primary dispatch table maps E3 to `EXMSPHL`; the DD and FD tables
map the same byte to `EXMSPIX` and `EXMSPIY`. `EXMSPHL` reads the stack word,
stores the pre-exchange HL word at SP, and uses a 19 T-state contract. The IX
and IY routines preserve HL around the equivalent exchange and use the
additional prefix timing for 23 T-states. The adjacent `E0` through `EF`
entries independently cover returns, POP, branch, calls, PUSH, arithmetic,
restart, and prefixes.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Primary EX (SP),HL | IMPLEMENT_NOW | Fuse `e3`, upstream `EXMSPHL` |
| DD/FD indexed exchange forms | IMPLEMENT_NOW | Fuse `dde3`/`fde3`, upstream `EXMSPIX`/`EXMSPIY` |
| Stack read/write ordering and wrap | IMPLEMENT_NOW | upstream exchange routine and existing bus abstraction |
| Flags and unrelated register retention | IMPLEMENT_NOW | upstream exchange contract and deterministic regression tests |
| EX DE,HL, POP IX/IY, LD SP,index | FOLLOW_ON_CR | separate baseline entries and opcode families |

## Zero-Gap Exit Scan

Re-scan upstream primary, DD, and FD E3 entries, `EXMSPHL`, `EXMSPIX`, and
`EXMSPIY`, plus the full E0 through EF dispatch family. Close only when all
three pinned cases pass remotely, the baseline contains none of their entries,
the replacement unsupported sentinels remain valid, and no undispositioned
stack-exchange behavior remains.
