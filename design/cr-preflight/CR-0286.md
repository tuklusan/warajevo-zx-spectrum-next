# CR-0286 Open / Run Format-Routing Seam

Status: CLOSED
Priority: HIGH
Execution order: ARCHITECTURE_2_PHASE_12I
Blocking: NO

## Functional Inventory

- Accept one user-selected path through the universal `file.open_run` seam.
- Classify supported TAP, TZX, WAV, SNA, Z80, and MDR paths without requiring
  the user to choose a media category first.
- Treat extension matching case-insensitively and reject empty, extensionless,
  and unsupported paths deterministically.
- Return a route only; do not mutate machine state or perform silent conversion.
- Keep dialog acquisition host-only so the deterministic core remains unaware
  of operating-system dialogs and paths.

## Upstream And Architecture Discovery

- UI Architecture Sections 8.1 and 22 require `file.open_run` as the universal
  entry point and explicit native-routing/conversion boundaries.
- The legacy reference Start workflow accepts one broad selection and routes
  by recognized suffix, including tape, snapshot, and Microdrive families.
- The migration seam deliberately excludes legacy archive extraction and
  format conversion from this ticket; those require their own safety gates.
- No deterministic core, transport, local/hosted harness, or wrapper changes
  are allowed.
