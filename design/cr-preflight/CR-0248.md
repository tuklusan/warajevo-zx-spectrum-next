# CR-0248 Implement Controlled Memory Mutation

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Permit debugger memory writes only through the shared live-machine facade and
  only in the explicit paused mutation access mode.
- Route writes through the canonical machine memory boundary so ROM protection,
  48K/128K mapping, paging, and bus ownership remain authoritative.
- Reject null machines, invalid access mode, and unsafe writes atomically with
  no partial state change.
- Emit deterministic traceability for accepted and rejected write requests.
- Preserve single-byte address semantics without accidental address wrapping;
  block mutation and fill/search remain separate later surfaces.
- Leave inspection, CPU mutation, execution control, and host presentation
  behavior unchanged.
