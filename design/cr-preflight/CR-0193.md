# CR-0193 Freeze 128K PAL Timing and Profile Evidence

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Freeze the 128K PAL line, frame, visible-area, and interrupt timing constants.
- Preserve one profile-driven master-tick architecture rather than duplicating the
  48K timeline implementation.
- Freeze the 128K contention start, repeat period, and contended RAM-bank set.
- Record port `0x7ffd` partial decoding, paging bits, screen selection, ROM select,
  and paging-lock behavior as evidence for later implementation tasks.
- Distinguish base 128K/+2 behavior from +2A/+3 timing and paging variants, which are
  outside the initial 128K PAL profile.
- Record upstream implementation locations and authoritative external evidence.

## Upstream Completeness Gate

Rescan the preserved Warajevo Z80, memory/paging, timing, snapshot, and sound paths for
every 128K profile assumption that affects the Phase-9 implementation. Compare those
findings with the frozen architecture and technical reference; every behavior must be
implemented later or explicitly scoped to a named task/variant disposition.

## Upstream Discovery

The preserved source exposes a distinct 128K execution profile, snapshot paging fields,
and AY state. The technical reference identifies 228 T-states per line, 311 lines per
frame, 63 pre-picture lines, 70,908 T-states per frame, 128K paging through `0x7ffd`,
and contention for RAM banks 1, 3, 5, and 7 with the 14,361/228 timing pattern.

## Disposition

- Base ZX Spectrum 128K PAL/+2 timing and paging evidence: `IMPLEMENT_NOW` as frozen
  profile input for Tasks 184-187.
- AY register/audio behavior: `DEFERRED` to Tasks 188-193.
- +2A/+3 extra paging and altered contention: `CONTROLLED_SCOPE` outside the initial
  base 128K profile, pending a later explicitly named CR.
- Implementation of memory paging, ULA differences, or live 128K state: `DEFERRED` to
  Tasks 184-187 and must not be silently introduced by this evidence CR.

## Zero-Gap Exit Scan

Before closure, rescan the upstream profile/timing/paging references, architecture
sections 9, 12, 15, 20, 25, and 49, and the timing authority. Confirm every initial
128K timing/profile constant and variant boundary has an authority and a mapped later
task, with no unsupported +2A/+3 assumption leaking into the base profile.

## Evidence and Exit Gates

- Exact-SHA DOCUMENTATION review, independent bootstrap review, and any required code review.
- Static repository gates and `git diff --check` locally; no local build or test.
- Remote/hosted validation only if executable or test artifacts are changed.
- Second upstream zero-gap scan completed before closure.
