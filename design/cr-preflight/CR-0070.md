# CR-0070 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Implement every DD/FD `80` through `BF` ALU form whose source is selected
  index high, selected index low, or `(IX/IY+d)`: ADD, ADC, SUB, SBC, AND,
  XOR, OR, and CP.
- Select IXH/IXL for DD and IYH/IYL for FD. Preserve the established primary
  ALU flag rules, including carry input, CP accumulator preservation, and CP
  undocumented X/Y sourcing from the operand.
- For `(IX/IY+d)`, fetch the signed displacement, set MEMPTR to the computed
  address, record the address-calculation internal phase, then read exactly
  one operand byte. Register-byte forms retain the two-M1 8 T-state timing;
  memory forms complete in 19 T states.
- Retain repeated-prefix and ignored-prefix behavior in the shared dispatcher.
  Keep indexed stack-pair operations `DD/FD E1` and `DD/FD E5` outside this
  CR because they are a separate family.

## Upstream Discovery

The DD table routes `84` through `BE` to `ADDAXH`, `ADDAXL`, `ADDAMIX`,
`ADCAXH`, `ADCAXL`, `ADCAMIX`, `SUBXH`, `SUBXL`, `SUBMIX`, `SBCAXH`,
`SBCAXL`, `SBCAMIX`, `ANDXH`, `ANDXL`, `ANDMIX`, `XORXH`, `XORXL`,
`XORMIX`, `ORXH`, `ORXL`, `ORMIX`, `CP_XH`, `CP_XL`, and `CP_MIX`. The FD
table provides the analogous YH/YL and MIY helper entries. The table proof
shows all eight operations and all three operand classes share this exact
boundary; no source-byte substitution is optional merely because a corpus
vector is absent.
