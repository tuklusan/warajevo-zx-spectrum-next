# CR-0103 Preflight: Canonical Spectrum Palette Indices

Status: CLOSED

## Objective

Define the canonical 16-color Spectrum palette as host-independent indices,
without embedding RGB, pixel formats, or presentation-backend assumptions in
the deterministic core.

## Functional Inventory

- Define stable indices for the eight normal and eight bright Spectrum colors.
- Keep palette identity independent of host RGB ordering, channel depth, and
  presentation backend.
- Provide validation for invalid palette indices without undefined behavior.
- Preserve existing attribute decoding and canonical raster encoding contracts.
- Add deterministic table-driven tests covering all palette entries.

## Upstream Completeness Gate

Rescan the preserved reference palette and every current color/attribute path.
Account for normal and bright variants, index ordering, invalid-input behavior,
and the boundary between core color truth and later host RGB presentation. Any
unimplemented upstream behavior must be assigned to a named later task.

## Upstream Discovery

The reference implementation supplies Spectrum color semantics but does not
authorize host-specific RGB storage in the migrated core. Existing raster code
already emits logical color values; this CR freezes their canonical identity.

## Disposition

Add a documented core palette-index contract and pure lookup/validation helpers.
Keep RGB conversion outside the deterministic core for a later presentation
task.

## Zero-Gap Exit Scan

Before closure, rescan every normal/bright color path, attribute decoding,
raster sample encoding, invalid index handling, and host presentation boundary.
Confirm no scoped palette rule remains implicit or host-dependent.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux build/test with exhaustive palette fixtures and complete corpus.
- Hosted platform smoke across the supported matrix.
- Repeat canonical palette values across supported compilers and hosts.
