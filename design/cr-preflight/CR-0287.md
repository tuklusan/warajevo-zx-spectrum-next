# CR-0287 Open / Run Subsystem Dispatch

Status: CLOSED
Priority: HIGH
Execution order: ARCHITECTURE_2_PHASE_12J
Blocking: NO

## Functional Inventory

- Dispatch a selected path through the universal `file.open_run` seam after
  format classification.
- Route tape formats to the tape handler, snapshots to the snapshot handler,
  and MDR to the Microdrive handler.
- Preserve the selected path unchanged for the owning subsystem.
- Reject missing handlers and unsupported formats deterministically without
  invoking any handler or changing machine state in this seam.
- Propagate handler failure without silently converting or falling back.

## Upstream And Architecture Discovery

- UI Architecture Sections 8.1, 20, and 22 require one universal Open / Run
  entry point with native subsystem routing and explicit conversion boundaries.
- The legacy reference Start workflow accepts a broad selection and selects
  tape, snapshot, Microdrive, or conversion behavior from the recognized file
  suffix; the modern seam retains the native-routing behavior without legacy
  archive side effects.
- CR-0286 supplies classification. This CR adds dispatch only and does not
  duplicate tape, snapshot, or Microdrive implementations.
- No deterministic core, transport, local/hosted harness, or wrapper changes
  are allowed.
