# CR-0241 Inventory the Legacy Monitor and Debugger

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Inventory every historical monitor/debugger user workflow and implementation
  routine family before debugger implementation tickets proceed.
- Classify each item as REQUIRED, LATER, REPLACE, or DROP with an architecture
  replacement and regression authority.
- Preserve one live machine implementation and keep host output outside core
  state.
- Reconcile the inventory against both Architecture 1 and UI Architecture 2.

## Authorities

- `design/warajevo-zx-spectrum-next-architecture.md` sections 41, 44, and 49.2.
- `design/warajevo-zx-spectrum-next-ui-architecture.md` section 21.
- `design/wzsn-architectures-1-2-developer-tasks.md` tasks 223-225.
- `reference/original-warajevo/source/src/spectrum-kernel/SPECMON.ASM` in full.
- `design/monitor-debugger-inventory.md`.

## Upstream Discovery

The complete preserved `SPECMON.ASM` source was scanned for its help-table
commands, public monitor entry points, breakpoint/single-step handlers,
register and memory editors, disassembler, screen dump, input editor, and
output boundaries. The resulting command and routine-family mapping is stored
in `design/monitor-debugger-inventory.md`.

## Disposition

| Class | Disposition | Reason |
|---|---|---|
| Monitor workflows required by Architecture 1/2 | REQUIRED | Implement through shared debugger/state APIs |
| Host output and file boundaries | REPLACE | Preserve diagnostic result outside core |
| Historical internals with no user-visible contract | LATER | Reassess during implementation preflight |
| No independently justified workflow | DROP | Must be documented before removal |

## Zero-Gap Exit Scan

Re-read the complete source label scan and help table after inventory edits.
Every user-facing command must be mapped, every helper family must have a
disposition, and no host handle, path, or second machine implementation may
enter the replacement architecture.

## Exit Gates

- Full source/help-table reconciliation has no unmapped routine family.
- Exact-SHA CODE and DOCUMENTATION reviews pass serially.
- The inventory is committed and published before debugger implementation.
