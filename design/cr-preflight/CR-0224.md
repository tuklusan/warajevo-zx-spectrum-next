# CR-0224 Interface 1 Machine-Visible Registers and State

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Preserve the active `INTERFACE1` mode boundary and the low-byte aliases for
  `$E7` data, `$EF` status/control, and `$F7` serial/network data ports.
- Add deterministic Interface 1 machine-visible register state for the `$EF`
  control latch, its previous value, the eight-bit motor shift register, the
  selected-motor validity/result, and timestamped latch transitions.
- Initialize the control latch to `$EE`, matching upstream `MDVINIT`, and use
  the defined reserved-bit policy for bits 5 through 7.
- Implement control-latch writes with the frozen functional bits: COMMS DATA,
  COMMS CLOCK falling-edge shift, R/W', ERASE, and WAIT.
- Keep Microdrive image parsing, sector buffering, motor timing, network state
  transitions, and host media handles out of this CR; those remain later
  implementation tickets.
- Expose deterministic read-only accessors and include the new state in the
  canonical serialization/hash representation.

## Upstream And Workflow Completeness Gate

The complete preserved `MDRIVE.ASM` register declarations and routines
`ZXI1_IN`, `ZXI1_OUT`, `ZXI1_STS`, `ZXI1_CTRL`, and `MDVINIT` were read in
full for this scope. The preserved `SPECSIM.ASM` dispatch table, `OPTIONE`,
`ZXI1P`, and `ZXI1OLD` activation paths were cross-checked against the frozen
companion specification and existing bus dispatch. No upstream register or
edge behavior in this task may be silently omitted; behavior that depends on
later Microdrive or ZX Net state is recorded as a deferred boundary.

## Upstream Discovery

Upstream initializes `ZXI1CTREG` to `$EE`, stores a prior latch value, tests
the WAIT equality boundary, flushes before changed Microdrive functional bits,
stores the new latch, and shifts COMMS DATA into the motor register on a
`1 -> 0` COMMS CLOCK edge. The existing core has no Interface 1 bus branch or
machine-visible latch state, so this CR must add the state boundary without
embedding host I/O or media behavior.

## Disposition

- Control-latch and prior-latch state: `IMPLEMENT_NOW`.
- Motor shift register and deterministic falling-edge transition record:
  `IMPLEMENT_NOW`; motor selection/device behavior remains deferred.
- `$E7`, `$EF`, and `$F7` complete device semantics: deferred to the dedicated
  Microdrive and ZX Net tickets after this state boundary is available.
- Host serial, filesystem, socket, and printer behavior: `DO_NOT_IMPLEMENT`.

## Zero-Gap Exit Scan

Re-read the scoped upstream routines and companion-spec tables after
implementation. Confirm reset value, reserved bits, WAIT boundary, falling
edge behavior, alias masking, timestamp preservation, serialization offsets,
and failure-atomic behavior are all covered by project-owned tests. Confirm
that no later media or host behavior was accidentally pulled into this CR.
