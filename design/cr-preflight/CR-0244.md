# CR-0244 Forward Diagnostic Traces and Logs by UDP Syslog

Status: CLOSED

## Functional Inventory

- Forward project diagnostic traces and logs to the fixed destination
  `sanyalnet-oracle-vps2.duckdns.org:65514` using UDP only.
- Encode forwarded records in the project-approved Unix syslog format with
  deterministic severity/facility mapping and preserved source metadata.
- Define whether forwarding is opt-in, how it is disabled, and how credentials,
  machine state, memory contents, ROM bytes, host paths, and personal data are
  excluded or redacted before transmission.
- Ensure DNS resolution, queueing, retry, backpressure, packet sizing, and
  socket failure are non-blocking and cannot alter canonical machine state or
  stop the emulator.
- Define behavior when the endpoint is unavailable, changes address, or returns
  no response; UDP has no delivery acknowledgement.
- Add remote/hosted validation and retain inspected packet-format evidence
  without exposing private captures in the public repository.

## Upstream Discovery

- Architecture 1 sections 28, 44, 44.3, and 55.15.
- UI Architecture 2 diagnostics, trace, and host-network boundaries.
- `src/core/wz_trace.h`, `src/core/wz_trace.c`, and

## Disposition

| Surface | Disposition | Reason |
|---|---|---|
| UDP syslog transport adapter | OPEN_FOR_DESIGN | New requested behavior |
| Core trace/log generation | PRESERVE_EXISTING_BOUNDARY | Must not enter host transport |
| Canonical machine state and timing | MUST_NOT_CHANGE | Determinism invariant |
| Sensitive payloads and private test evidence | REDACT_OR_EXCLUDE | Privacy and repository rules |
| Endpoint availability and delivery confirmation | EXPLICITLY_BEST_EFFORT | UDP has no acknowledgement |

## Zero-Gap Exit Scan

Before implementation approval, re-read all named architecture, trace, logging,
workflow, and upstream authorities. Confirm every emitted record class has a
severity/facility mapping, redaction rule, packet-size policy, and failure
behavior. Confirm no implementation silently sends data before opt-in or
introduces a second transport path.

## Implementation Record

- Added `src/diagnostics/wz_syslog_udp.*` as the sole UDP transport adapter.
- Trace projection includes only sequence, master tick, and event kind; the
  full binary trace remains a private local diagnostic artifact.
- Application log text is printable-ASCII sanitized and bounded to one packet;
  oversize messages are dropped rather than fragmented or queued.
- The fixed endpoint is resolved once during opt-in host setup. The socket is
  nonblocking on every supported host family, and all send failures are ignored
  by the diagnostic path.
- Added the `wz_syslog_udp` contract test target. Remote and hosted validation
  must still prove wire framing, redaction, disabled behavior, failure
  isolation, and UDP-only delivery.
