## Upstream Discovery
UI Sections 8.4, 34.6, 47, and the frozen equivalence contract require GUI
Screenshot and Telnet SCREENSHOT to share the same raster capture and PNG
encoding path while differing only in host destination policy. Task 298 is the
derived backlog item. The preserved upstream source has no portable GUI/Telnet
pixel-equivalence test; the project-owned screenshot service is the canonical
boundary. No upstream behavior remains undispositioned.

## Disposition
`IMPLEMENT_NOW`: extend the shared screenshot-service regression with two
independently allocated output buffers and equivalent raster inputs, proving
identical PNG bytes and unchanged raster data. Destination/path and GUI chrome
are intentionally absent from the encoder input by architecture.
