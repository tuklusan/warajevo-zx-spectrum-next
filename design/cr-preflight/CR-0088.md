# CR-0088 Preflight: Controlled Unmapped and Unsupported I/O

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Define and implement deterministic, non-crashing behavior for unsupported or
unmapped 48K I/O paths, preserving bus timing, trace visibility, and the
existing ULA port-FE and synthetic-source boundaries.

## Functional Inventory

- Accept every 16-bit I/O address without out-of-bounds indexing or undefined
  behavior.
- Return the defined fallback byte for unmapped reads when no source claims the
  request.
- Make unsupported writes deterministic no-ops while retaining request and
  timing observability.
- Preserve partial ULA port-FE decoding and explicit synthetic data-source
  claiming order.
- Preserve contention adjustment before dispatch and source classification.
- Preserve null callbacks, invalid arguments, reset, and trace behavior.
- Ensure random-port fixture input cannot crash the core.
- Keep model-specific peripherals deferred to named later tasks.

## Upstream Completeness Gate

Architecture section 46 requires controlled behavior for unmapped and
unsupported I/O, with no crashes or undefined behavior under random-port
fuzzing. The preserved Warajevo dispatch paths were scanned for port masking,
ULA selection, peripheral fallthrough, and default input behavior. The WZSN
bus contract already has a total 16-bit request address and fallback read path;
this CR makes the unsupported-write and negative-path contract explicit.

Authorities are architecture sections 12, 15, 36, 44, and 46; task 074;
`design/machine-timing-evidence.md`; CR-0087; and the preserved source under
`reference/original-warajevo/source/`.

## Upstream Discovery

WZSN dispatches I/O reads through ULA port-FE, the timed data source, the
compatibility input callback, or `0xff`, and dispatches writes only to the ULA
port-FE path. The fallback behavior is safe, but the contract and acceptance
coverage do not yet explicitly exercise the full address range and unsupported
write path.

## Disposition

Keep the current total-dispatch implementation, document the fallback/no-op
contract in the bus API, and add deterministic boundary and random-port fixture
coverage. Do not add peripheral decode or model-specific values in this CR.

## Zero-Gap Exit Scan

Before closure, rescan every I/O read/write path, address conversion, ULA
selection, data-source claim, compatibility callback, fallback, contention,
observer, trace, reset, and invalid-request path. Classify every result as
implemented, covered, or explicitly deferred to a named later task.
