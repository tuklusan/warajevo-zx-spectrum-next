# CR-0277 Implement Toolbar Speed Selector State Reflection

Status: APPROVED_FOR_IMPLEMENTATION
Priority: HIGH
Execution order: ARCHITECTURE_2_PHASE_12B
Blocking: NO

## Functional Inventory

- Enumerate exactly 25%, 50%, 100%, 200%, 400%, 800%, and Unlimited.
- Keep the selected value immediately available to the toolbar/status surface.
- Reflect host audio muted state outside 50%-200% while leaving emulated audio
  semantics untouched.
- Reject invalid values without changing UI state.
- Keep speed selection in the application layer; the deterministic machine
  clock and host pacing remain separate.

## Upstream And Architecture Discovery

- Upstream has no equivalent modern toolbar selector; its speed behavior is
  part of the legacy interactive environment and is replaced by the frozen
  modern `machine.speed.set` contract.
- The UI architecture requires the seven values, immediate status/audio
  reflection, and no machine reset or master-tick discontinuity.
- The existing speed policy and host audio policy are the authoritative
  project boundaries; the selector delegates to those policies.
