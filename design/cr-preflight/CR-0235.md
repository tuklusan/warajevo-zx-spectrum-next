# CR-0235 Canonical Interface 1, Microdrive, and ZX Net State

Status: CLOSED

## Functional Inventory

- Extend the endian-explicit native serializer and FNV state hash with every
  deterministic Interface 1, Microdrive, ZX Net, and networking-mode field
  required by the frozen companion specification.
- Preserve the existing canonical field order and version framing while
  adding an explicit, validated extension block; reject malformed, truncated,
  wrong-version, invalid-enum, and inconsistent device state without partial
  mutation.
- Include Interface 1 ROM presence, variant, page, identity, control latch,
  previous latch, motor shift, selected motor, and control-latch tick; ROM
  bytes remain represented by their canonical identity rather than duplicated
  in the native state stream.
- Include all mounted Microdrive slot identities and validated lengths,
  write-protect and dirty state, motor/cartridge position, sector/header/data
  phase, data pointer, GAP/checksum state, and bounded cache contents required
  for exact replay, without serializing host pointers, paths, handles, or
  timestamps.
- Include the complete deterministic ZX Net state, including state, claim and
  block identifiers, bounded buffer, bit/byte positions, counters, and
  canonical timing values; exclude the application transport queue and host
  sockets because they are outside the deterministic core.
- Preserve the single `NONE`/`INTERFACE1`/`EAR_MIC` networking-mode invariant
  and ensure serialized state cannot create simultaneous modes or activate
  unavailable EAR_MIC behavior.
- Ensure hash sensitivity for every newly serialized field and exact
  serialize/deserialize/hash round trips across 48K and 128K profiles.
- Preserve historical SNA/Z80 incompatibility results when active Interface 1
  or other unrepresentable device state cannot be encoded in those formats.
- Add regression coverage for round trips, field sensitivity, malformed input,
  wrong mode/version, truncated extension data, invalid device combinations,
  and no mutation after failed loads.
