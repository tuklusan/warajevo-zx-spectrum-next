# CR-0159 Preflight: Normal Cassette Playback

Status: APPROVED_FOR_IMPLEMENTATION

## Scope

Implement the first machine integration for normal cassette playback. A mounted
in-memory tape must advance on canonical master time, expose its current EAR
level through the ULA port-FE input bit, and remain independent of host wall
clock, GUI, Sokol, and file handles. Normal mode is the default and represents
the emulated Spectrum ROM reading the timed waveform; no loader trap is allowed
in this scope.

## Functional Inventory

- Attach one validated `wz_tape_state_t` to the machine without taking ownership
  of host file handles or introducing host-time dependencies.
- Advance tape state by the exact number of canonical master ticks consumed by
  the headless runner/emulation path.
- Preserve pulse duration across speed settings because speed changes host
  pacing only, not emulated time.
- Return the current tape EAR level on ULA port-FE reads at bit 6 while
  preserving keyboard and floating input semantics already defined by the
  machine profile.
- Keep motor-off state frozen, make rewind deterministic, and keep end-of-tape
  behavior stable.
- Define safe behavior for no mounted tape and invalid machine/tape arguments.
- Add headless synthetic edge fixtures that verify exact transitions at the
  boundary tick and ROM-loader-visible port reads.
- Keep the reserved networking ownership boundary intact; this CR does not
  implement any networking-mode behavior.

## Upstream Completeness Gate

The upstream reference was searched line-by-line for cassette, EAR, loader,
SAVE/LOAD, and tape-state behavior. Relevant material includes the environment
entry points in `WARAJEVO.PAS`, the loader path in `LOADER.ASM`, the compiler
loader/trap paths in `SPECCOMP.ASM`, and the CPU tape paths in `TSZ80.ASM` and
`Z80_C.ASM`. The migration inventory for this CR is:

- preserve timed EAR input as a machine-visible signal;
- preserve normal loader execution as the authenticity baseline;
- preserve deterministic tape position and edge ordering;
- keep accelerated loader paths separate from normal playback;
- do not infer unsupported loader behavior from trap entry points.

The current architecture and CR-0158 state model cover the first four items at
the API boundary. This CR must close the remaining machine integration gap and
must not claim parser, SAVE, trap, or accelerated-loader coverage.

## Upstream Discovery

The upstream search identified the normal loader path, timed EAR input, and
separate accelerated/trap paths described above. No additional applicable
normal-playback behavior was found outside that inventory.

## Disposition

Implement only machine attachment/advancement, ULA EAR read integration, and
synthetic headless tests. Defer TAP/TZX/WAV parsing, SAVE/MIC output, instant
loading, trap detection, and networking ownership to their ordered CRs.
