# CR-0190 Z80 v3 Loading for Frozen Supported Variants

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Classify a Z80 image with a zero base PC and a 54-byte extended header as v3.
- Read and validate the extended PC and all hardware/device fields before publication.
- Accept only the frozen supported plain 48K profile; reject paging, Interface 1,
  AY, and other v3 device state that the current machine cannot represent.
- Parse pages 8, 4, and 5 exactly once with uncompressed 16 KiB or bounded v2-style
  RLE payloads, preserving page boundaries and rejecting malformed input.
- Publish only after complete validation through isolated temporary state.
- Preserve the v2 canonical writer; v3 input must never become the default output form.

## Upstream Completeness Gate

The preserved upstream `SNAPSHOT.PAS` header classifier and 48K loader path must be
rescanned for the 54-byte extension discriminator, extended PC, hardware mode, paging
and device fields, page numbers, declared lengths, and decompression behavior. Every
upstream v3 behavior must be implemented or explicitly rejected under the frozen matrix.

## Upstream Discovery

The upstream classifier reads 30 bytes first, treats a zero base PC as an extended
image, then recognizes an additional-header length of 54 as v3 and reads the complete
86-byte header. Its 48K path consumes length-prefixed pages and maps historical pages
8, 4, and 5 to 0x4000, 0x8000, and 0xc000 respectively. The migration must retain
those boundaries while rejecting unrepresentable hardware and device state.

## Disposition

- Plain 48K v3 input with representable zero device state: `IMPLEMENT_NOW`.
- Extended PC, page ordering, uncompressed pages, and bounded page-local RLE: `IMPLEMENT_NOW`.
- 128K paging, Interface 1, AY state, Timex, MGT, Multiface, and other device state:
  `CONTROLLED_ERROR` pending a later CR.
- v3 writing: `DEFERRED`; v2 remains the canonical initial writer.
- Malformed, duplicate, missing, truncated, overrun, or trailing data: `CONTROLLED_ERROR`.

## Zero-Gap Exit Scan

Before closure, rescan the frozen media matrix, this preflight, the upstream header and
48K page loader, the implementation, and tests. Confirm every v3 header field, page-number
mapping, compression boundary, unsupported-state disposition, and publication rule is
implemented or explicitly rejected with no missing behavior.

## Evidence and Exit Gates

- Exact-SHA CODE review, independent bootstrap review, and documentation review as applicable.
- Static repository gates and `git diff --check` locally; no local build or test.
- Remote Linux, Windows 10, Windows 11, and Intel Mac smoke evidence where available.
- Hosted platform matrix with housekeeping, exact SHA, and publication gates.
- Close only after the second upstream scan reports zero missing v3 behaviors.
