# CR-0111 Preflight: Instruction and Bus Timing Smoke

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Run and strengthen the frozen instruction and bus-cycle timing smoke set before
host/UI expansion, capturing canonical traces for every scoped case.

## Functional Inventory

- Cover instruction boundaries, bus-cycle phases, wait states, and master ticks.
- Capture canonical CPU and bus event traces with deterministic ordering.
- Compare timing behavior against frozen architecture evidence and upstream.
- Require first-divergence evidence for every mismatch.
- Preserve headless core independence from host presentation.

## Upstream Completeness Gate

Rescan preserved reference timing traces and the architecture timing tables
before adding cases. Assign every behavior outside this smoke set to a later task.

## Upstream Discovery

The core already exposes instruction, bus, and timing trace events; this CR binds
the Phase-4A smoke evidence to those contracts without host-specific behavior.

## Disposition

Add only missing deterministic timing fixtures and evidence manifests. Do not
replace reference-derived timing with software-recognition shortcuts.

## Zero-Gap Exit Scan

Before closure, rescan instruction phases, bus cycles, wait states, event order,
master ticks, trace hashing, and first-divergence diagnostics.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux timing smoke and complete corpus.
- Hosted platform smoke across all supported labels.
- Final upstream zero-gap scan and publication evidence.
