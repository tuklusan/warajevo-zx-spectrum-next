# CR-0210 Complete 128K Z80 Snapshot Variant Validation

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Load 128K v2-class Z80 snapshots into the live 128K machine without changing
  the historical byte format.
- Preserve the complete CPU/register/interrupt state represented by the Z80
  header and the 128K hardware-mode paging state.
- Decode all eight 16K RAM pages, including compressed and uncompressed blocks,
  with duplicate, missing, truncated, and overrun pages rejected.
- Validate v2 hardware mode and paging fields against the supported 128K profile;
  reject unsupported machine variants rather than silently approximating them.
- Keep loading atomic: malformed or semantically unsupported input leaves the
  live machine unchanged.
- Preserve AY state only where the Z80 variant carries it and retain the
  canonical reset/default behavior otherwise; do not invent bytes.
- Add deterministic 128K Z80 round-trip, compression, page-order, register,
  hardware-mode, malformed-input, and capacity coverage.

## Upstream Discovery

- Inspect the legacy Z80 header mapping, hardware-mode values, PC encoding,
  page-number mapping, compression sentinel, and AY/paging treatment.
- Compare every discovered behavior with the existing image parser and live
  128K machine model before implementation.
- Record any intentional scope difference, especially unsupported Timex,
  Interface-1, Disciple, or other hardware extensions.

## Disposition

- Supported 128K v2-class live load and exact validation: `IMPLEMENT_NOW`.
- Canonical v2-class save is permitted only for representable supported state;
  lossless failure must be controlled and atomic.
- v1/v3 input compatibility remains parser-backed and must not regress.
- Timex and other hardware extensions: `DEFERRED_WITH_CR`.

## Pre-Implementation Gates

- Enumerate all functional behavior against current parsers, machine state, and
  preserved upstream implementation before editing.
- Perform a second upstream zero-gap scan after implementation covering header
  fields, PC encoding, page mapping, compression, hardware modes, atomicity,
  and all malformed boundaries.
- Require exact-SHA CODE, DOCUMENTATION, and independent bootstrap reviews with
  zero findings before remote execution.
- Use local static gates only; all builds and tests run remotely or hosted.

## Evidence and Exit Gates

- Remote Linux sanitizer, Intel Mac, Windows 10, and Windows 11 validation pass.
- Hosted `platform-smoke` housekeeping, full matrix, and publication pass.
- Closure records exact commit range, review results, remote run IDs, hosted run
  ID, and the second upstream zero-gap result.

## Zero-Gap Exit Scan

- Confirm every scoped Z80 v2 128K behavior is implemented and tested, with
  every deferred hardware extension explicitly recorded.
- Confirm v1/v3 parser behavior remains covered and no malformed input can
  publish partial live state.
