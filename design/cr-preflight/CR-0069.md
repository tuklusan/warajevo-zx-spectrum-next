# CR-0069 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Implement DD/FD `46`, `4E`, `56`, `5E`, `66`, `6E`, and `7E` as signed
  displacement reads into B, C, D, E, H, L, and A respectively.
- Implement DD/FD `70`, `71`, `72`, `73`, `74`, `75`, and `77` as signed
  displacement writes from B, C, D, E, H, L, and A respectively.
- Preserve ordinary H/L selection for the `66`, `6E`, `74`, and `75` forms;
  only CR-0068's non-memory matrix substitutes IXH/IYH and IXL/IYL.
- Preserve flags and unrelated state, set MEMPTR to the calculated indexed
  address, fetch the signed displacement, record the address-calculation
  internal phase and final memory cycle, and complete in 19 T states.

## Upstream Discovery

The DD/FD tables route register destinations to `LDBMIX` through `LDAMIX` and
`LDBMIY` through `LDAMIY`; they route stores to `LDMIXB` through `LDMIXA` and
`LDMIYB` through `LDMIYA`. The `LDHM`/`LDLM` and `LDMIXH`/`LDMIXL` helpers
explicitly retain ordinary H/L behavior. Every helper uses signed indexed
address calculation before one memory access and has no flag effect.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Indexed-memory reads into B/C/D/E/H/L/A | IMPLEMENT_NOW | LDBMIX through LDAMIX helpers |
| Indexed-memory writes from B/C/D/E/H/L/A | IMPLEMENT_NOW | LDMIXB through LDMIXA helpers |
| Ordinary H/L behavior in memory forms | IMPLEMENT_NOW | LDHM/LDLM and LDMIXH/LDMIXL helpers |
| IXH/IYH and IXL/IYL register-only forms | PRESERVE | CR-0068 transfer matrix |
| Indexed ALU forms | FOLLOW_ON_CR | DD/FD ALU table entries |

## Zero-Gap Exit Scan

Re-scan all DD/FD `46`, `4E`, `56`, `5E`, `66`, `6E`, `70` through `75`, and
`77` entries, their read/write helper routines, and adjacent indexed ALU
entries. Close only when every memory-transfer form is remotely validated and
all excluded behavior has an explicit follow-on disposition.
