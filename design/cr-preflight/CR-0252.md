# CR-0252 Implement Host Printer Presentation and Export Boundary

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Consume completed deterministic printer flush events without adding host
  state, handles, paths, clocks, or device availability to the core.
- Preserve mode, event order, byte order, and pixel meaning when projecting
  captured printer data into a host-consumable bitmap payload.
- Provide bounded caller-owned output with explicit capacity errors and no
  hidden allocation, filesystem write, printer-device write, or UI dependency.
- Keep the presentation format portable and deterministic so GUI, tests, and a
  later Printer Manager can choose their own file/UI adapter.
- Preserve the existing upstream disposition: BIOS/LPT/INT 17 output is
  replaced, not emulated as a host requirement.

## Zero-Gap Exit Scan

Before closure, re-read the complete printer inventory, CR-0251 audit, named
architecture sections, and host-output policy. Confirm that every event mode,
byte, ordering rule, capacity failure, and empty-event case is represented.
Confirm that no export function writes a host path or mutates canonical state.
