# CR-0234 Application ZX Net Transport Normalization Boundary

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Keep all future cross-process transport code outside `src/core`.
- Accept only complete bounded 256-byte ZX Net blocks at the application
  boundary.
- Normalize host arrival into an emulated `master_tick` and deterministic
  sequence number before delivery.
- Preserve FIFO ordering for equal ticks and prevent later packets from being
  scheduled before an already normalized packet.
- Dequeue only packets whose normalized tick is due; do not mutate the core or
  perform host I/O from the queue.
- Reject malformed, oversized, or full-queue input without partial mutation.

## Upstream Discovery

The preserved `MDRIVE.ASM` network handlers define the Spectrum-visible
state machine, fixed `BUSYLEN=5`, `FREELEN=5`, `NETDELAY=30`, and a 256-byte
network buffer. They do not define a portable host transport contract. The
architecture therefore requires an application/orchestrator normalization
boundary and forbids host packet timing from directly changing core state.

## Disposition

- Implement a fixed-capacity application queue and normalized-packet contract.
- Keep sockets, files, threads, host clocks, and transport retry policy out of
  this CR and out of `src/core`.
- Deliver packets as ordinary application-scheduled events to a later
  orchestrator integration; the queue itself has no core dependency.

## Zero-Gap Exit Scan

- Re-read the upstream network handlers and verify that no core-visible state,
  timing constant, block bound, or collision behavior is duplicated or altered.
- Inspect every changed source, test, and architecture statement for direct
  host transport or wall-clock mutation of `wz_zxnet_t`.
- Confirm malformed input, queue saturation, equal-tick ordering, late-tick
  clamping, and due-time delivery each have named regression coverage.

## Exit Gates

  or test.
- Exact-SHA CODE, DOCUMENTATION, and independent bootstrap reviews pass.
- Approved Linux, Windows 10, Windows 11, and Intel macOS remote validation
  pass, with private evidence retained under `test-artefacts/`.
- Exact-SHA hosted validation passes all required matrix lanes and publication
