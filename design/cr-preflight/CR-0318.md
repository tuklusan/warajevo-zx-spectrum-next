## Change Request
CR-0318: Implement eight Microdrive slot controls

Status: APPROVED_FOR_IMPLEMENTATION
Priority: medium

## Functional Inventory
- Expose all eight Microdrive slots through stable UI control metadata.
- Provide mount, eject, and set-default semantic command IDs for every slot.
- Keep the compact `MDV 1` toolbar control as a shortcut, without inventing a
  one-drive-only backend or duplicating command semantics.
- Preserve the existing eight-slot mounted state shown by the status panel.
- Route activation through the shared command registry and preserve its
  availability/permission behavior.

## Upstream Discovery
UI §14 requires eight Interface 1 Microdrive slots, each with a semantic
mounted/unmounted state, and defines the command families
`media.microdrive.mount`, `media.microdrive.eject`, and
`media.microdrive.set_default` for slots 1 through 8. UI §15 assigns the full
state to the Microdrive Manager while the toolbar remains a compact MDV 1
control. The existing layout only provides the MDV 1 toolbar entry and status
state; no complete slot-action metadata or dispatch surface exists.

## Disposition
`IMPLEMENT_NOW`: add a deterministic data-driven eight-slot action table and
its registry-dispatch helper, with focused tests for all 24 actions and slot
numbering. No host media I/O or Microdrive backend behavior is introduced by
this presentation-layer CR.

## Zero-Gap Exit Scan

all three stable command families, labels identify the correct slot, the
existing toolbar shortcut remains unchanged, and no action bypasses the shared
registry or claims unsupported backend operations.
