# CR-0098 Preflight: Freeze Canonical Raster Sample Encoding

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Freeze the logical byte-level meaning of each native raster sample before the
canonical raster buffer is implemented, with explicit active-pixel, border,
blanking, and reserved-value semantics independent of host presentation.

## Functional Inventory

- Define the complete initial sample value set and reserved range.
- Distinguish normal/bright active-pixel palette indices from border indices.
- Represent blanking and synchronization without host RGB values.
- Define profile-provided native raster dimensions and row-major indexing.
- Define invalid/reserved-value handling for producers and consumers.
- Keep canonical hashes and serialization independent of host pixel formats.
- Ensure Sokol, screenshots, scaling, shaders, and window chrome remain outside
  the encoding contract.

## Upstream Completeness Gate

Architecture sections 16, 16.3, 17, 19, 36, and 51 require Spectrum-level
logical samples before presentation. Rescan the raster representation, color
semantics, border state, blanking timeline, profile geometry, and host boundary
requirements. Every scoped encoding rule must be documented, tested, or
assigned to a named later task.

## Upstream Discovery

The preserved reference supplies display behavior but not a portable modern
sample contract. The architecture explicitly requires logical palette/border/
blanking values and prohibits host RGB storage. This ticket freezes that
project-owned contract before raster materialization.

## Disposition

Add the standalone encoding specification and machine-readable boundary tests;
do not yet implement the full raster buffer or pixel decoder. Tasks 085-095
retain ownership of raster storage, pixel/color/FLASH behavior, diagnostics,
and Phase-4 acceptance.

## Zero-Gap Exit Scan

Before closure, rescan the architecture’s raster/sample/color/presentation
sections and preserved display behavior. Confirm each scoped value and invalid
state is represented, and no host-format assumption remains.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux build/test of encoding boundary fixtures and complete corpus.
- Hosted platform smoke across the supported matrix.
- Repeat encoding constants and dimensions across supported hosts.
