# CR-0185 SNA 48K Writer

Status: CLOSED

## Functional Inventory

- Emit exactly one standard 48K SNA image of 49,179 bytes.
- Encode all SNA register fields, IFF2, interrupt mode, border, and the 48 KiB
  RAM image in the frozen byte order.
- Encode PC by placing it at `SP-2` and storing the adjusted SNA stack pointer,
  without mutating the live machine.
- Reject non-48K profiles, unrepresentable WZSN-only state, invalid CPU state,
  and stack positions outside the SNA RAM window.
- Reject null or undersized output buffers before publication and leave output
  bytes unchanged on all validation failures.
- Preserve exact canonical headers, private artefact rules, and remote-only
  execution.

## Upstream Discovery

The upstream snapshot save path and SNA header conventions were compared with
the frozen matrix and the new isolated parser. The writer mirrors the standard
48K stack-PC convention while keeping the live machine immutable.

## Disposition

- Standard SNA 48K writer: `IMPLEMENT_NOW`; task 172.
- SNA 128K writer, Z80 writers, and live snapshot commit: `DEFERRED_WITH_CR`.
- Unrepresentable state and invalid stack placement: `CONTROLLED_ERROR`.

## Zero-Gap Exit Scan

The frozen matrix, upstream save/load behavior, machine address window, CPU
validation, and historical representability predicate were rescanned. Every
standard SNA 48K field has a defined encoding or controlled failure, and no
128K or alternate-format behavior is included implicitly.

## Closure Requirements

- Static repository gates pass.
- Exact-SHA CODE and DOCUMENTATION reviews pass.
- Linux and Windows remote smoke prove valid, round-trip, and rejected saves.
