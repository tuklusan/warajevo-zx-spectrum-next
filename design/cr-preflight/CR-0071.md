# CR-0071 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Implement DD `E1` and FD `E1` as POP IX and POP IY, respectively: read the
  low then high stack bytes, increment SP after each read, and replace only
  the selected index register.
- Implement DD `E5` and FD `E5` as PUSH IX and PUSH IY, respectively: retain
  the primary one-T-state internal phase, decrement SP before each write, and
  write high then low bytes.
- Preserve flags, MEMPTR, all non-selected registers, PC and R progression,
  repeated-prefix behavior, and the exact 14 T-state POP / 15 T-state PUSH
  timing including bus order.

## Upstream Discovery

The upstream DD table routes `E1` to `POPIX` and `E5` to `PUSHIX`; the FD
table routes the same entries to `POPIY` and `PUSHIY`. These four entries are
the only cases still retained by the pinned unresolved baseline. The adjacent
DD/FD `E3`, `E9`, and `F9` index-pair operations are already implemented and
must retain their existing behavior.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| POP IX/IY stack reads | IMPLEMENT_NOW | DD/FD table `E1` entries |
| PUSH IX/IY stack writes | IMPLEMENT_NOW | DD/FD table `E5` entries |
| Flags, MEMPTR, prefix progression | IMPLEMENT_NOW | primary stack-cycle contract and DD/FD dispatch |
| EX (SP),IX/IY, JP (IX/IY), LD SP,IX/IY | PRESERVE | closed CR-0062, CR-0065, and existing dispatcher paths |

## Zero-Gap Exit Scan

Re-scan the DD and FD stack-pair dispatch rows, `POPIX`, `POPIY`, `PUSHIX`,
and `PUSHIY`, plus adjacent `E3`, `E9`, and `F9` handlers. Close only when all
four remaining baseline cases have remote and hosted evidence and no adjacent
indexed stack-pair behavior lacks a disposition.
