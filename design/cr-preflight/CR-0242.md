# CR-0242 Inventory the ZX Printer

Status: CLOSED

## Functional Inventory

- Inventory every historical ZX Printer peripheral behavior and host workflow.
- Classify each behavior as REQUIRED, LATER, REPLACE, or DROP with an explicit
  Architecture 1/UI Architecture 2 replacement or boundary.
- Preserve port status, motor, four modes, pixel buffering, row flush, and
  deterministic ordering while keeping host output outside core state.

## Upstream Discovery

- Full scan of `reference/original-warajevo/source/src/spectrum-kernel/ZXPRINT.ASM`.
- Port dispatch in preserved `SPECSIM.ASM` and setup mappings in `SETUP.PAS`.
- Architecture 1 sections 41, 49.2 and UI Architecture 2 sections 16, 21.

## Disposition

| Class | Disposition | Reason |
|---|---|---|
| Port-visible peripheral behavior | REQUIRED | Core compatibility |
| Host LPT/BIOS output | REPLACE | Application export boundary |
| Legacy host print workflow | DROP | UI architecture disposition |
| Unlisted internal helper | LATER | Must be re-audited before closure |
