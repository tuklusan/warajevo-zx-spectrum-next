# CR-0189 Z80 v2 Loading and Canonical 48K Saving

Status: CLOSED

## Functional Inventory

- Parse the exact 30-byte base header and 23-byte extended header.
- Require v2 PC encoding, plain 48K hardware, no Interface 1 paging, no 7FFD state, and no unrepresentable AY state.
- Map all Z80 CPU registers, interrupt state, border, and extended PC into an isolated candidate machine.
- Parse page blocks 8, 4, and 5 exactly once, accepting uncompressed 16 KiB pages and bounded v2 RLE pages.
- Reject truncated blocks, zero-length compressed blocks, invalid page numbers, duplicate or missing pages, overrun runs, and trailing bytes.
- Publish the snapshot only after complete validation; preserve the prior snapshot on failure.
- Add a deterministic canonical writer using v2 headers and uncompressed pages in page order 8, 4, 5.
- Reject non-48K machines and active state excluded by the historical representability predicate without modifying the output buffer.

## Upstream Completeness Gate

The preserved upstream `SNAPSHOT.PAS` loader path was rescanned for v2 header classification,
extended PC handling, page numbering, page lengths, and per-page RLE behavior. The frozen
project matrix in `design/media-format-support.md` is the project contract; unsupported
hardware/device state is a controlled error because the current canonical machine state
cannot represent it without loss. A second zero-gap scan was completed before closure.

## Upstream Discovery

The upstream path classifies a zero base PC as an extended Z80 image, reads the 23-byte
extension, obtains the PC from that extension, and loads each length-prefixed page by its
historical page number. Its decompressor consumes v2 page-local RLE without the v1 terminal
marker; this implementation retains the same page and stream boundaries while rejecting
hardware and device state not representable by the current 48K machine.

## Disposition

- Z80 v2 plain 48K input and page-local RLE: `IMPLEMENT_NOW`.
- Deterministic uncompressed v2 48K writer: `IMPLEMENT_NOW`.
- 128K, Interface 1, AY state, v3 extensions, and live snapshot commit: `DEFERRED_WITH_CR`.
- Malformed or unrepresentable input: `CONTROLLED_ERROR` with no publication.

## Zero-Gap Exit Scan

The second zero-gap scan rescanned the frozen media matrix, this preflight, the upstream
header/page loader and decompressor paths, the implementation, and tests. Every v2 field,
page-number mapping, compression boundary, and error disposition is implemented or
explicitly rejected; no missing v2 behavior was found.
