# CR-0157 Preflight: Freeze Tape Format Matrix

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Freeze the byte-level TAP, Warajevo-native TAP, TZX, and WAV input contract
before tape parser implementation begins.

## Functional Inventory

- Classify every relevant TZX block as supported, metadata-ignored, or
  unsupported with controlled error.
- Define TZX length, target, loop, call, select, and termination validation.
- Define standard TAP identification, block lengths, pulse expansion,
  checksum/truncation errors, and writing.
- Keep Warajevo-native TAP separate from standard TAP.
- Define accepted WAV PCM forms, deterministic threshold/edge conversion, and
  malformed-input behavior.
- Ensure failed parsing publishes no partial tape state.

## Upstream Completeness Gate

Compare preserved upstream tape readers, native TAP handling, TZX timing and
control behavior, and sampled-audio conversion. Every applicable legacy
behavior must be classified before implementation; new deterministic host
boundaries must not erase observable loader behavior.

## Upstream Discovery

The preserved upstream source is the behavioral reference for standard and
native tape loading. The companion matrix records where the portable migration
must preserve behavior and where the architecture intentionally requires a
controlled unsupported result.

## Disposition

Freeze `design/media-format-support.md` as the parser authority. No parser
implementation ticket may proceed until this CR passes its completeness and
documentation gates.

## Zero-Gap Exit Scan

Close only when every TZX ID, TAP variant rule, WAV accepted form, malformed
input path, and state-publication boundary is explicitly disposed.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
