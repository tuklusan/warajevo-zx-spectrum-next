# CR-0051 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Acquire and verify exactly the pinned Fuse source only in private test artifacts.
- Enumerate every vector in `z80/tests/tests.in` exactly once.
- Compare registers, auxiliary state, timing, and memory against `tests.expected`.
- Preserve the selected-family manifests as diagnostic subsets of the complete result.
- Report machine-readable passed, failed, inapplicable, and reviewed-waived counts.
- Permit an inapplicable disposition only when the vector assumption is outside the certified core contract.
- Fail the run for every applicable unsupported, missing, malformed, or mismatched case.

## Upstream Discovery

Authority: architecture section 36.1, task 060, and the pinned Fuse corpus.

The current project adapter selects ED, indexed-CB, CB rotate/shift, stack,
branch, INC/DEC, and HALT subsets. The pinned corpus itself is the external
test authority for full vector enumeration; legacy Warajevo has no equivalent
portable conformance-manifest contract.

coverage. Every input vector must therefore be represented in a single complete
