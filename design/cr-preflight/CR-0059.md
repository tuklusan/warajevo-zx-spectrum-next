# CR-0059 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

Closure status: CLOSED

## Functional Inventory

- Decode primary opcode `D9` as EXX rather than as an unsupported instruction.
- Exchange the complete BC, DE, and HL register pairs with their alternate
  banks, preserving AF and all non-exchanged CPU state.
- Preserve the one M1 fetch, PC/R behavior, and four T-state instruction
  duration; EXX must not add memory or I/O bus cycles.
- Retain ordinary primary behavior when EXX follows DD or FD prefix bytes,
  whose prefix effects do not redefine the D9 operation.
- Remove only the resolved `d9` entry from the pinned unresolved baseline and
  cover the full alternate-bank swap in deterministic and Fuse regression
  evidence.

## Upstream Discovery

The preserved upstream `Z80.ASM` primary, DD, and FD dispatch tables all route
`D9` to `EXX`. Its EXX routine is a four-T-state operation that swaps BC, DE,
and HL with their shadow state. The nearby `D8` through `DF` entries separately
route conditional return, absolute branch, I/O input, call, push, arithmetic,
restart, and prefix behavior; none is part of this CR.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Primary EXX register exchange | IMPLEMENT_NOW | pinned Fuse `d9`, upstream EXX |
| D9 decode classification | IMPLEMENT_NOW | primary/DD/FD upstream dispatch tables |
| Prefix-byte timing and state retention | IMPLEMENT_NOW | existing prefix execution contract |
| DB input, E3, EB, F9, and indexed families | FOLLOW_ON_CR | distinct unresolved baseline entries |

## Zero-Gap Exit Scan

Re-scan upstream primary, DD, and FD dispatch entries for `D9`, plus the full
EXX routine and its surrounding `D8` through `DF` family. Close only when the
complete alternate-bank exchange, timing, fetch-only bus trace, prefix cases,
and pinned corpus accounting pass remotely with no undispositioned EXX behavior.
