# CR-0340: Make review fixture Git object hashes portable on Windows

Status: CLOSED
Priority: high
Blocking: workflow gate

## Change Request
Make the review-gate Git fixture produce deterministic UTF-8/LF text bytes in
its working tree and committed Git objects on every host, without changing
production review behavior or any frozen harness/wrapper.

## Functional Inventory
- Preserve the fixture's ability to create base and head commits.
- Preserve exact byte-hash assertions for mapped source files.
- Disable implicit Git line-ending conversion in fixture repositories.
- Write fixture text as explicit UTF-8 bytes rather than platform text mode.
- Keep production packet, snapshot, transport, and publication behavior unchanged.
- Retain the existing 87-test review-gate regression coverage.

## Upstream Discovery
- The upstream/reference implementation is not authoritative for this
  project-specific review fixture; the relevant behavior is the existing test
  contract in `tests/test_review_gate.py`.
- Hosted run `34341351580` showed the same failure on five Windows lanes:
  `review map HEAD hash mismatch: guard`.
- The same suites completed their remaining tests; Linux and macOS lanes passed.

## Disposition
`IMPLEMENT_NOW`: set `core.autocrlf=false` and write fixture text as explicit
UTF-8 bytes in each temporary Git fixture, then run focused remote and hosted
validation.

## Zero-Gap Exit Scan
Confirm the fixture configuration is applied before every commit, no
production code or frozen harness was changed, and the linked packet test
still compares the committed object hash rather than weakening the assertion.

## Exit Gates
- Static project gates pass.
- Remote reviewer regression passes.
- Focused linked CODE review passes while this CR is active.
- Hosted Windows lanes pass in the next required matrix run.
- Publication gate inspects all lane manifests and evidence successfully.
