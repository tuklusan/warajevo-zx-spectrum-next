# CR-0345 Deterministic Structured-Review Request Sampling

Status: APPROVED_FOR_IMPLEMENTATION
Priority: high
Execution order: WORKFLOW_REVIEW_GATE_BEFORE_PRODUCT_QUEUE
Blocking: YES

## Functional Inventory

- Make structured external-review requests deterministic for the configured NIM reviewer.
- Preserve JSON mode, disabled-thinking discovery, bounded retries, strict schema validation, and fail-closed verdicts.
- Apply the setting to discovery, falsification, adjudication, and documentation requests without changing packet scope or evidence rules.
- Keep the request payload free of credentials and preserve serial review locking and telemetry.

## Upstream Discovery

- NVIDIA's model-specific NIM guidance documents JSON mode through `response_format` and uses deterministic temperature in its structured-output example.
- The current gate already requests JSON mode and validates the returned schema, but omits an explicit temperature setting.
- The observed CR-0344 review failure is repeated schema rejection after parseable API responses; no harness or wrapper defect was found.
- No product behavior or Architecture #3 work is in scope.

## Disposition

`IMPLEMENT_NOW`: add the documented deterministic sampling setting to the shared review request payload and lock it with the existing request-payload regression test. Do not relax schema validation or change review packet contents.

The implementation boundary is `tools/reviewer/review_gate.py`; regression coverage is in `tests/test_review_gate.py`.

## Zero-Gap Exit Scan

Confirm that the setting applies to every structured request path, does not enable hidden reasoning for discovery, does not alter retry or deadline behavior, does not expose secrets, and does not modify frozen harnesses or wrappers.

## Exit Gates

Close only after focused CODE and DOCUMENTATION review, remote reviewer regression, remote/hosted validation where required by the workflow gate, inspected evidence, and publication inspection for the exact published commit. No local build or test is permitted.
