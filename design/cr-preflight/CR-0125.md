# CR-0125 Preflight: Host Presentation Rectangle

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Freeze the default host-visible crop and border presentation rectangle so
screenshots and presentation tests reference stable geometry.

## Functional Inventory

- Define the source raster rectangle exposed to the host.
- Define border inclusion and crop behavior explicitly.
- Keep the rectangle independent from canonical raster generation.
- Preserve deterministic source hashes regardless of presentation choice.

## Upstream Completeness Gate

Compare the architecture presentation geometry, canonical raster dimensions,
existing host upload boundary, and preserved upstream behavior. Record every
crop, border, and screenshot assumption before implementation.

## Upstream Discovery

CR freezes only the host-visible rectangle required by later scaling and tests.

## Disposition

Document and implement a stable default rectangle. Do not add scaling, shaders,
CRT effects, or alter canonical raster samples in this task.

## Zero-Gap Exit Scan

core isolation are explicit and evidenced.
