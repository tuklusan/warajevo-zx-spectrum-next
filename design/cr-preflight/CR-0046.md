# CR-0046 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Give normal external reviews a bounded 20-minute default deadline.
- Preserve explicit per-invocation deadline overrides.
- Preserve fail-closed expiration, lock ownership, immutable packet binding, and remote-test authorization rules.
- Keep the retained bootstrap path on the same default so maintenance and production paths do not diverge.

## Upstream Discovery

Authority: project reviewer workflow. Upstream Warajevo has no external review
harness; this project-local governance behavior is not an upstream migration
surface. The normal and bootstrap commands were scanned for their shared
`DEFAULT_REVIEW_DEADLINE_SECONDS` import and command-line override handling.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Normal review default | IMPLEMENT_NOW | User-approved 20-minute timeout |
| Bootstrap review default | IMPLEMENT_NOW | Shared deadline constant |
| Explicit override and failure behavior | IMPLEMENT_NOW | Existing argparse and deadline controls remain unchanged |

## Zero-Gap Exit Scan

The second scan covered normal, bootstrap, and health-check deadline paths.
Health checks intentionally retain their explicit 60-second default. No
undispositioned behavior remains.
