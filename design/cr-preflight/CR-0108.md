# CR-0108 Preflight: Raster-State Validation

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Add defensive raster-state validation and controlled failure paths for developer
builds, preventing invalid dimensions or sample storage from overrunning buffers.

## Functional Inventory

- Validate raster dimensions and storage capacity before initialization and access.
- Reject null or undersized storage deterministically.
- Reject invalid sample values without mutating the buffer.
- Keep release behavior bounded and diagnostics independent of host presentation.
- Cover corrupted-state and boundary cases without undefined behavior.

## Upstream Completeness Gate

Rescan preserved reference buffer allocation, raster bounds, sample encoding, and
failure paths. Assign every behavior outside this defensive contract to a later task.

## Upstream Discovery

The current raster buffer API already exposes explicit dimensions and storage;
this CR hardens those boundaries while preserving canonical sample semantics.

## Disposition

Implement validation at the core buffer boundary and add deterministic regression
fixtures. Do not add host-specific assertions or hidden recovery behavior.

## Zero-Gap Exit Scan

Before closure, rescan overflow arithmetic, null pointers, capacity, coordinates,
sample validity, mutation ordering, and developer/release behavior.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux build/test with invalid-state fixtures and complete corpus.
- Hosted platform smoke across all supported labels.
- Final upstream zero-gap scan and publication evidence.
