# CR-0254 Complete Phase-11 Monitor, Debugger, and Printer Regression Coverage

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Reconcile every REQUIRED monitor/debugger function in the monitor inventory
  with a deterministic regression case and an existing shared API boundary.
- Reconcile every REQUIRED ZX Printer state, port, mode, flush, and ordering
  behavior in the printer inventory with a deterministic regression case.
- Cover accepted, rejected, boundary, disabled, empty, and failure-isolated
  paths; preserve host-only and explicitly replaced legacy behavior as such.
- Keep regression cases independent of host paths, wall-clock timing, network
  delivery, UI state, and private media contents.

## Upstream Discovery

- Re-read the complete preserved `SPECMON.ASM` and `ZXPRINT.ASM` routines.
- Compare their function-level dispositions with
  `design/monitor-debugger-inventory.md`, `design/zx-printer-inventory.md`,
  and `design/zx-printer-implementation-audit.md`.
- Compare the existing debugger, printer, export, and diagnostics tests; record
  any missing behavior before implementation.
- Record the result in `design/phase-11-regression-coverage-matrix.md` and do
  not close this CR while a required workflow is marked `MISSING`.
- Re-read Architecture 1 sections 41, 44, and 49.1 and UI Architecture 2
  sections 21, 44, and 45.

## Disposition

| Surface | Disposition | Reason |
|---|---|---|
| Required debugger inspection/mutation/breakpoint/step paths | IMPLEMENT_NOW | Phase-11 regression gate |
| Required printer state, port, mode, and flush paths | IMPLEMENT_NOW | Phase-11 regression gate |
| Host UI presentation and dialogs | VERIFY_BOUNDARY_ONLY | UI queue owns presentation |
| BIOS/LPT/INT 17 and host-only DOS behavior | REPLACE_OR_DEFER | Explicit architecture disposition |
| Private difficult-media and hardware captures | PRIVATE_ONLY | Never public test input |

## Zero-Gap Exit Scan

Before closure, every REQUIRED inventory row must name one passing regression
case, or an explicit approved replacement/disposition. A second complete scan
of the preserved routines must find no unclassified required branch, state
transition, error path, or output-order rule.

## Required Evidence

- Tracked coverage matrix mapping each required inventory row to test names.
- Remote build/test evidence on the available lab lanes.
- Hosted matrix evidence with all applicable lanes terminal and successful.
- Serial CODE, TEST_ARTIFACT, and DOCUMENTATION reviews for the exact commit.
- Private closure evidence containing inspected manifests, traces, and visual
  evidence where supported.

## Exit Gates

CR-0254 may close only after the coverage matrix, upstream zero-gap scan,
remote/hosted validation, evidence inspection, serial reviews, and publication
gate all pass.

## Current Audit Result

The coverage matrix identifies covered debugger/printer surfaces and remaining
required monitor workflows without corresponding shared APIs or regressions.
CR-0254 remains `in_progress`; the missing rows require individually owned
follow-up CRs before the Phase-11 gate can close.
