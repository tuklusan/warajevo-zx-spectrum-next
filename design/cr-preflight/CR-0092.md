# CR-0092 Preflight: Close the Phase-3 Gate

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Reconcile the completed Phase-3 bus, I/O, contention, interrupt, trace, and
differential evidence against both architecture documents and the preserved
Warajevo source, then close the Phase-3 gate only if no scoped behavior remains
unimplemented, untested, unclassified, or undocumented.

## Functional Inventory

- Reconcile all Phase-3 CRs and task dispositions against architecture sections
  12 through 15, 22, 36, 39, 44, 49.1, and 51.
- Confirm bus ownership, contention timing, interrupt edges and sampling,
  keyboard/output behavior, trace evidence, and canonical state coverage.
- Record every explicit later-phase exclusion and its owning task.
- Require clean repository, review, remote, hosted, and publication gates.

## Upstream Completeness Gate

Scan the preserved `SPECSIM.ASM` and `Z80.ASM` paths plus the architecture
task ledger. Every scoped behavior must map to implementation and evidence or
to a named deferred task; no silent omission is acceptable.

## Upstream Discovery

The Phase-3 source scan found the legacy simulator ULA/output and timer paths
in `SPECSIM.ASM`, and instruction-level memory, I/O, stack, and interrupt paths
in `Z80.ASM`. CR-0074 through CR-0091 provide the corresponding project-owned
implementation and evidence dispositions. The remaining source behavior is
outside this gate and is named explicitly in the reconciliation artifact.

## Disposition

Use `design/phase-3-reconciliation.md` as the authoritative task-to-evidence
ledger. Close this CR only when every scoped behavior is covered and every
later-phase behavior is assigned to its ordered task; do not mark deferred
raster, floating-bus, host, media, or peripheral work as Phase-3 complete.

## Zero-Gap Exit Scan

Repeat the scan of preserved source paths, architecture sections, task ledger,
closed CR evidence, implementation ownership, and deferred-task assignments.
The exit condition is two successive scans with no new scoped gap.

## Verification Plan

- Local static and cross-document gates only; no local build or test.
- CODE and DOCUMENTATION advisory reviews of the reconciliation.
- Remote and hosted evidence receipts remain bound to the closed Phase-3 CRs.
- Repeat the zero-gap scan after any discrepancy is corrected.

## Reconciliation Artifact

`design/phase-3-reconciliation.md`. Its deferred-scope section prevents
Phase-4 raster/floating-bus work and later host/device work from being counted
