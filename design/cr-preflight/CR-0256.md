# CR-0256 Implement Bounded Debugger Disassembly and Value Formatting

Status: CLOSED

## Functional Inventory

- Provide a read-only bounded disassembly operation over the one live machine
  memory boundary.
- Decode the required Z80 primary, CB, ED, DD, and FD instruction forms used by
  the debugger view, including prefixes and immediate/displacement bytes.
- Return deterministic caller-owned text with explicit capacity and malformed
  or incomplete-input behavior; never execute the decoded instruction.
- Provide deterministic hexadecimal value formatting for 8-bit and 16-bit
  values without locale, host path, wall-clock, or UI dependencies.
- Reject ranges that wrap beyond the 16-bit visible address space.

## Upstream Discovery

- Re-read the complete disassembly and numeric-formatting routine families
  `DISS`, `DISS_*`, `INDREG`, `INDCB`, `OPC`, `BITS`, `RSTN`, `RP`, `TOKEN`,
  `CONVNUM`, `NUM8`, and `NUM16` in `SPECMON.ASM`.
- Compare prefix, operand, displacement, register-pair, bit, reset-vector,
  and fallback behavior with the current core memory APIs.
- Re-read Architecture 1 sections 41, 44, and 49.2 and UI Architecture 2
  sections 21, 26, and 45; presentation must consume the shared service.

## Disposition

| Surface | Disposition | Reason |
|---|---|---|
| Read-only primary/CB/ED/indexed decode | IMPLEMENT_NOW | Required debugger view |
| Deterministic 8/16-bit formatting | IMPLEMENT_NOW | Required debugger value service |
| Instruction execution or state mutation | MUST_NOT_EXIST | Disassembler is observational |
| Host/UI text widgets and styling | DEFERRED_WITH_CR | UI presentation boundary |
| Unbounded source ranges | REJECT | 16-bit visible-memory contract |

## Zero-Gap Exit Scan

Before closure, every named upstream decode family and error/fallback branch
must map to a deterministic API result and regression case. Repeat the complete
source scan and compare all instruction-prefix and operand forms; no unsupported
form may silently acquire an incorrect mnemonic or length.

## Required Evidence

- Tracked decode coverage matrix mapping upstream forms to tests.
- Serial CODE, TEST_ARTIFACT, and DOCUMENTATION reviews for the exact commit.
- Remote lab and hosted matrix build/test evidence with inspected manifests.
- Private closure record retaining traces and visual evidence where supported.
