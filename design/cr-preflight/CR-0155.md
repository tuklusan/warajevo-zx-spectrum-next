# CR-0155 Preflight: Cross-Compiler Mixer Determinism

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Demonstrate that the frozen canonical audio representation, mixer arithmetic,
beeper rendering, and evidence hashes are deterministic across at least two
available compiler and architecture environments.

## Functional Inventory

- Use the same canonical mixer and beeper vectors on each environment.
- Verify fixed-point sample values and saturation are identical.
- Verify PCM and canonical evidence hashes are identical.
- Record compiler, architecture, and complete test totals.
- Keep host device availability separate from core mixer correctness.

## Upstream Completeness Gate

Compare preserved upstream speaker/mixer arithmetic and conversion behavior,
including signedness, clipping, channel combination, and sampling boundaries.
Confirm that every applicable observable behavior is represented by the frozen
WZSN fixed-point contract and its regression vectors.

## Upstream Discovery

The preserved upstream path uses host-oriented audio conversion and has no
portable canonical hash contract. The migration boundary therefore freezes
the deterministic core representation while retaining applicable speaker
levels and transition timing from upstream.

## Disposition

Run the existing canonical mixer, beeper PCM, and hash regressions on the
Linux x64 compiler and Windows x64 compiler currently available in the lab,
then corroborate them with the complete hosted runner matrix.

## Zero-Gap Exit Scan

Close only when all selected environments report identical canonical evidence,
no test is silently skipped, compiler/architecture identity is recorded, and
the upstream arithmetic comparison has no undispositioned gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
