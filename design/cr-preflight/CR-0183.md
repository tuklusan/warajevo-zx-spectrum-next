# CR-0183 Freeze Snapshot Format Matrix

Status: CLOSED

## Functional Inventory

- Freeze exact SNA 48K header, payload length, register order, stack-PC recovery,
  border and interrupt-mode ranges, and atomic publication rules.
- Freeze SNA 128K scaffolding boundaries without inventing missing paging state.
- Freeze Z80 v1, v2, and v3 header classes, page lengths, compression choices,
  PC locations, canonical writer form, and unsupported hardware behavior.
- Define malformed compression, lengths, page identifiers, trailing data, and
  wrong-model inputs as controlled failures.
- Preserve the temporary snapshot object and historical representability gate.

## Upstream Discovery

The upstream `SNAPSHOT.PAS` path was read through header detection, 48K loading,
compressed-stream expansion, register restoration, and page handling. Its
historical Z80 classes are reflected in the frozen matrix, while the current
portable machine model remains the authority for fields introduced after that
implementation.

## Disposition

- Frozen SNA/Z80 byte-level contract: `IMPLEMENT_NOW`.
- SNA 48K loader: `DEFERRED_WITH_CR`; task 171 / CR-0184.
- SNA 128K paging scaffolding: `DEFERRED_WITH_CR`; task 173.
- Z80 loaders and writer: `DEFERRED_WITH_CR`; tasks 174-176.
- Unsupported variants and malformed input: controlled errors, never partial
  state publication.

## Zero-Gap Exit Scan

The architecture snapshot matrix, media summary, upstream loader branches, and
current temporary-state boundary were compared line by line. Every currently
scheduled SNA/Z80 variant has an exact accepted form or an explicit controlled
error disposition; parser implementation remains ordered follow-on work.
