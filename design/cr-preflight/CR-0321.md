## Change Request
CR-0321: Implement Microdrive Manager whole-cartridge workflows

Status: CLOSED
Priority: medium

## Functional Inventory
- Provide stable manager operations for mount/select, eject/unselect, set
  default drive, catalog, format, optimize/reorder sectors, view sector
  allocation, logical rename, write protect, and write unprotect.
- Route every operation through the shared command registry with stable dotted
  IDs, common availability predicates, disabled reasons, result handling, and
  delegated semantic handlers.
- Acquire drive/path/name arguments outside semantic dispatch through explicit
  drive selectors, file dialogs, and text input; never acquire GUI parameters
  inside a handler.
- Require explicit local confirmation for every media-mutating operation and
  classify those operations as MEDIA_DESTRUCTIVE for the initial remote policy.
- Preserve read-only catalog and allocation inspection as REMOTE_SAFE; mounting
  remains HOST_READ because it acquires a host image.
- Keep this UI contract free of media mutation, duplicate mounting, file
  parsing, and deterministic machine-state ownership; those belong to shared
  media/core services.
- Provide stable labels, descriptions, menu grouping, result schema, and
  keyboard/focus metadata for GUI, tests, and future Telnet projection.

## Upstream Discovery
The retained upstream authorities are `reference/original-warajevo/source/src/environment/MICROD.PAS`
and `reference/original-warajevo/source/src/spectrum-kernel/MDRIVE.ASM`.
`MICROD.PAS` exposes cartridge format, rename, read-sector, read-file,
directory, and optimize operations, and requires confirmation before format and
optimize. `MDRIVE.ASM` preserves cartridge presence and write-protection
semantics. UI architecture Sections 14, 15.1-15.5, 24, 39, 45, 47, 48, and
51 define the eight-drive manager boundary, command IDs, permission classes,
confirmation, availability, accessibility, and evidence requirements.
Developer task 316 is the implementation scope; logical-file and advanced
sector operations remain subsequent tasks.

## Disposition
`IMPLEMENT_NOW`: add the complete registry-backed whole-cartridge workflow
metadata contract and regression coverage. Delegate execution to the caller's
shared availability and semantic handler so this UI layer cannot invent a
second Microdrive implementation or mutate deterministic state.
