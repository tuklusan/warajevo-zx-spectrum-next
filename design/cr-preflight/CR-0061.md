# CR-0061 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Decode primary opcode `DB` as IN A,(n) rather than as an unsupported opcode.
- Read the immediate port low byte, form the port address from the pre-read A
  high byte and immediate low byte, and request the value through the existing
  I/O-read bus contract.
- Store the returned byte in A while preserving every flag bit, increment PC
  and R correctly, and retain the documented 11 T-state instruction duration.
- Set MEMPTR to the port address plus one with low-byte wrap, based on the
  pre-read accumulator port high byte.
- Preserve DD/FD prefix retention and timing when a prefix precedes DB; remove
  only `db` through `db_3` from the pinned unresolved baseline.

## Upstream Discovery

The preserved upstream primary, DD, and FD dispatch tables route `DB` to
`INAN`. Its normal and fast paths copy A into the port high byte, load the
immediate byte as the low port byte, perform the input, replace A with the
returned value, advance PC, and state that flags are unaffected. The surrounding
`D8` through `DF` entries dispatch independently to conditional return, EXX,
branch, call, push, arithmetic, restart, and prefix behavior.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Primary IN A,(n) semantics | IMPLEMENT_NOW | Fuse `db` through `db_3`, upstream INAN |
| I/O read bus observation | IMPLEMENT_NOW | existing WZ_BUS_IO_READ contract |
| MEMPTR increment and wrap | IMPLEMENT_NOW | port-address sequencing and paired OUT migration evidence |
| Device-specific port behavior | DEFERRED_TO_OWNER | architecture section 15.4 |
| ED IN r,(C) and other primary gaps | FOLLOW_ON_CR | separately decoded opcode families |

## Zero-Gap Exit Scan

Re-scan INAN and the full primary, DD, and FD `D8` through `DF` dispatch family.
Close only when all four DB cases pass remotely, their baseline entries are
removed, fetch/immediate/I/O-read timing and pre-read-A MEMPTR behavior are
covered, and no undispositioned IN A,(n) behavior remains.
