# CR-0211 Add Deterministic 128K Paging, Interrupt, and Raster Fixtures

Status: CLOSED

## Functional Inventory

- Freeze deterministic fixtures for every supported 128K 7FFD paging bit and
  bank mapping, including fixed banks, selected bank, screen bank, ROM bank,
  and paging lock behavior.
- Verify interrupt timing and frame/raster relationships under the 128K PAL
  profile without duplicating the 48K raster engine.
- Cover paging writes at valid aliases and reject invalid port-address decode
  without state mutation.
- Cover screen-bank and floating-bus/raster-visible behavior at deterministic
  master ticks where the implemented profile exposes it.
- Exercise reset and frame-boundary behavior for paging, interrupt line, and
  raster position.
- Record canonical expected state/timing results so fixtures are independent of
  host clock, GUI, Sokol, or thread scheduling.

## Source Authority

- `design/warajevo-zx-spectrum-next-architecture.md` sections 9, 15, 16, 36,
  38, 40, and 49.1.
- `design/wzsn-architectures-1-2-developer-tasks.md` task 196.

  `src/core/wz_raster.c`, and 128K machine-profile sources.
- Existing 128K paging, interrupt, raster, and SNA/Z80 state tests.
- Preserved upstream `SPECSIM.ASM` plus documented/hardware timing evidence.

## Upstream Discovery

- Inspect legacy 128K paging-port decode, lock semantics, screen-bank mapping,
  interrupt generation, frame geometry, and raster-visible memory behavior.
- Compare each discovered behavior with the current shared raster engine and
  machine-profile timing model.
- Record conflicts and intentional scope boundaries before implementation;
  hardware/reference evidence wins over historical emulator shortcuts.

## Disposition

- Deterministic 128K paging/interrupt/raster fixtures: `IMPLEMENT_NOW`.
- New hardware timing claims without authoritative evidence: `DEFERRED_WITH_CR`.
- Host presentation, Sokol, and GUI behavior: outside this CR.

## Pre-Implementation Gates

- Enumerate every fixture behavior and expected result before editing.
- Perform a second upstream zero-gap scan after implementation covering every
  paging bit, address alias, lock transition, interrupt/frame boundary, raster
  coordinate, and reset condition.
- Require exact-SHA CODE, DOCUMENTATION, and independent bootstrap reviews with
  zero findings before remote execution.
- Use local static gates only; all builds and tests run remotely or hosted.

## Evidence and Exit Gates

- Remote Linux sanitizer, Intel Mac, Windows 10, and Windows 11 validation pass.
- Hosted `platform-smoke` housekeeping, full matrix, and publication pass.
- Closure records exact fixture evidence, commit range, reviews, remote run IDs,
  hosted run ID, and the second upstream zero-gap result.

## Zero-Gap Exit Scan

- Confirm every scoped 128K paging, interrupt, and raster fixture is present,
  deterministic, and exercised by the test runner.
- Confirm unsupported or unevidenced hardware behavior is explicitly deferred,
  not silently omitted or approximated.
