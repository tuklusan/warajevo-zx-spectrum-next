# CR-0047 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Retry a length-truncated, single-candidate falsification request once against
  the same immutable evidence packet.
- Disable hidden reasoning for that retry and constrain it to one compact JSON
  decision.
- Preserve evidence validation, deadline enforcement, lock ownership, telemetry,
  and fail-closed behavior when the compact retry also truncates or fails.
- Keep multi-candidate sharding and all non-falsification paths unchanged.

## Upstream Discovery

Authority: project-local reviewer workflow. The upstream emulator has no
external review harness. The normal gate's length handling, batch splitter,
deadline propagation, receipt authorization, and unit tests were scanned. The
only undispositioned path is a single candidate whose hidden reasoning consumes
the normal output budget before structured output is emitted.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Single-candidate length response | IMPLEMENT_NOW | CR-0045 telemetry recorded an unresolved truncation |
| Compact retry mode | IMPLEMENT_NOW | Same packet, schema, deadline, and one retry only |
| Further truncation or invalid output | PRESERVE | Existing inconclusive fail-closed result |
| Multi-candidate split behavior | PRESERVE | Existing deterministic batch sharding |

## Zero-Gap Exit Scan

The second scan covered normal and compact falsification calls, schema repair,
truncation telemetry, review receipt invalidation, deadline enforcement, and
the retained bootstrap path. The bootstrap path is intentionally unchanged
because it does not perform falsification. No undispositioned behavior remains.
