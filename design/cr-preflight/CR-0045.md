# CR-0045 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Persist an absolute complete Z80 state sufficient to reconstruct a failing instruction.
- Emit compact deltas between absolute synchronization records.
- Preserve canonical master tick and same-tick sequence ordering.
- Decode a wrapped trace from a surviving absolute state without overwritten history.
- Keep the 16 MiB ring capable of retaining eight complete 48K frames.
- Reject incomplete records and preserve observational-only behavior.

## Upstream Discovery

Authority: Architecture section 44.2 and CR-0042 audit. Upstream `Z80.ASM`
state block was scanned for main/alternate registers, IX/IY, PC, stack, I/R,
IFF1/IFF2, IMODE and HSTATE. The legacy implementation has no portable
structured trace format; the required behavior is a portable reimplementation
of its observable CPU state, not source translation.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Complete CPU-state synchronization | IMPLEMENT_NOW | Architecture full register snapshot requirement |
| Compact change records | IMPLEMENT_NOW | Fixed 16 MiB retention requirement |
| Wrap-decodable surviving history | IMPLEMENT_NOW | Periodic absolute synchronization requirement |
| ULA/device state synchronization | DEFERRED_WITH_CR | Device implementation and trace events remain future work |

## Zero-Gap Exit Scan

The second scan covered upstream state variables and the architecture's wrap,
freeze and retention clauses. No CPU-state field required for reconstruction is
undispositioned; device state is explicitly owned by future device trace CRs.

## Validation Correction

Three independent remote runs established that a record tick delta is relative
to its preceding record. Forward recovery now advances from the following
committed record's delta, preserving identical master ticks across a multi-chunk
synchronization snapshot. The regression fixture explicitly checks the first
and last synchronization chunks share their stored tick.

The first sparse-delta matrix exposed a codec boundary omission: delta chunks
must use the synchronization record's complete 64-bit payload path rather than
the ordinary event payload. The codec and fixture now explicitly verify a
delta updates the high-order program-counter field after recovery.

## Compact State Delta Encoding

Each periodic synchronization remains five absolute register chunks at one
master tick. Between those baselines, `CPU_STATE_DELTA` records carry only the
chunks whose packed values changed. A decoder rejects deltas until a complete
absolute snapshot has been assembled, then applies each delta to that baseline
and advances its reconstructed master tick. A wrapped reader can therefore
ignore orphaned deltas before the first surviving absolute snapshot without
inventing state from overwritten history.
