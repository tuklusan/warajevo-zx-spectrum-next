# CR-0075 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Preserve the non-secret HTTP status when a deadline-enforced reviewer
  subprocess receives an HTTP failure response.
- Keep deadline enforcement, retry classification, fail-closed behavior, and
  private credential handling unchanged.
- Do not treat an unavailable reviewer as a successful advisory review.

## Upstream Discovery

This is project-owned review-harness behavior. The active failure was observed
through the existing authenticated health check; it is not inherited emulator
behavior and has no Warajevo source equivalent.

## Zero-Gap Exit Scan

Re-scan parent/worker transport serialization, HTTP and non-HTTP failure
paths, retry classification, telemetry, credential disclosure boundaries, and
the existing review-gate tests. Close only when the parent retains an HTTP
failure's status without exposing response content or credentials.

## Disposition

Serialize only a typed, numeric HTTP status from the child transport process
and reconstruct the corresponding HTTP failure in the parent. Preserve the
existing generic transport classification for all other failures.

## Closure Evidence

Closure status: CANDIDATE
