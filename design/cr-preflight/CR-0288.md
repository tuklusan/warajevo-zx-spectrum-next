# CR-0288 Explicit Open / Run Conversion Boundary

Status: IN_PROGRESS
Priority: HIGH
Execution order: ARCHITECTURE_2_PHASE_12K
Blocking: NO

## Functional Inventory

- Distinguish native Open / Run formats from formats requiring a compatibility
  or preservation conversion.
- Route recognized legacy conversion candidates to an explicit conversion
  handler without changing their path or silently mutating machine state.
- Return a deterministic unavailable result when no conversion tool is wired.
- Treat archives and unknown formats as controlled unsupported results rather
  than guessing or extracting behind the user’s back.
- Preserve existing native tape, snapshot, and Microdrive routing behavior.

## Upstream And Architecture Discovery

- UI Architecture Sections 8.1, 20, and 22 require one Open / Run entry point,
  native routing where implemented, explicit Compatibility Tools for conversion,
  and no silent lossy conversion.
- The legacy reference Start workflow recognizes additional historical suffixes
  and performs conversion or extraction side effects; those behaviors are
  recorded as migration inventory, not copied into the modern universal seam.
- CR-0287 supplies native dispatch. This CR adds only the explicit conversion
  boundary and controlled unsupported outcomes.
- No deterministic core, transport, local/hosted harness, or wrapper changes
  are allowed.
