## Change Request
CR-0325: Implement ZX Printer Manager presentation and export

Status: CLOSED
Priority: medium

## Functional Inventory
- Present captured virtual ZX Printer output through a subordinate Media manager.
- Consume completed `wz_printer_flush_event_t` events and the shared bitmap exporter;
  do not access BIOS, LPT, host printer devices, or duplicate core printer semantics.
- Expose stable manager availability and disabled reasons when no captured output is
  available, while preserving the last accepted capture until explicitly replaced.
- Support explicit bitmap export into a caller-selected host destination through a
  host-side operation; failed or cancelled export must not mutate printer/core state.
- Keep printer mode, status, port behavior, and timing owned by the deterministic
  `wz_printer` peripheral and keep manager state outside canonical machine state.
- Register the manager and export operations through the shared command registry with
  the correct host-read/host-write permissions and no remote destructive behavior.
- Make the manager reachable as `Media > ZX Printer > Printer Manager...` and retain
  `Settings > Peripherals > ZX Printer` as a separate host presentation setting.

presentation/export seam over the existing core event and bitmap-export APIs. Do not
change printer emulation behavior or modify frozen harnesses.
