# CR-0219 Implement Cold Networking-Mode Reconfiguration

Status: CLOSED

## Functional Inventory

- Provide one core operation for changing between `NONE` and `INTERFACE1`.
- Recreate the same machine profile as a fresh context, clearing RAM, CPU,
  paging, ROM-loaded state, timing, input, tape, audio, raster, bus hooks, and
  device state owned by the machine context.
- Preserve the selected networking mode in the new context.
- Make selecting the already-active mode idempotent and non-destructive.
- Reject reserved `EAR_MIC` activation through this operation without changing
  the machine, matching CR-0218 and the Architecture #3 boundary.
- Keep application pause/run state outside the core operation; the operation
  must not invent or mutate host scheduler state.
- Preserve the existing machine profile pointer and return controlled errors
  for invalid machine or mode arguments.
- Do not silently solve dirty Microdrive media; that guard remains task 218.

## Upstream Completeness Gate

Inspect the preserved `SPECSIM.ASM`, `MDRIVE.ASM`, machine initialization and
reset paths, and architecture sections 24.1, 24.6, 26, 36, 39, and 49.1.
Confirm that mode switching is a cold context replacement rather than an
ordinary Spectrum reset or hot device toggle, and that the preserved source's
Interface-1 activation does not justify retaining stale RAM hooks or device
state. Confirm that application pause/run is an orchestrator concern and that
the operation does not include Architecture #3 router behavior.

## Upstream Discovery

The architecture explicitly requires destruction and recreation of the live
machine context using the same profile and newly selected mode. Existing RAM,
resident hooks, paged-ROM state, and device state do not survive. The current
public setter only assigns an enum, so it leaves the required boundary absent.
The current `wz_machine_t` has no application pause/run field, which confirms
that preservation belongs to the host/orchestrator layer rather than this core
API.

## Disposition

- Add a deterministic core cold-reconfiguration operation: `IMPLEMENT_NOW`.
- Keep the existing setter as the non-destructive enum boundary for callers
  that only need state assignment until the orchestrator migration is complete.
- Dirty-media resolution and Interface-1 device implementation: `DEFERRED` to
  tasks 207 onward and task 218's guard.
- EAR/MIC router, resident stack, and physical acceptance: `DEFERRED` to
  Architecture #3.

## Zero-Gap Exit Scan

Before closure, rescan every machine initialization/destruction path, mode
setter/getter, state serializer/deserializer, host/orchestrator call site, and
test. Verify that both 48K and 128K contexts are recreated, same-mode requests
are idempotent, rejected requests are atomic, and no application pause/run bit
is accidentally discarded or invented in the core.
