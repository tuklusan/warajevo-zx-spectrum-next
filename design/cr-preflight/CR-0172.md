# CR-0172: Explicit Tape Loading Mode State

Status: CLOSED

## Objective

Represent the architecture's explicit cassette loading-mode choice in the core
machine state. Normal loading is the deterministic default. This change adds
the state boundary only; it does not execute instant loading or trap behavior.

## Functional Inventory

- Provide a machine-owned loading-mode value.
- Define Normal and Instant/Trap values with stable numeric representation.
- Initialize and destroy machines in Normal mode.
- Validate mode changes without mutating state on invalid input.
- Preserve the mode in canonical machine serialization and hashing.
- Reject invalid serialized mode values atomically.
- Leave eligibility, accelerated transfer, fallback, and equivalence behavior to
  the later architecture tickets.

## Upstream Discovery

The preserved reference implementation was inspected before implementation.
`reference/original-warajevo/source/src/spectrum-kernel/TAPE.ASM` documents
`LOAD_MODE` and its historical mode transitions. The architecture documents
translate that legacy behavior into an explicit WZSN Normal versus
Instant/Trap selection, with Normal as the authenticity baseline and default.
The reference code does not provide the new C machine-state API or the WZSN
canonical state format, so those are new project material rather than a hidden
port of legacy implementation details.

## Disposition

Implemented here:

- `wz_tape_loading_mode_t` with Normal and Instant/Trap values.
- Machine setter/getter and deterministic initialization.
- State serialization version 10 with the mode in the fixed header.
- Invalid-input and state-round-trip regression coverage.

Deferred by design:

- Positive trap eligibility and loader recognition: Task 157.
- Instant-load machine mutation and safe fallback: Task 158.
- Normal/Instant equivalence regressions: Tasks 159 and 166.
- UI selector and visible default: Task 303.

## Zero-Gap Exit Scan

The upstream scan was repeated after the implementation. No upstream behavior
was omitted from this ticket's stated boundary: the legacy mode evidence is
recorded, Normal is the default, and no instant path is enabled implicitly.
The deferred behaviors remain explicitly represented in the ordered backlog.
