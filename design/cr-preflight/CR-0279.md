# CR-0279 Fullscreen Host Presentation Boundary

Status: IN_PROGRESS
Priority: HIGH
Execution order: ARCHITECTURE_2_PHASE_12C
Blocking: NO

## Functional Inventory

- Provide the View > Fullscreen action through the shared application command path.
- Entering and leaving fullscreen changes host presentation only.
- Preserve canonical machine state, emulated time, raster state, media state,
  and command availability across the presentation transition.
- Keep the action keyboard-operable and expose deterministic success, cancel,
  and host-error outcomes.

## Upstream And Architecture Discovery

- The UI architecture Section 18.1 and acceptance items 44 and 57 are the
  controlling modern contract; the legacy reference has host-window behavior,
  not a portable semantic fullscreen boundary.
- Existing host presentation/scaling files provide the integration seam;
  existing layout data provides the stable `view.fullscreen` command identity.
- The implementation must not change deterministic core state, media behavior,
  Telnet semantics, or any frozen harness/wrapper.

inspection pass. No local build or test is permitted.
