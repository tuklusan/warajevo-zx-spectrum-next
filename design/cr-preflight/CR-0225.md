# CR-0225 Microdrive Cartridge Image Parsing and Validation

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Define a portable read-only MDR image view with explicit byte length and
  validated sector count.
- Require every image length to be an exact multiple of 543 bytes.
- Accept only 9 through 254 complete sectors, matching the preserved
  `MDVINIT` bounds.
- Expose safe sector addressing without copying image bytes or exposing host
  file handles, paths, timestamps, or ownership state to the core.
- Return controlled parse/argument errors for null, short, long, partial, and
  overflow-prone inputs without mutating a previously valid image view.
- Keep sector checksum interpretation, eight-sector caching, motor state,
  write-protection, write buffering, atomic flush, and host media I/O in later
  CRs.

## Upstream And Workflow Completeness Gate

The complete preserved `MDVINIT` length/open path and the `MDV_CACHE` sector
addressing boundary were read in full. The companion specification sections
6, 8, and 11 were cross-checked against the upstream constraints. No upstream
length or sector-boundary behavior in this ticket may be silently omitted;
runtime transport and media mutation are explicitly deferred rather than
reimplemented here.

## Upstream Discovery

The preserved implementation divides the file length by 543, rejects lengths
below 9 sectors and above 254 sectors, stores the validated sector count, and
uses sector offsets of `sector * 543`. The final cache window may be shorter
than eight sectors, but that is a later cache/flush concern and does not relax
the image-shape invariant.

## Disposition

- MDR shape validation and immutable sector view: `IMPLEMENT_NOW`.
- Sector pointer/address bounds: `IMPLEMENT_NOW`.
- Header/data checksum and GAP interpretation: deferred to task 210.
- Motor/cartridge selection and visibility: deferred to task 210.
- Write protection, dirty state, save/flush, and host file access: deferred to
  tasks 211–213.

## Zero-Gap Exit Scan

Re-read the complete scoped upstream routines and companion-spec sections after
implementation. Confirm exact 543-byte arithmetic, inclusive 9/254 bounds,
partial-length rejection, safe sector indexing, failure atomicity, and no host
resource leakage. Confirm later cache, motor, checksum, and write behavior has
not been pulled into this CR.
