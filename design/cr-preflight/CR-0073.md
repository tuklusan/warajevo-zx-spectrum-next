# CR-0073 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Demonstrate that the fixed 16 MiB timing ring retains at least eight complete
  48K PAL frames under an actual `TIMING_FULL` CPU/bus trace workload.
- Use deterministic instruction execution with timing tracing enabled, rather
  than a sparse synthetic event stream, and recover the frozen ring through the
  production reader.
- Verify fixed capacity, recoverable event order, instruction reconstruction,
  and an eight-frame pre-write retention window without changing emulated state
  or increasing the trace-file size.
- Close Phase-2 only after the complete pinned Fuse corpus, project CPU
  acceptance inventory, exact bus traces, and this measured retention proof
  all have current remote and hosted evidence.

## Upstream Discovery

This is an architecture-owned diagnostic requirement, not a source migration
from a Warajevo routine. Architecture sections 44.1 and 44.2 require a fixed
16 MiB circular timing file, periodic absolute CPU state synchronization, and
at least eight complete 48K PAL frames of `TIMING_FULL` retention before
Phase-2 exits. The preserved Z80 reference remains relevant only to the
deterministic instruction workload; it cannot waive the trace retention floor.

## Disposition

| Functional aspect | Disposition | Evidence target |
| --- | --- | --- |
| Fixed 16 MiB ring capacity | PRESERVE_AND_MEASURE | file-size assertion |
| Real CPU/bus timing workload | IMPLEMENT_NOW | deterministic traced instruction loop |
| Wrapped reader recovery | IMPLEMENT_NOW | ordered recovered events and instruction markers |
| Eight PAL-frame retention | IMPLEMENT_NOW | recovered master-tick window at least `8 * 69888` |
| Fuse and project CPU acceptance | PRESERVE | CR-0071 and CR-0072 evidence |
| Contention/ULA timing events | DEFER | Phase-3 and later owned behavior |

## Zero-Gap Exit Scan

Re-scan the trace writer, reader, synchronization codec, CPU trace emission,
and the Phase-2 acceptance requirements. Close only when the measured workload
uses the normal timing-trace path and proves the eight-frame floor without a
capacity increase, sparse-event substitution, or unowned Phase-3 assumptions.
