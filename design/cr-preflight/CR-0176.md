# CR-0176: Extend Default External Review Deadline for Slow NIM Responses

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Raise the shared default deadline for normal and bootstrap external reviews to
3,600 seconds (one hour) so slow but valid review responses are not classified
as unavailable under the documented operating conditions. Preserve explicit
deadline overrides, retry behavior, serialized locking, health-check timing,
fail-closed semantics, and the configured API/model contract.

## Functional Inventory

- Apply the one-hour default to normal CODE, DOCUMENTATION, and TEST_ARTIFACT reviews.
- Apply the same default to the legacy/bootstrap review entry point.
- Keep explicit `--deadline-seconds` values authoritative, including shorter values.
- Keep health checks independently bounded at their existing short timeout.
- Keep 404, 408, 429, and transient server responses on the existing retry path.
- Keep deadline expiry terminal and non-authorizing; it must never produce PASS.
- Keep review locking serialized so packets are never reviewed in parallel.
- Preserve telemetry of the selected deadline and terminal reason.
- Update authoritative documentation, tests, and CR evidence without exposing secrets.

## Upstream Discovery

The preserved upstream source was scanned for external-review workflow,
deadline policy, and reviewer transport behavior. No corresponding review gate
exists upstream; this is project infrastructure. No upstream emulator behavior
is introduced or omitted by this change.

## Disposition

- `IMPLEMENT_NOW`: change the shared normal/bootstrap default to 3,600 seconds.
- `IMPLEMENT_NOW`: update the authoritative review-gate deadline documentation.
- `IMPLEMENT_NOW`: add deterministic tests for the published default and its
  preservation of explicit overrides and fail-closed expiration.
- `PRESERVE`: health-check timeout, retry schedule, lock serialization, and
  API/model configuration.
- `NOT_APPLICABLE`: emulator behavior and upstream compatibility behavior.
- `NOT_APPLICABLE`: local build or test execution; validation remains remote or hosted.

## Zero-Gap Exit Scan

and authority documents for stale 1,200-second default claims. Confirm that
