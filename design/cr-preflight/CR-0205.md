# CR-0205 Implement AY Noise Generator

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Implement the AY 5-bit noise-period register R6 with zero treated as one.
- Maintain a deterministic 17-bit noise linear-feedback shift register.
- Advance the noise divider from the same integer AY-clock accumulator as the
  tone generators, independent of host audio requests.
- Expose the logical noise level and period for later channel mixing.
- Reset the LFSR, divider, level, and master-tick phase deterministically.
- Keep tone, envelope, mixer, PCM, and serialized AY-state behavior separate.

## Upstream Completeness Gate

Rescan the preserved AY sound paths for R6 masking, divider cadence, LFSR
width, feedback taps, shift direction, reset seed, and output-bit selection.
Compare every noise-only rule with the new core implementation and assign
envelope, mixer, host delivery, and snapshot behavior to named later tasks.

## Upstream Discovery

The preserved sound implementation models a dedicated noise counter and a
17-bit feedback register alongside the three tone oscillators. The project
already owns the AY register image and deterministic master-tick accumulator;
this CR adds only the noise divider and LFSR state to that boundary.

## Disposition

- R6 period decode, minimum period, 17-bit LFSR, output level, and AY-clock
  advancement: `IMPLEMENT_NOW`.
- Tone interaction/mixer gating: `DEFERRED_WITH_CR` to Tasks 192-193.
- Envelope generation and register edge cases: `DEFERRED_WITH_CR` to Task 191.
- AY serialization and PCM regression: `DEFERRED_WITH_CR` to Task 193.
- Non-base 128K variants: `CONTROLLED_SCOPE`.
