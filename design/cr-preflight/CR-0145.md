# CR-0145 Preflight: Fixed-Point Mixer Representation

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Freeze the deterministic numeric representation, accumulation, saturation, and
rounding rules required before canonical audio mixer implementation.

## Functional Inventory

- Use signed 32-bit Q16.16 canonical samples on every supported platform.
- Use signed 64-bit accumulators for mixer intermediate sums.
- Define the exact unity constant and fractional-bit count.
- Saturate over-range results rather than wrapping.
- Reduce fractional values with round-to-nearest, ties away from zero.
- Keep the contract independent of host float width, rounding mode, and SIMD.
- Keep physical device conversion outside canonical mixer arithmetic.

## Upstream Completeness Gate

Inspect preserved upstream speaker/audio numeric paths and compare amplitude,
mixing, clipping, and host conversion responsibilities. Retain relevant audio
intent while replacing host-dependent integer widths or floating behavior with
the explicit deterministic core contract.

## Upstream Discovery

The preserved upstream sound path is tied to host speaker configuration and
does not provide a portable canonical fixed-point PCM contract. The migration
therefore freezes Q16.16 samples and Q64 accumulators before mixer behavior is
implemented.

## Disposition

Add the numeric policy constants and types to the core audio boundary and bind
the decision into the architecture document. Mixer operations, clipping code,
and host delivery remain subsequent CRs.

## Zero-Gap Exit Scan

Close only when representation width, unity, accumulation, overflow,
saturation, tie rounding, host separation, and cross-platform invariance have
no undispositioned gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
