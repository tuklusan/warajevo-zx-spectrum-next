# CR-0117 Preflight: Full Phase-4A Timing Smoke Repeat

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Repeat the complete Phase-4A timing-smoke suite after the timing evidence and
reproducer gates, using at least two independent compilers.

## Functional Inventory

- Re-run instruction and bus-cycle timing cases.
- Re-run interrupt-entry and edge timing cases.
- Re-run contention and fetch-versus-write cases.
- Re-run border and floating-bus cases.
- Re-run raster-racing and multicolor cases.
- Confirm deterministic traces and canonical outputs remain unchanged.

## Upstream Completeness Gate

Compare the full Phase-4A task list, frozen timing evidence, and upstream
reference behavior before execution. Any uncovered timing behavior remains an
explicit follow-up CR rather than being silently treated as passed.

## Upstream Discovery

diagnostics, validation, and reproducer ordering required for this repeat.

## Disposition

Execute the existing complete timing suite without changing implementation.
Open a follow-up CR for every unexplained compiler disagreement or upstream
behavioral gap.

## Zero-Gap Exit Scan

Close only when every Phase-4A case has evidence, at least two compiler paths
agree, and the upstream comparison finds no untracked timing gap.

- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows harness runs using the published revision.
- Hosted platform smoke across all available labels.
- Final upstream zero-gap scan and publication evidence.
