# CR-0247 Implement Bounded Memory Inspection

Status: CLOSED

## Functional Inventory

- Read one byte or a bounded block from the live machine memory boundary
  without cloning or exposing a debugger-owned memory array.
- Preserve the full 16-bit address space, including the final address, and
  reject block requests that would wrap past address `0xffff`.
- Reject null machine, null single-byte destination, and null non-empty block
  destination arguments deterministically.
- Allow zero-length reads with a null block destination and leave machine state
  unchanged for every inspection operation.
- Preserve ROM/RAM and 48K/128K mapping behavior by delegating to the existing
  machine memory accessor; do not bypass bus or paging ownership.
- Keep memory mutation, search, fill, paging edits, and host presentation
  outside this CR; those surfaces require later controlled APIs.

## Zero-Gap Exit Scan

The broader scan covers every address-boundary, zero-length, null-argument,
ROM/RAM mapping, 48K/128K paging, display/editor, and host-state boundary
identified by the architecture, inventory, current implementation, and
upstream routines. No undispositioned behavior remains.
