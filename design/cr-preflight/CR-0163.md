# CR-0163 Preflight: Standard TAP Writing

Status: CLOSED

## Objective

Implement standard Spectrum TAP writing for supported SAVE output without
changing core emulated timing or conflating the format with Warajevo-native
TAP. The writer must emit exact two-byte little-endian block lengths and the
defined data bytes, including their XOR checksum representation.

## Functional Inventory

- Accept validated standard TAP logical blocks from caller-owned memory.
- Emit one exact little-endian length prefix per block and reject lengths that
  cannot be represented by the standard format.
- Preserve every defined data byte and produce the final XOR checksum byte.
- Provide a sizing pass and bounded caller-owned output operation with no
  partial output publication on insufficient capacity or invalid input.
- Preserve empty, multi-block, and binary data semantics deterministically.
- Keep writing outside the deterministic machine core and independent of host
  paths, files, wall clock, GUI, and audio callbacks.
- Add headless write/read round-trip, checksum, truncation, capacity, and
  deterministic-repeat fixtures.

## Upstream Completeness Gate

Compare upstream SAVE, tape-block, checksum, and output paths line-by-line in
`WARAJEVO.PAS`, `LOADER.ASM`, `SPECCOMP.ASM`, `TSZ80.ASM`, and `Z80_C.ASM`.
Record applicable SAVE data boundaries, flag/checksum behavior, output error
semantics, and any distinction between standard and native TAP. Reconcile
the result with the frozen TAP contract in `design/media-format-support.md`
and the parser delivered by CR-0162.

## Upstream Discovery

CR-0162 provides strict standard TAP parsing and deterministic pulse expansion;
CR-0161 provides core MIC transitions. The remaining ordered gap is a
host-independent standard TAP logical writer for supported blocks. Native TAP,
TZX, WAV, and host filesystem export remain separate work.

## Disposition

Implement only standard TAP logical writing, validation, sizing, bounded
output, and round-trip tests. Do not implement native TAP writing, TZX/WAV
support, host file I/O, instant loading, trap detection, or networking.
