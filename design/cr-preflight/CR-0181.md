# CR-0181 Architecture-Based macOS Matrix Acceptance

Status: CLOSED

## Functional Inventory

- Schedule every configured hosted macOS lane during cross-platform runs.
- Continue waiting for every configured lane to reach a terminal state.
- Require every non-macOS lane to succeed.
- Require at least one successful Intel macOS lane and one successful ARM
  macOS lane for hosted publication acceptance.
- Permit exact-commit local or remote lab evidence to substitute for a missing
  hosted Intel or ARM architecture at CR closure.
- Never treat a queued, missing, or unavailable lane as an implicit success.
- Preserve `fail-fast: false`, exact-SHA binding, and publication identity.
- Keep machine identity and complete test results with any lab substitution.

## Upstream Discovery

The upstream product source and architecture were scanned for platform and
host-backend behavior. This policy-only change does not replace or alter any
upstream emulator behavior. Repository discovery covered the hosted matrix,
publication gate, lab machine contract, remote evidence paths, queue-waiting
rules, and all current macOS labels.

## Disposition

- All configured hosted macOS lanes: `IMPLEMENT_NOW`; preserve broad coverage.
- Non-macOS hosted lanes: `IMPLEMENT_NOW`; mandatory portability proof.
- Hosted Intel and ARM minimum: `IMPLEMENT_NOW`; architecture coverage gate.
- Local/remote lab substitution: `IMPLEMENT_NOW`; exact-commit closure evidence.
- Queued/unavailable lanes: `IMPLEMENT_NOW`; environmental, never implicit pass.
- Product behavior: `NOT_APPLICABLE`; no emulator behavior changes.

## Zero-Gap Exit Scan

The second scan revisited hosted labels, architecture classification, terminal
waiting, non-macOS requirements, exact-SHA evidence, lab substitution records,
and publication behavior. No undispositioned behavior remains. The matrix
still attempts all configured macOS lanes; acceptance now requires coverage of
both macOS architectures rather than every individual macOS label.

## Closure Requirements

- Static repository gates pass.
- Exact-SHA CODE and DOCUMENTATION reviews pass.
- The hosted matrix reaches terminal state for every configured lane.
- All non-macOS lanes pass and both macOS architectures have valid evidence.
- Publication and any lab substitution evidence are bound to the same commit.

Closed on 2026-09-04 after hosted run `33914657804` reached terminal state for
all configured lanes, passed all non-macOS lanes, and supplied successful Intel
and ARM macOS evidence at the validated commit.
