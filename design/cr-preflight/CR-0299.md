## Change Request
CR-0299: GUI Save Screenshot workflow

Status: APPROVED_FOR_IMPLEMENTATION
Priority: high

## Functional Inventory
- Expose the stable `host.screenshot.save` GUI action through a shared save workflow.
- Acquire a caller-selected destination for each Save Screenshot operation.
- Encode the completed presentation raster through `wz_screenshot_png_encode`; never duplicate PNG or framebuffer logic in the GUI seam.
- Preserve machine state and raster input while preparing output.
- Return explicit success, cancellation, invalid-destination, invalid-raster, and insufficient-output-capacity results.
- Keep destination state host-only and bounded; do not expose it through the deterministic machine state or remote command metadata.
- Keep the workflow toolkit-independent so the later GUI adapter owns the native file dialog and file commit policy.
- Ensure a cancelled or rejected operation leaves the workflow and machine state unchanged.

## Upstream Discovery
Architecture authority: UI Section 8.4 and task 294. Related current seams
are `src/app/wz_screenshot_service.h`, `src/app/wz_snapshot_save_workflow.h`,
`src/app/wz_command_registry.h`, and `src/app/wz_ui_layout.c`.
The preserved upstream tree was searched for screenshot, PNG, file-dialog,
capture, and save-path behavior. No portable screenshot workflow or GUI file
dialog exists in the preserved legacy source; the applicable legacy behavior is
the host Save Screenshot action, which is represented by the architecture
command contract. No additional upstream behavior remains undispositioned.

## Disposition
`IMPLEMENT_NOW`: add a bounded, toolkit-independent screenshot save workflow
that stores the selected destination and delegates all raster encoding to the
shared screenshot service. `DEFERRED_WITH_CR`: native toolkit dialog and atomic
host file commit remain later host integration work. No duplicate encoder or
host framebuffer capture is permitted.

## Zero-Gap Exit Scan
The final scan must confirm destination acquisition, cancellation, invalid
inputs, output-capacity reporting, exact delegation to the shared encoder,
input/machine immutability, host-only destination state, and no duplicate GUI
PNG path. It must also confirm the stable command remains `host.screenshot.save`.
