# CR-0085 Preflight: CPU Interrupt Sampling and Same-Edge Ordering

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Verify and implement the boundary between the scheduled level-triggered ULA
interrupt line and CPU interrupt sampling. Freeze an explicit, testable event
order for a line edge coincident with CPU timing without using C call order as
hardware truth.

## Functional Inventory

- Sample the maskable interrupt line only at the CPU instruction boundary
  required by the Z80 contract, not continuously in the middle of an M-cycle.
- Preserve EI's one-instruction recognition delay and DI/IFF gating.
- Keep HALT behavior equivalent to repeated NOP boundaries for interrupt
  sampling.
- Preserve IM0, IM1, IM2, NMI, acknowledge, refresh, stack, and trace behavior.
- Define same-master-tick ordering between a ULA line edge, CPU sampling, and
  any CPU bus activity.
- Record line edge, sample decision, acceptance, and acknowledge as ordered
  timing events with exact master ticks.
- Ensure state reset and canonical serialization preserve any new sampling
  state without host-clock dependence.
- Keep unsupported or manually requested interrupt entry behavior explicit and
  backward-compatible for deterministic fixtures.

## Upstream Completeness Gate

The authoritative Z80 reference states that `/INT` is level-triggered, held
low for 32 T-states on the 48K machine, and sampled during the last M-cycle of
an instruction; HALT behaves as repeated NOPs and EI delays recognition until
after the following instruction. The preserved Warajevo sources were scanned
for `INT_8`, `PROCINT`, `IFF`, `HSTATE`, `RCLK`, and the interrupt dispatch
paths in `SPECSIM.ASM` and `Z80.ASM`.

The project authorities are sections 10, 11, 14, 36, 44, and 51 of
`design/warajevo-zx-spectrum-next-architecture.md`, tasks 070 and 071 in
`design/wzsn-architectures-1-2-developer-tasks.md`, CR-0084, and
`design/machine-timing-evidence.md`.

## Upstream Discovery

The current CPU has explicit interrupt-entry helpers and trace records but no
automatic connection to the machine interrupt line. CR-0084 supplies the
profile-driven line schedule. The scheduler currently orders CPU before ULA
for equal ticks, which is only a Phase-1 abstraction and cannot be reused as
the hardware sampling rule without an explicit evidence decision.

## Disposition

Implement the smallest complete CPU-line sampling boundary and add a named
same-edge ordering rule to the timing evidence. Preserve the existing public
manual interrupt-entry helper for fixtures, but route normal instruction
boundary sampling through the line state. Use line state observed at the
sampling edge; a deassertion before that edge prevents acceptance. Defer ULA
fetch, floating-bus, raster, and model-specific interrupt variations to their
named later CRs.

## Zero-Gap Exit Scan

Before closure, rescan every return path from `wz_z80_step`, HALT/EI/DI paths,
interrupt entry modes, NMI, bus acknowledge and refresh operations, line
scheduling, scheduler priorities, trace serialization, canonical state, and
the preserved interrupt routines. Classify each discovered behavior as
implemented, covered by an existing fixture, or explicitly deferred to a
named later task. No undispositioned same-edge behavior permits closure.

## Verification Plan

- Static gate and source scan on the local machine only.
- Remote Linux CMake/CTest and complete pinned Fuse suite.
- Hosted platform smoke across Linux, Windows, and macOS targets.
- CODE and DOCUMENTATION advisory reviews against this preflight and the
  authoritative timing evidence.
- Direct edge vectors for assertion before/after instruction boundaries,
  deassertion before sampling, EI delay, HALT, same-tick trace ordering, and
  state round-trip.
