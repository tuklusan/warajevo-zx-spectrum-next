# CR-0116 Preflight: Timing Failure Regression Policy

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Enforce the Phase-4A rule that every timing failure receives a minimal
deterministic trace-based reproducer before implementation changes are made.

## Functional Inventory

- Define the required first-divergence trace evidence for timing failures.
- Ensure regressions capture instruction, bus, ULA, and master-tick context.
- Require a minimal reproducer before any timing implementation fix.
- Preserve upstream comparison and failure classification.
- Keep diagnostic evidence headless and deterministic.

## Upstream Completeness Gate

Rescan reference failure traces, existing timing regressions, and architecture
section 44 requirements. Assign any behavior outside this policy to a later task.

## Upstream Discovery

Existing trace and hash contracts provide the evidence primitives; this CR makes
the pre-fix reproducer requirement explicit without changing emulation behavior.

## Disposition

Add policy evidence and only missing regression fixtures discovered by the audit.
Do not suppress failures or approve implementation changes without reproducers.

## Zero-Gap Exit Scan

Before closure, rescan timing failures, trace completeness, minimality, upstream
classification, and ordering of reproducer versus implementation fix.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux complete timing suite and regression evidence.
- Hosted platform smoke across all supported labels.
- Final upstream zero-gap scan and publication evidence.
