# CR-0237 Deterministic Interface 1, Microdrive, and ZX Net Regression Tests

Status: CLOSED

## Functional Inventory

- Verify Interface 1 ROM loading, old/new variant selection, paging, shadow
  mapping, reset, and restoration when leaving Interface 1.
- Verify MDR image geometry, mount, sector addressing, buffered writes,
  protection, dirty tracking, flush, discard, and round-trip persistence.
- Verify all six ZX Net states, claim/acceptance, collection isolation,
  bounded loopback transfer, collision read/write, and deterministic timing.
- Verify 48K and 128K machine integration without host-time or filesystem
  dependence in the deterministic core.
- Retain failure-state assertions for invalid media, failed flush, and invalid
  device transitions.
