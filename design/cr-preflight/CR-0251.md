# CR-0251 Implement Deterministic ZX Printer Peripheral

Status: CLOSED

## Functional Inventory

- Implement the Spectrum-visible ZX Printer port at low byte `0xfb` (251),
  including deterministic status reads and control/pixel writes.
- Preserve the upstream motor transitions: motor-on acceptance is rejected
  when the printer is absent/not ready, motor-off flushes pending output, and
  the first motor-on control write is consumed without a pixel.
- Preserve the four configured modes: Epson normal, Epson enlarged, HP normal,
  and HP enlarged. Mode identity is core state; host printer protocol bytes are
  not core state.
- Preserve the bounded 256-byte pixel buffer, pixel duplication/rotation rules,
  row progression, slow-motor immediate flush, four-row flush, and HP byte/row
  boundaries in deterministic ordering.
- Expose completed printer output through a core-owned bounded event stream;
  host presentation/export remains outside the deterministic peripheral.
- Keep BIOS/LPT/INT 17, host handles, paths, wall clock, and printer availability
  outside canonical machine state. Disabled hardware decode must not mutate the
  printer.

  `src/core/wz_machine.{h,c}`; no second machine or host-facing core boundary.

## Zero-Gap Exit Scan

The implementation must re-read the complete printer routine, dispatch tables,
inventory, and named architecture sections before closure. Every upstream
state field and branch must have an explicit implementation or disposition:
status bits, last output latch, motor, mode, pixel buffer/count, row, flush
thresholds, and mode-specific pixel/flush behavior. Any host-only BIOS/LPT path
must remain explicitly replaced rather than silently copied.
