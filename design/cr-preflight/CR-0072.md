# CR-0072 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Establish a project-owned, reviewable CPU acceptance inventory that maps each
  Phase-2 CPU category to deterministic test evidence rather than treating the
  pinned Fuse corpus as complete coverage.
- Cover primary, CB, ED, DD/FD, and DDCB/FDCB instruction families; flags and
  undocumented-visible behavior; stack and branch timing; prefix retention;
  HALT, EI/DI, IM0/1/2, and NMI boundaries; bus ordering; state
  serialization/hash behavior; and timing-trace reconstruction.
- Identify and implement only genuinely missing focused vectors. Preserve the
  complete Fuse suite as complementary conformance evidence, not a substitute
  for project-owned timing, interrupt, trace, and differential fixtures.
- Record the Warajevo 2.50 reference boundary for each differential-capable
  CPU scenario. Real-hardware evidence remains authoritative if a preserved
  reference approximation disagrees.

## Upstream Discovery

Architecture section 36.1 requires project-owned instruction, timing/bus,
contention, interrupt, real-hardware, and full-machine evidence in addition
to Fuse. Section 39 requires compatible scenarios to compare CPU registers,
memory, snapshots, and user-visible behavior with preserved Warajevo 2.50;
it does not allow an uninvestigated mismatch to be silently classified.

The existing CPU implementation and tests already cover the upstream Z80
dispatch families, indexed forms, interrupt entry helpers, and trace encoding.
This CR must rescan the preserved `Z80.ASM` dispatch and interrupt paths plus
the test suite before declaring any category covered. Phase-3 memory map,
contention scheduling, ULA fetch, and device behavior remain out of scope and
must not be represented as completed CPU acceptance coverage.

## Zero-Gap Exit Scan

Re-scan the complete project CPU test inventory, all primary/CB/ED/DD/FD
dispatch paths, interrupt entry and trace paths, the Fuse manifest, and the
preserved Warajevo Z80 dispatch/interrupt reference. Close only when every
Phase-2 CPU acceptance category has direct project-owned evidence or a
reviewed, phase-owned deferred disposition, and no inherited upstream CPU
behavior is omitted from the coverage inventory.
