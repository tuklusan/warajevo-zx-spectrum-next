# CR-0056 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Preserve CP A, S/Z/H/PV/N/C, instruction timing, PC/R, and (HL) memory read.
- Source CP undocumented X/Y from the compared operand.
- Cover b8, ba, bb, bd, be, and bf; retain already-passing b9 and bc.

## Upstream Discovery

`upstream/main` dispatches all primary CP forms through `CP_B` through `CP_A`.
The portable shared ALU helper is the only affected implementation point. Pinned
Fuse vectors confirm operand-derived X/Y while ordinary subtraction flags remain
unchanged.
