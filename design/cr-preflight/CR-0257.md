# CR-0257 Implement Debugger Jump and Register Undo Controls

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Add a paused-state program-counter jump operation over the one live machine.
- Preserve CPU-state validation, mutation access mode, traceability, and
  failure atomicity for jump requests.
- Add one-level undo for the most recent accepted register-state mutation;
  rejected mutations must not replace the undo state.
- Keep undo and jump deterministic, bounded, host-independent, and separate
  from UI command acquisition and presentation.

## Upstream Discovery

- Re-read the complete `JUMP`, `SETREG`, `STOREREG`, `BACKREG`, `UNDOREG`, and
  `UNDOLOOP` routine families in `SPECMON.ASM`.
- Compare register validation, restore ordering, mutation failures, and
  breakpoint/step interaction with the existing shared debugger APIs.
- Re-read Architecture 1 sections 41, 44, and 49.2 and UI Architecture 2
  sections 21 and 45.

## Disposition

| Surface | Disposition | Reason |
|---|---|---|
| Paused program-counter jump | IMPLEMENT_NOW | Required shared debugger control |
| One-level register undo | IMPLEMENT_NOW | Required mutation workflow |
| Host/UI command widgets | DEFERRED_WITH_CR | UI presentation boundary |
| Unpaused jump or undo | REJECT | Preserve safe-state policy |
| Invalid CPU state | REJECT | Preserve existing validation and atomicity |

## Zero-Gap Exit Scan

Before closure, every named jump and register-undo branch must map to a result
and regression case. Repeat the upstream scan and verify accepted, rejected,
repeated-undo, and interaction paths without introducing a second machine state.

## Required Evidence

- Updated Phase-11 coverage matrix with test names for jump and undo.
- Serial CODE, TEST_ARTIFACT, and DOCUMENTATION reviews for the exact commit.
- Remote lab and hosted matrix validation with inspected manifests.
- Private closure record retaining traces and visual evidence where supported.

## Exit Gates

CR-0257 may close only after the upstream zero-gap scan, exact-SHA reviews,
remote/hosted validation, evidence inspection, and publication gate pass.
