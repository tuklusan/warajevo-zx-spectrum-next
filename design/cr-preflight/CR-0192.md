# CR-0192 Cross-Host Snapshot Round-Trip and Failure Regression Coverage

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Exercise the canonical SNA 48K writer and loader as a deterministic round trip.
- Exercise the canonical Z80 v2 48K writer and loader as a deterministic round trip.
- Assert portable header, page-order, length, register, and memory-byte contracts at
  the format boundary rather than relying only on host-sized structures.
- Verify truncated SNA/Z80 inputs, unsupported hardware fields, and wrong-format/model
  inputs return controlled errors.
- Verify failed loads leave the previously accepted snapshot unchanged.
- Verify failed saves leave the caller's output buffer unchanged, including capacity
  failures and unrepresentable networking state.
- Keep all runtime execution on remote or hosted validation machines.

## Upstream Completeness Gate

Rescan the preserved upstream snapshot load/save paths and the frozen media matrix for
all 48K SNA/Z80 byte ordering, stack/PC, page mapping, compression, variant rejection,
and failure-atomicity behavior relevant to this regression slice. Existing format CRs
cover implementation; this CR must prove the cross-host contract as one acceptance set.

## Upstream Discovery

The upstream snapshot path uses fixed byte offsets for CPU state and memory, reconstructs
the SNA return PC from the stack, and maps Z80 pages 8, 4, and 5 to the three 48K banks.
The migration retains those format boundaries while using isolated candidates and
non-mutating writers for unsupported or truncated data.

## Disposition

- Deterministic 48K SNA/Z80 round-trip and golden-boundary checks: `IMPLEMENT_NOW`.
- Truncation, wrong-format/model, unsupported-field, and atomic-failure regressions:
  `IMPLEMENT_NOW`.
- 128K live-machine snapshot integration: `DEFERRED` to Phase 9 tasks 183-195.
- Native v3 writing and historical formats outside the frozen matrix: `DEFERRED` or
  `CONTROLLED_ERROR` according to `design/media-format-support.md`.

## Zero-Gap Exit Scan

Before closure, rescan upstream snapshot readers/writers, the media matrix, all current
format loaders/writers, and the new tests. Confirm every listed cross-host byte boundary
and failure class is exercised or explicitly deferred, with no missing 48K behavior.

## Evidence and Exit Gates

- Exact-SHA CODE review, independent bootstrap review, and documentation review as applicable.
- Static repository gates and `git diff --check` locally; no local build or test.
- Remote Linux sanitizer smoke, remote Windows 10/11 and Intel Mac smoke where available.
- Hosted platform matrix with housekeeping, exact SHA, and publication gates.
- Second upstream zero-gap scan completed before closure.
