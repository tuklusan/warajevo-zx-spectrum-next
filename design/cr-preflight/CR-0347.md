# CR-0347 Preflight: Allow Slow Reviewer Calls Within the Review Deadline

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

The external reviewer may require many minutes for one inference call. The
transport timeout must not terminate a healthy call at 180 seconds when the
review deadline permits up to one hour. The request timeout must remain bounded
by the overall deadline, and deadline exhaustion must remain fail-closed.

Functional aspects covered: normal slow responses, timeout calculation,
retryable transport failures, overall deadline enforcement, bootstrap reuse of
the shared client, lock lifetime, telemetry, and regression tests.

## Upstream Discovery

Authorities examined: `design/review-gate.md`, `WORKFLOW.md`,
`tools/reviewer/review_gate.py`, `tools/reviewer/legacy_bootstrap_gate.py`,
and `tests/test_review_gate.py`. The scan covered the deadline, transport
worker, retry loop, and shared bootstrap client. No separate bootstrap timeout
or undispositioned upstream behavior exists for this scope.

## Disposition

- Request timeout alignment: `IMPLEMENT_NOW`; cap each call at the one-hour
  review deadline while still taking the smaller remaining time.
- Deadline enforcement and retry policy: `NOT_APPLICABLE`; preserve behavior.
- Harnesses, wrappers, packet construction, and product code:
  `NOT_APPLICABLE`; unchanged.

## Zero-Gap Exit Scan

The exit scan must show a bounded one-hour request ceiling, a smaller timeout
when the deadline has less remaining time, preserved fail-closed deadline
behavior, and a passing remote reviewer regression. No local build or test is
permitted.
