# CR-0042 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Emit optional deterministic instruction-boundary events with PC, opcode and register state.
- Emit every CPU-visible bus operation with cycle, address, value, T-state length and master tick.
- Preserve monotonically increasing same-tick sequence ordering.
- Record maskable-interrupt and NMI acceptance/acknowledge decisions.
- Persist all structured fields through the fixed-size circular diagnostic trace and standalone reader.
- Keep tracing observational: disabled, failed, frozen or wrapped diagnostics may not change core state.
- Cover trace reconstruction of an opcode failure and preserve the 16 MiB ring contract.

## Upstream Discovery

Authority: Architecture sections 11, 36 and 44.2; task 059.

Reference examined: `upstream/main`, legacy `src/spectrum-kernel/Z80.ASM` and
`src/spectrum-kernel/SPECSIM.ASM`; searches covered instruction dispatch,
refresh/timing, IFF/interrupt state, HALT, and NMI paths. The legacy code
contains instruction dispatch and timing accounting but no portable structured
trace-file contract; WZSN architecture supplies that required replacement.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Instruction/timing dispatch evidence | IMPLEMENT_NOW | Z80.ASM dispatch and RF/RC timing paths |
| Bus-cycle evidence | IMPLEMENT_NOW | Architecture section 11.3 and current machine bus API |
| Interrupt and NMI transitions | IMPLEMENT_NOW | Z80.ASM IFF state and SPECSIM.ASM NMI path |
| Legacy host debugger implementation | REIMPLEMENTED_DIFFERENTLY | Architecture section 44 requires a portable binary ring |
| ULA/peripheral timing events | DEFERRED_WITH_CR | Their devices are not implemented; later device CRs must add events |
| Eight-frame timing-torture measurement | DEFERRED_WITH_CR | Required at Phase-2 closure task 062 after full timing corpus exists |

## Zero-Gap Exit Scan

A second upstream scan covered neighboring interrupt, HALT, refresh, dispatch,
and timing-accounting symbols. No undispositioned behavior relevant to the
current CPU/bus trace scope remains. Device-specific trace events are explicitly
deferred because the corresponding device implementations do not yet exist.
