# CR-0151 Preflight: Bounded Host Audio Backpressure

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Ensure host audio buffering remains bounded and that overflow or underflow
cannot change machine event order, selected runtime speed, or canonical hashes.

## Functional Inventory

- Bound host audio storage to a fixed capacity.
- Preserve FIFO ordering for accepted samples across wraparound.
- Report rejected overflow samples without blocking the producer.
- Report underflow as fewer samples returned without synthesizing samples.
- Keep queue occupancy and loss counters outside canonical machine state.
- Ensure queue pressure cannot alter machine timing, speed selection, or events.
- Keep device callbacks limited to consuming prepared host samples.

## Upstream Completeness Gate

Compare preserved sound buffering and callback paths for overflow, underflow,
device demand, and speed interaction. Retain observable audio delivery while
rejecting any callback-driven machine advancement or host pressure feedback
into deterministic execution.

## Upstream Discovery

The preserved upstream sound path uses host backend buffering and does not
provide a canonical-state isolation contract. WZSN therefore uses a fixed host
FIFO with explicit loss/underflow behavior and a regression assertion that
host queue activity leaves the machine hash unchanged.

## Disposition

Use the existing fixed-capacity push queue as the bounded backpressure seam.
Overflow drops newest not-yet-accepted samples and increments a saturating
host-only counter; underflow returns only available samples. No blocking,
machine callback, or speed mutation is introduced.

## Zero-Gap Exit Scan

Close only when capacity, wraparound order, overflow, underflow, loss counting,
non-blocking behavior, callback isolation, speed preservation, canonical-hash
isolation, and upstream comparison have no undispositioned gap.

## Verification Plan

- CODE and DOCUMENTATION advisory reviews.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
