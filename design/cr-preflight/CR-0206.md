# CR-0206 Implement AY Envelope Generator

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Decode the AY 16-bit envelope period from registers R11 and R12, with zero
  treated as one at the logical divider boundary.
- Advance the envelope from the same deterministic AY-clock domain as tone and
  noise, independent of host audio requests.
- Implement all sixteen AY envelope shape encodings, including continue,
  attack, alternate, and hold behavior.
- Restart the envelope deterministically when R13 is written, including the
  initial level and direction selected by the attack bit.
- Expose the logical envelope level and period for the later mixer integration.
- Keep channel mixer gating, PCM delivery, and serialized state explicitly
  deferred to their named follow-on CRs.

## Upstream Completeness Gate

Rescan the preserved AY paths for R11/R12 period decode, the envelope clock
divider, R13 restart timing, all shape-control combinations, terminal hold and
alternate transitions, channel use of envelope volume, and reset behavior.
Compare each rule against the new core state and record deferred mixer,
serialization, and host-delivery responsibilities rather than silently
omitting them.

## Upstream Discovery

The preserved AY implementation stores an envelope counter, current volume,
step direction, and terminal volume. Its shape kernel distinguishes continue,
attack, alternate, and hold and updates channels whose volume register selects
the envelope. This CR moves the deterministic envelope state to the canonical
AY-clock boundary without coupling it to host callbacks.

## Disposition

- R11/R12 period decode, zero handling, AY-clock divider, R13 restart, shape
  state machine, and logical level: `IMPLEMENT_NOW`.
- Per-channel mixer application: `DEFERRED_WITH_CR` to Task 192.
- AY state serialization and canonical PCM regression: `DEFERRED_WITH_CR` to
  Task 193.
- Non-base 128K variants: `CONTROLLED_SCOPE`.

handling, restart semantics, all sixteen shape values, terminal transitions,
envelope-selected channel behavior, and master-tick conversion. Confirm every
scoped envelope rule is implemented and tested, with later mixer, PCM, and
serialization responsibilities explicitly excluded.
