# CR-0259 Implement Deterministic Machine Reset and Warm Restart Boundary

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Add one shared machine-reset operation for the one live machine.
- Restore the active profile's authentic initial CPU and peripheral state.
- Clear transient execution, paging, interrupt, raster, printer, and debugger
  mutation state without restarting the host application.
- Preserve the architecture-defined host boundaries: model, speed, display,
  audio, input preferences, Telnet connection, and mounted media remain under
  their existing policies.
- Keep reset deterministic, host-independent, traceable, and failure-atomic.

## Upstream Discovery

- Re-read the complete `ABORT`, `ANEW`, and `ASOFT` routine families in
  `SPECMON.ASM`, including the separate 48K and 128K branches.
- Compare their reset and warm-restart effects with Architecture 1 sections
  41, 44, 49.2, and 55.13 and UI Architecture 2 sections 9.2, 21, and 27.1.
- Re-read the current machine initialization, networking reconfiguration,
  interrupt, raster, media, printer, and debugger state boundaries.
- Record all preserved, reset, and explicitly deferred surfaces in the
  implementation and regression evidence.

## Disposition

| Surface | Disposition | Reason |
|---|---|---|
| Emulated machine state | IMPLEMENT_NOW | Required `machine.reset` boundary |
| Host application process | MUST_PRESERVE | Reset must not restart WZSN |
| Model and emulation speed | MUST_PRESERVE | Explicit UI architecture rule |
| Telnet connection and key ownership | MUST_PRESERVE | Explicit core reset policy |
| Mounted media | MUST_PRESERVE | Reset is not media eject |
| Debugger undo and breakpoint state | RESET_TRANSIENT_STATE | No stale mutation after reset |
| Legacy BASIC host internals | REPLACE_WITH_SHARED_BOUNDARY | Not a second machine model |

## Zero-Gap Exit Scan

Before closure, compare every state written by `ABORT`, `ANEW`, and `ASOFT`
with the new reset contract. Verify both certified profiles, repeated reset,
reset while paused, reset with mounted media, reset with active input/network
boundaries, and reset trace ordering. No routine branch may remain unclassified.

## Required Evidence

- Deterministic reset API and focused regression cases for both certified
  profiles, preservation rules, repeated reset, and transient-state clearing.
- Updated Phase-11 coverage matrix naming the passing reset regression.
- Serial CODE, TEST_ARTIFACT, and DOCUMENTATION reviews for the exact commit.
- Remote lab and hosted matrix validation with inspected manifests and private
  closure evidence.

## Exit Gates

CR-0259 may close only after the upstream zero-gap scan, exact-SHA reviews,
remote/hosted validation, evidence inspection, and publication gate pass.
