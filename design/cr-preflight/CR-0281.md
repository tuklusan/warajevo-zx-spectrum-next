# CR-0281 Shared Display Settings Surface

Status: IN_PROGRESS
Priority: HIGH
Execution order: ARCHITECTURE_2_PHASE_12E
Blocking: NO

## Functional Inventory

- Expose View > Display Settings through the shared Display settings surface.
- Keep scaling, crop, and host presentation effects host-owned and separate from
  canonical raster, timing, machine state, and emulated audio semantics.
- Reuse one settings model for the View shortcut and the main Settings surface.
- Preserve cancel and invalid-input state invariants and keyboard operation.

## Upstream And Architecture Discovery

- UI Architecture Sections 18.3 and 23.1 define the shared host-only Display
  settings contract; the legacy reference contributes display concepts but no
  modern settings API.
- Existing host presentation and scaling files are the integration seam, and
  no duplicate display configuration store may be introduced.
- No deterministic core, transport, harness, or wrapper changes are permitted.
