# CR-0052 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Decode every documented primary load/data-transfer opcode currently reported by Fuse.
- Preserve flags for load and 16-bit increment/decrement operations.
- Execute immediate and indirect reads/writes through the machine bus at exact ticks.
- For `0x22` and `0x2A`, fetch the low and high address operands at offsets 8
  and 14, then transfer the low and high data bytes at offsets 20 and 26.
  For `0x3A`, fetch both address operands at offsets 8 and 14, then read the
  data byte at offset 20. These offsets are relative to completion of the
  opcode fetch and preserve the upstream instruction-cycle ordering.
- Update PC, MEMPTR, and register state according to the primary instruction form.
- Preserve 16-bit wrap behavior at all address boundaries.
- Cover register, memory, and pair forms with the complete pinned Fuse manifest.

## Upstream Discovery

Reference examined: `upstream/main`, `src/spectrum-kernel/Z80.ASM`, `TABLE1`,
`LDBCNN`, `LDDENN`, `LDHLNN`, `LDSPNN`, `LDMBCA`, `LDAMBC`, `LDMDEA`,
`LDAMDE`, `LDMNNA`, `LDAMNN`, and the register-load table entries.

The reference separates CPU semantics from host implementation. This CR
reimplements the same Z80-visible state transitions in portable C through the
machine bus, without translating host assembly mechanisms.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Primary load/data transfers | IMPLEMENT_NOW | Fuse failures and Z80.ASM dispatch |
| Index-prefixed substitutions | FOLLOW_ON_CR | Separate DD/FD failure cluster |
| I/O port loads and stores | FOLLOW_ON_CR | Separate Fuse D3/DB failure cluster |
| Undocumented SLL behavior | RETAINED_EXISTING | Existing CB implementation |

## Zero-Gap Exit Scan

The second upstream scan covered all TABLE1 primary load positions and their
memory variants. Prefix and I/O dispatch are explicitly outside this CR and
remain tracked by their own applicable Fuse failures.
