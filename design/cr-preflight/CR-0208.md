# CR-0208 Serialize AY State and Add Canonical Audio Regression Evidence

Status: CLOSED

## Functional Inventory

- Advance the versioned WZSN-native state format without changing historical
  SNA/Z80 layouts or their representability rules.
- Serialize and deserialize the AY selected register and all sixteen AY
  registers in explicit little-endian/byte order.
- Serialize and deserialize all deterministic AY generator state: tone
  counters and levels, noise counter/LFSR/level, envelope counter/period/level,
  envelope attack/holding state, and AY master-tick phase.
- Exclude transient AY event-log history from canonical state while resetting
  that host/evidence buffer deterministically after load.
- Validate serialized AY ranges and reject malformed state atomically without
  mutating the target machine.
- Include every serialized AY field in the canonical machine hash so changing
  any AY-observable state changes the hash.
- Prove a machine state containing non-default AY registers and generator
  state round-trips byte-for-byte and produces the same canonical hash.
- Prove the canonical AY mixer sample remains identical after state round-trip.
- Keep canonical PCM sample-phase accumulation and Sokol/physical audio
  delivery explicitly deferred to their named follow-on work.

## Upstream Completeness Gate

Rescan the preserved snapshot and AY paths for every state-bearing field:
selected register, R0-R13 audio registers, tone/noise/envelope counters and
levels, noise shift register, envelope direction/holding, and chip clock
phase. Compare the inventory with the new native format and tests. Confirm
historical formats only carry the fields their formats define and that no
host event log, output queue, or device callback state enters canonical state.

## Upstream Discovery

The preserved snapshot path stores the selected AY register and sixteen AY
register bytes, while the live deterministic implementation additionally owns
the generator counters, levels, noise shift register, envelope state, and
clock phase. The native WZSN state must preserve the latter fields even though
historical snapshot formats cannot represent them. The preserved source also
confirms AY state is restored as part of snapshot recovery rather than as host
audio-device state.

## Disposition

- Versioned native AY state serialization, validation, hash participation, and
  atomic round-trip tests: `IMPLEMENT_NOW`.
- Historical SNA/Z80 AY field expansion: `DEFERRED_WITH_CR`; retain their
  existing format contracts.
- Canonical 44,100 Hz sample-phase accumulation and PCM hash vectors:
  `DEFERRED_WITH_CR` to the canonical PCM task.
- Sokol push delivery and host audio queue state: `DEFERRED_WITH_CR` to host
  audio tasks.
- Non-base 128K snapshot formats: `CONTROLLED_SCOPE`.

## Zero-Gap Exit Scan

Before closure, rescan the native state version/header, all AY fields listed
above, little-endian encoding, range validation, atomic failure behavior,
hash sensitivity, mixer equivalence, event-log exclusion, and historical
format boundaries. Confirm every scoped state rule is implemented and tested,
with PCM phase and host delivery explicitly excluded.
