# CR-0228 Microdrive Write Protection and Buffered Writes

Status: CLOSED

## Functional Inventory

- Track per-transport write protection and dirty state deterministically.
- Accept writes only for an active mounted cartridge in write mode and outside
  GAP/erase restrictions.
- Buffer writes without mutating the source image until an explicit commit.
- Saturate the bounded sector pointer at the 543-byte sector limit.
- Refuse writes to protected, inactive, unmounted, invalid, or read-mode media
  without mutating image bytes or dirty state.
- Keep atomic host save/flush and cross-process ownership in later CRs.

## Upstream And Workflow Completeness Gate

The complete upstream `MDV_OUT`, `MDV_IN`, `FLUSH`, and `MOTOR` paths were read
and cross-checked with companion-spec sections 6 through 8. The preserved
behavior distinguishes write mode, protection, active motor, GAP/erase state,
bounded pointer, dirty buffer, and explicit flush boundaries.

## Upstream Discovery

`MDV_OUT` ignores writes unless one motor is active and the control latch is in
write mode with erase clear; accepted bytes enter a bounded 543-byte buffer.
`FLUSH` resets an empty/non-write buffer, refuses protected media, and marks
the cache dirty when accepted data is committed. This CR models only the
deterministic in-memory write contract.

## Disposition

- Write-protect state and bounded in-memory buffer: `IMPLEMENT_NOW`.
- Explicit commit/dirty indication without host I/O: `IMPLEMENT_NOW`.
- Atomic save/flush and ownership: defer to tasks 212 and 213.

## Zero-Gap Exit Scan

is omitted.
