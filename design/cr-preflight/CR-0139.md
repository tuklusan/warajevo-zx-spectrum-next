# CR-0139 Preflight: Unlimited Pacing Responsiveness

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Ensure Unlimited mode removes artificial pacing while preserving the host
loop's opportunity to service input, presentation, and other events.

## Functional Inventory

- Never request or invoke an artificial sleep in Unlimited mode.
- Preserve every canonical machine frame, timed device event, and event order.
- Keep presentation coalescing and host event servicing outside the core.
- Ensure entering or leaving Unlimited mode uses the same speed-change boundary.
- Verify the sleep seam is not called, including after large tick progress.
- Keep Unlimited behavior independent of canonical state, serialization, and hashing.

## Upstream Completeness Gate

Inspect the preserved upstream run loop and fast-forward behavior. Confirm that
removing wall-clock throttling does not skip ULA execution or timed machine
effects, and that host presentation/event servicing remains an outer-loop
responsibility.

## Upstream Discovery

The architecture specifies Unlimited as the fastest deterministic core run with
normal wall-clock throttling omitted. It permits dropping intermediate host
presentation but does not permit skipping machine execution or device events.

## Disposition

Retain the existing host pacing Unlimited branch and strengthen its contract
test to prove that no sleep callback is called. No core or canonical timing
changes are required for this task.

## Zero-Gap Exit Scan

Close only when Unlimited entry, sustained progress, exit to a finite policy,
sleep suppression, event preservation, and host-loop separation have no
undispositioned gaps.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
