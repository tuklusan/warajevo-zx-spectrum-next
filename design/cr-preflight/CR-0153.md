# CR-0153 Preflight: Sokol Host Audio Delivery

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Connect canonical PCM to Sokol's push audio API and validate host delivery on
WASAPI, ALSA, and CoreAudio where the platform provides usable audio hardware.

## Functional Inventory

- Initialize Sokol audio at the frozen canonical rate and mono channel policy.
- Push prepared PCM from the host/orchestrator without a stream callback.
- Convert fixed-point canonical samples only at the host boundary.
- Apply the host speed mute policy before device submission.
- Report unavailable devices independently from deterministic core correctness.
- Shut down audio in orderly host cleanup.
- Keep device demand, callback timing, and backend state out of machine state.

## Upstream Completeness Gate

Compare preserved upstream speaker/audio backend delivery for device setup,
sample conversion, mute behavior, and shutdown. Retain observable host output
while enforcing producer-driven WZSN audio and no callback-driven emulation.

## Upstream Discovery

The preserved upstream audio path is backend-specific and does not provide a
Sokol push-only boundary. WZSN uses Sokol's push API with no stream callback;
backend availability is an environmental result, never a core test verdict.

## Disposition

Add a host-only Sokol audio adapter using the frozen 44,100 Hz mono contract,
fixed-point-to-float conversion, explicit mute gating, and orderly shutdown.
Host smoke evidence records available and unavailable backends separately.

## Zero-Gap Exit Scan

Close only when WASAPI, ALSA, CoreAudio, initialization, push submission,
conversion, mute, unavailable-device handling, shutdown, callback isolation,
and upstream comparison have no undispositioned gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Sokol host build/run smoke where audio hardware permits.
- Final upstream zero-gap scan and publication evidence.
