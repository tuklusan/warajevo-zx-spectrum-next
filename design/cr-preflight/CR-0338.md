# CR-0338: Bound review diffs to mapped code and document ranges

Status: APPROVED_FOR_IMPLEMENTATION
Priority: high
Blocking: workflow gate

## Change Request
Ensure requirement-linked review packets transmit only the mapped related code
or document range and changed diff hunks that intersect that range, never a full
selected file or unrelated same-file changes.

## Functional Inventory
- Parse unified diff hunk ranges safely.
- Retain only hunks intersecting mapped prior or current ranges.
- Fail closed for malformed or empty mapped diffs.
- Preserve exact requirement, related excerpt, prior excerpt, and hash checks.
- Preserve the frozen reviewer transport and remote harness behavior.

## Upstream Discovery
- CR-0336 established the requirement-linked packet contract.
- The current packet builder still used a whole-file diff for a selected file.
- Review budget constants and reviewer prompts require bounded review units.

## Disposition
`IMPLEMENT_NOW`: add range-intersection filtering to linked diff generation and
retain focused regression coverage. Do not modify frozen harnesses.

## Zero-Gap Exit Scan
Confirm unrelated files and unrelated same-file hunks are absent from linked
CODE and DOCUMENTATION packets, while a mapped changed hunk remains present.

## Exit Gates
- Static repository gates pass.
- Remote reviewer regression suite passes.
- Focused linked CODE and DOCUMENTATION reviews pass.
