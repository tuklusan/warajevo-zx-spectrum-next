# CR-0077 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Add a profile-declared expected external-ROM identity and a deterministic
  identity calculation over exactly 16 KiB of supplied bytes.
- Reject ROM loading when the profile has no configured certification identity
  or when supplied bytes do not match it; never embed firmware bytes.
- Preserve the accepted ROM identity and loaded-ROM protection state in the
  canonical serialized machine state.
- Prove correct loading, wrong-hash rejection, unconfigured-profile rejection,
  ROM protection, and restored protection state with deterministic fixtures.

## Upstream Discovery

The preserved Warajevo host source has no portable firmware-distribution or
identity-certification mechanism. This is a project-owned legal and
deterministic-regression boundary required by architecture sections 29 and 36.

## Zero-Gap Exit Scan

Re-scan profile construction, ROM loading, all memory-write protection paths,
state serialization/deserialization, state hashing, trace identity consumers,
and fixture setup. Close only when no unverified ROM can become write-protected
or be restored as a certified machine.

## Disposition

Use a stable 64-bit FNV-1a identity over the exact ROM region. Built-in profiles
remain unconfigured for redistributable firmware; a certification caller must
supply a profile copy with its expected identity. A successful load records the
identity and activates protection; all other loads leave machine state intact.

## Closure Evidence

Closure status: CANDIDATE

The exit scan found one profile identity declaration, one exact-size FNV-1a
identity function, one fail-closed load transition, and one machine-bus write
protection path. Serialization records both loaded-ROM state and identity and
rejects inconsistent combinations. The preserved source contains historical
ROM allocation/paging and 16 KiB utilities, but no portable external-ROM
certification contract; that boundary remains project-owned.

The deterministic regression fixture is an otherwise zero 16 KiB image with
byte `1234` equal to `5a`; its required FNV-1a 64-bit identity is
`5bb7495d13c5113f`, using offset basis `14695981039346656037` and prime
`1099511628211`. The test asserts that exact independent value before loading.
