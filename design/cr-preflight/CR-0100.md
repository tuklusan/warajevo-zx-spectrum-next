# CR-0100 Preflight: Active-Pixel Color Decoding

Status: CLOSED

## Objective

Decode fetched bitmap and attribute bytes into canonical Spectrum logical color
indices without host RGB values, presentation dependencies, or wall-clock
state.

## Functional Inventory

- Select the bitmap bit for each pixel with Spectrum MSB-first ordering.
- Decode INK and PAPER from the attribute byte.
- Produce normal logical colors for BRIGHT clear and bright logical colors
  for BRIGHT set.
- Select INK when the bitmap bit is one and PAPER when it is zero.
- Leave FLASH interpretation to its separately ordered ticket.
- Reject invalid bit positions deterministically.
- Cover all eight normal colors, all eight bright colors, and both bitmap
  pixel states with table-driven tests.
- Keep logical indices independent of RGB palette, GPU, Sokol, and screenshots.

## Upstream Completeness Gate

Architecture sections 16.3, 17, 18, 36, and 51 require active pixels to be
derived from fetched bitmap/attribute state. Rescan the preserved display
decoding paths, attribute bit layout, bitmap bit order, BRIGHT semantics, and
host presentation boundary. Every scoped rule must be implemented, tested, or
assigned to a named later task.

## Upstream Discovery

The preserved reference supplies the legacy Spectrum display layout. The
current core freezes fetch events, logical sample encoding, and raster storage;
the missing slice is a pure active-pixel decoder that maps those bytes to
logical palette values.

## Disposition

Add a pure core decoder for one active pixel. Keep FLASH phase, raster
materialization, border, and host palette conversion outside this ticket.
Tasks 087-095 retain ownership of INK/PAPER/BRIGHT tables, FLASH, diagnostics,
and Phase-4 acceptance.

## Zero-Gap Exit Scan

Before closure, rescan bitmap/attribute layout, bit order, normal/bright color
semantics, invalid inputs, and later-task assignments. Confirm no scoped color
rule is implicit or host-dependent.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux build/test with full table-driven active-pixel fixtures and the
  complete pinned corpus.
- Hosted platform smoke across the supported matrix.
- Repeat logical decoder outputs across supported hosts.
