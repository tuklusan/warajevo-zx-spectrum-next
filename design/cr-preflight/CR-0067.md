# CR-0067 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Implement DD/FD `24`, `25`, `26`, `2C`, `2D`, `2E`, `34`, `35`, and `36`
  forms: IXH/IYH and IXL/IYL increment, decrement, immediate load, plus
  indexed-memory increment, decrement, and immediate load with signed offset.
- Preserve exact primary-compatible flags for register and memory INC/DEC;
  preserve flags for immediate loads; retain non-selected registers and MEMPTR
  behavior defined by the upstream indexed address calculation.
- Record DD/FD prefix fetches, signed displacement reads, immediate reads,
  read-modify-write bus order, PC/R progression, and exact indexed timing.
- Remove only the remotely resolved cases from the baseline. Indexed register
  transfers and ALU forms remain follow-on CRs.

## Upstream Discovery

The DD and FD dispatch tables route these entries to `INCXH/INCYH`,
`DECXH/DECYH`, `LDXHN/LDYHN`, `INCX L/INCY L`, `DECX L/DECY L`,
`LDXLN/LDYLN`, `INC_MIX/INC_MIY`, `DECMIX/DECMIY`, and `LDMIXN/LDMIYN`.
The indexed-memory routines calculate the signed displacement before memory
access and perform the required read-modify-write or immediate store.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| IXH/IYH and IXL/IYL INC/DEC/LD n | IMPLEMENT_NOW | upstream DD/FD tables |
| INC/DEC/LD (IX/IY+d) | IMPLEMENT_NOW | upstream indexed memory routines |
| Indexed transfers and ALU forms | FOLLOW_ON_CR | remaining baseline entries |

## Zero-Gap Exit Scan

Re-scan DD and FD tables for `24` through `36`, their helper routines, and
neighboring indexed families. Close only when every scoped form is remotely
validated and no undispositioned behavior remains.
