# CR-0191 Deterministic SNA/Z80 Parser Fuzz Coverage

Status: CLOSED

## Functional Inventory

- Exercise SNA 48K and 128K parser boundaries with deterministic malformed inputs.
- Exercise Z80 v1, v2, and v3 header classification and supported/unsupported fields.
- Exercise truncated headers, page headers, declared lengths, and trailing bytes.
- Exercise compressed streams with zero runs, overlong runs, truncated runs, and
  invalid v1 termination markers.
- Exercise invalid, duplicate, missing, and unsupported page numbers.
- Exercise unsupported hardware, paging, Interface 1, AY, and device-state fields.
- Prove malformed input never publishes partial snapshot state or crashes.
- Keep generation deterministic and run fuzz/sanitizer execution only on remote machines.

## Upstream Completeness Gate

The preserved upstream SNA and Z80 loader paths must be rescanned for every parser
boundary and failure path relevant to this work. The existing CR-0089 generic safety
fixture is not sufficient because its model-specific parser strategies were explicitly
deferred; this CR must cover the frozen Phase-8 snapshot matrix and its controlled errors.

## Upstream Discovery

The upstream `SNAPSHOT.PAS` paths classify SNA by exact header/file shape, classify Z80
v1 from the base PC and compression bit, classify v2/v3 from additional-header lengths,
and consume page headers and decompressed payloads according to the historical page map.
The migration must preserve valid behavior while making malformed and unsupported cases
bounded, atomic, and explicit.

## Disposition

- Deterministic mutation corpus and targeted malformed fixtures: `IMPLEMENT_NOW`.
- Remote sanitizer and CTest execution with recorded seed/evidence: `IMPLEMENT_NOW`.
- Valid parser behavior: `PRESERVE_EXISTING_CONTRACT`.
- Unsupported variants and malformed input: `CONTROLLED_ERROR` with no publication.
- Native libFuzzer integration or unbounded runtime fuzzing: `DEFERRED`; the bounded
  deterministic fixture is the current cross-platform project gate.

## Zero-Gap Exit Scan

The second scan of the frozen media matrix, all SNA/Z80 loaders, compression helpers,
page mapping, header classification, unsupported-state checks, atomic publication, and
the deterministic corpus found no missing parser-fuzz behavior. The sanitizer run also
found and validated correction of an existing one-byte fuzz-fixture overrun before closure.
