# CR-0275 Implement Semantic Help and About Actions

Status: APPROVED_FOR_IMPLEMENTATION
Priority: HIGH
Execution order: ARCHITECTURE_2_PHASE_12B
Blocking: NO

## Functional Inventory

- Provide stable `help.help` and `help.about` action metadata.
- Provide deterministic Help content through a toolkit-independent projection.
- Provide deterministic About identity content without host paths, wall-clock
  values, or toolkit-specific objects.
- Preserve platform-standard relocation of About without changing its semantic
  ID or canonical Help menu placement.
- Keep action execution and dialog/presentation ownership outside the core.

## Upstream Discovery

- Compare the preserved Warajevo startup/help registration and help-file path
  handling in `WARAJEVO.PAS` with `HELP.TXT`.
- Compare the required modern Help menu tree and stable IDs in UI Architecture
  2 Sections 7.2, 40, 43, 47, and 49.
- Perform a second scan after implementation for help-file failure behavior,
  reentrancy, About identity, platform relocation, and no host-data leakage.

## Disposition

| Surface | Disposition | Reason |
|---|---|---|
| Help/About semantic IDs and metadata | IMPLEMENT_NOW | Required menu contract |
| Deterministic content projection | IMPLEMENT_NOW | Test and later front-end contract |
| Toolkit dialog/window | DEFER_TO_HOST_ADAPTER | Host presentation boundary |
| Legacy binary help viewer | REIMPLEMENT | Preserve discoverability without DOS UI |

## Exit Gates

Close only after implementation, focused contract tests, the second upstream
zero-gap scan, serial CODE/TEST_ARTIFACT/DOCUMENTATION reviews, remote and
hosted validation, and publication evidence pass. No local build or test is
permitted.

## Implementation Record

- The candidate implementation is `src/app/wz_ui_help.c` and
  `src/app/wz_ui_help.h`, with focused coverage in
  `tests/wz_ui_help_tests.c` and a CMake test target.
- Help and About expose the required stable IDs and deterministic text without
  host paths, wall-clock values, toolkit objects, or file I/O.
- The second upstream scan covered legacy startup registration, derived help
  file handling, open-failure behavior, reentrancy protection, About identity,
  platform relocation, and host-data leakage. The legacy file/dialog concerns
  are intentionally replaced at the host adapter boundary; semantic content
  and IDs are preserved by the candidate.
- No harness or wrapper is modified by this CR.
