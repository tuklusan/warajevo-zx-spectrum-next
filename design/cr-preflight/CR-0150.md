# CR-0150 Preflight: Host Resampling Decision

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Freeze a host-only resampling choice for audible runtime speeds without
introducing platform-dependent behavior into canonical audio or machine state.

## Functional Inventory

- Convert canonical 44,100 Hz PCM to the physical device rate.
- Support natural duration and pitch changes from 0.5x through 2.0x.
- Preserve source ordering and clamp interpolated samples safely.
- Keep phase and interpolation state outside canonical serialization/hashing.
- Reset resampling only on explicit host stream restart.
- Discard muted-range delivery rather than building an unbounded backlog.
- Ensure device callbacks consume prepared data and never advance emulation.

## Upstream Completeness Gate

Compare preserved sound output and speed paths for source consumption, device
rate conversion, speed changes, and mute behavior. Retain audible output
semantics while replacing callback-driven timing with the producer-driven WZSN
host boundary.

## Upstream Discovery

The preserved upstream path delegates device-rate behavior to its host audio
backend and does not define a portable canonical resampling contract. WZSN
therefore freezes interpolation only at the host boundary, while retaining
the upstream-observable speed relationship and explicit mute behavior.

## Disposition

Freeze bounded linear interpolation with a host-only 64-bit fixed-point source
phase. The deterministic core remains at canonical PCM and has no resampler
dependency.

## Zero-Gap Exit Scan

Close only when device-rate conversion, speed ratio, phase ownership, clamping,
restart behavior, mute disposal, callback isolation, and upstream comparison
have no undispositioned gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
