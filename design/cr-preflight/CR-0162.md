# CR-0162 Preflight: Standard TAP Parsing

Status: CLOSED

## Objective

Implement strict parsing of standard Spectrum TAP into validated in-memory
tape media. Parsing must complete validation before publication, preserve
logical block bytes and checksum outcomes, and expand supported blocks into
the canonical Normal-mode pulse representation without host file state.

## Functional Inventory

- Recognize standard TAP by its repeated two-byte little-endian block lengths.
- Parse every block with exact bounds checks and reject truncation, impossible
  lengths, and trailing partial length fields.
- Validate the final XOR checksum byte without repairing or silently accepting
  a mismatch.
- Expand valid blocks into deterministic pilot, sync, data-bit, and pause
  segments using the frozen Spectrum timing rules.
- Preserve block order and data bytes for later writer and diagnostics work.
- Reject malformed input before the resulting tape object is mounted or any
  existing machine/tape state is changed.
- Keep parser memory ownership explicit and independent of host paths,
  file handles, wall clock, GUI, and audio callbacks.
- Add headless valid, empty, truncation, impossible-length, checksum-error,
  multi-block, and deterministic-repeat fixtures.

## Upstream Completeness Gate

Compare the upstream standard-loader and tape timing behavior line-by-line in
`WARAJEVO.PAS`, `LOADER.ASM`, `SPECCOMP.ASM`, `TSZ80.ASM`, and `Z80_C.ASM`.
Record applicable pilot/sync/data/pause timing, bit ordering, initial levels,
checksum handling, block boundaries, and loader-visible error behavior. Also
compare `design/media-format-support.md` and the current tape object so the
parser does not conflate standard TAP with the later Warajevo-native format.

## Upstream Discovery

CR-0158 through CR-0161 provide validated in-memory tape state, canonical
playback time, and core MIC output. The remaining gap is conversion from
standard TAP logical blocks to immutable timed segments. Native TAP, TZX, WAV,
writing, instant loading, and trap paths are separate ordered work and are not
authorized here.

## Disposition

Implement only standard TAP identification, strict parsing, checksum/error
reporting, deterministic pulse expansion, and headless tests. Do not add
Warajevo-native detection, TAP writing, TZX/WAV support, instant loading,
trap detection, or host export.
