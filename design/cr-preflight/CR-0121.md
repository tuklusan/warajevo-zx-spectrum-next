# CR-0121 Preflight: Minimal Sokol Application Shell

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Implement the smallest host application shell that opens a window around the
headless-driven core without moving machine logic into Sokol callbacks.

## Functional Inventory

- Add a host entry point and lifecycle boundary.
- Initialize and shut down the pinned Sokol dependency safely.
- Keep machine ownership and deterministic stepping outside callbacks.
- Provide a minimal close/quit path without adding UI features.
- Preserve headless compilation and testability of the core.

## Upstream Completeness Gate

Compare Sokol application lifecycle requirements, the frozen X11 decision,
existing core/orchestrator contracts, and preserved upstream behavior. Record
every required lifecycle or error path before implementation.

## Upstream Discovery

CR-0119 pins Sokol and CR-0120 freezes X11. Existing core contracts provide the
headless boundary; this CR adds only the host shell around that boundary.

## Disposition

Implement a minimal host translation unit and explicit core/host interface.
Do not add rendering, input, audio, pacing, or platform-specific machine logic
until their ordered tasks are active.

## Zero-Gap Exit Scan

Close only when lifecycle, shutdown, error handling, core isolation, and
headless compatibility are evidenced on the remote and hosted paths.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows host-shell build/smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
