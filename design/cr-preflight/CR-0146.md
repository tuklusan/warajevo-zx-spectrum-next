# CR-0146 Preflight: Initial AY Analog-Mixing Model

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Freeze the initial deterministic AY analog-mixing target that later 128K AY
implementation and canonical mixer work must reproduce.

## Functional Inventory

- Define three AY channels with equal contribution to the initial mono target.
- Define all 16 AY amplitude levels as a project-owned Q16.16 gain table.
- Define level zero as silence and the maximum level as unity gain.
- Keep tone/noise/envelope generation, register timing, and AY clocking separate.
- Keep stereo panning, host sample rate, resampling, and device delivery out of the model.
- Make the table compile identically across supported compilers.

## Upstream Completeness Gate

Inspect preserved upstream AY/sound configuration and compare channel count,
volume semantics, attenuation, stereo assumptions, and host conversion. Record
any legacy host-specific choices as non-canonical rather than silently inheriting
them into the 128K core model.

## Upstream Discovery

The preserved upstream source exposes AY-related sound selection and PC-speaker
delivery controls but does not provide a portable canonical AY PCM model. The
new target freezes equal mono channel summation and a Q16.16 attenuation table;
AY register/timing semantics remain separately owned by Phase 9.

## Disposition

Add the channel/level constants and gain table in a core audio policy header,
document the target, and bind it with a regression assertion. No AY device or
host audio delivery is implemented by this CR.

## Zero-Gap Exit Scan

Close only when channel count, volume endpoints, intermediate gain values,
summation, numeric representation, host separation, and upstream comparison
have no undispositioned gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
