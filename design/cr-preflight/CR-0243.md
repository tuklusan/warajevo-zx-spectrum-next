# CR-0243 Define the Shared Debugger API

Status: CLOSED

## Functional Inventory

- Define one debugger facade over the live machine for register, memory,
  machine-state, trace, and future execution inspection.
- Separate read-only inspection from paused mutation and preserve atomic state
  validation for later mutation CRs.
- Prevent a second CPU, memory model, scheduler, or canonical state copy.
- Keep host presentation and file/export behavior outside deterministic core
  state.

## Upstream Discovery

- Architecture 1 sections 41, 44, and 49.2.
- UI Architecture 2 section 21.
- `design/monitor-debugger-inventory.md` and preserved `SPECMON.ASM`.
- Existing `wz_machine`, `wz_z80`, `wz_trace`, and memory-boundary APIs.

Reconcile every required monitor workflow with the inventory and ensure the API
does not create a second machine implementation or bypass existing state/trace
boundaries.
