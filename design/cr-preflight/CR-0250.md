# CR-0250 Implement Scheduler-Backed Single-Step and Continue

Status: CLOSED

## Functional Inventory

- Expose single-step and continue controls through the existing live-machine
  scheduler and CPU, never through a debugger-specific executor.
- Single-step exactly one instruction or stop at the active breakpoint while
  preserving CPU, bus, interrupt, and master-tick ordering.
- Continue until the next breakpoint or explicit bounded stop condition,
  preserving the existing scheduler’s event ordering and timing semantics.
- Define halted CPU, interrupt acceptance, invalid state, and no-breakpoint
  behavior deterministically without partial state publication.
- Emit trace evidence for command, instruction boundary, stop reason, and
  resulting machine state without adding host metadata to canonical state.
- Keep UI command dispatch, persistence, conditional expressions, and external
  transport outside this core control API.
