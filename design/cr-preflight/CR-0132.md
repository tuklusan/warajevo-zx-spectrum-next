# CR-0132 Preflight: Keyboard Ghosting Behavior

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Research the preserved keyboard electrical behavior beyond ordinary multiple-row
selection and freeze whether ghosting is emulated, ruled out, or deferred with
an explicit evidence-backed contract.

## Functional Inventory

- Inventory upstream keyboard scan and matrix electrical assumptions.
- Distinguish ordinary row-combination behavior from ghosting phenomena.
- Identify diode/isolation assumptions and three-key rectangle cases.
- Define observable behavior for ambiguous or unsupported electrical cases.
- Ensure the chosen policy is deterministic and testable.
- Record provenance and the reason for implementation or explicit exclusion.

## Upstream Completeness Gate

Inspect preserved upstream source, documentation, tests, and machine-level
evidence for keyboard electrical behavior. Compare every relevant scan path,
masking rule, and multi-key case with the current matrix implementation; no
ghosting claim may rely on absence of a search hit alone.

## Upstream Discovery

The current matrix intentionally implements active-low row AND semantics. This
CR must determine whether additional electrical ghosting is observable in the
reference behavior or whether the row model is the complete accepted contract.

## Disposition

Produce a documented frozen policy and focused tests or an explicit evidence
record ruling additional ghosting out. Do not change host mappings, focus
handling, timestamps, or Kempston behavior here.

## Zero-Gap Exit Scan

Close only when upstream evidence, the three-key/multiple-row analysis, chosen
policy, and regression evidence are recorded with no unresolved ghosting gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation if implementation changes.
- Hosted platform matrix validation if implementation changes.
- Final upstream zero-gap scan and publication evidence.
