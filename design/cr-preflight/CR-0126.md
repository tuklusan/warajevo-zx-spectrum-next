# CR-0126 Preflight: Integer Host Scaling

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Implement integer nearest-neighbor host scaling so resizing preserves
canonical Spectrum pixels without filtering or core mutation.

## Functional Inventory

- Define integer scale-factor selection and output dimensions.
- Map each output pixel to exactly one source pixel.
- Reject or explicitly handle non-integer and zero-size requests.
- Keep scaling in host presentation code outside the deterministic core.

## Upstream Completeness Gate

Compare the architecture scaling contract, frozen presentation rectangle,
canonical raster format, existing upload boundary, and preserved upstream
behavior. Record all rounding, clipping, and ownership assumptions.

## Upstream Discovery

CR-0125 freezes the source rectangle and CR-0124 isolates backend details. This
CR adds only nearest-neighbor integer presentation mapping.

## Disposition

Add a pure host scaling contract and regression evidence. Do not change source
raster generation, upload format, shaders, or core timing.

## Zero-Gap Exit Scan

Close only when source-pixel preservation, dimensions, invalid requests, and
core isolation are evidenced on remote and hosted paths.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
