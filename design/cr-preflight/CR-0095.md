# CR-0095 Preflight: CPU Write Versus ULA Fetch Visibility

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Resolve visibility when a CPU memory write and a scheduled ULA bitmap or
attribute fetch occur at the same master tick. The result must follow one
documented deterministic ordering, preserve the actual fetched value in the
ULA event, and remain reproducible across runs and hosts.

## Functional Inventory

- Define the same-master-tick ordering between CPU memory writes and ULA
  bitmap/attribute fetches.
- Apply the ordering independently to bitmap RAM and attribute RAM.
- Ensure a write before a fetch is visible and a write after a fetch is not.
- Define behavior for an exact same-edge write/fetch, including trace order,
  bus source, and fetched value.
- Keep ROM write protection and ordinary CPU memory semantics intact.
- Preserve frame, raster, and fetch scheduling determinism without host time.
- Cover writes at the preceding master tick, exact fetch tick, and following
  master tick for both display-memory regions.
- Keep pixel decoding, border, FLASH, floating-bus, and presentation behavior
  assigned to their ordered later tasks.

## Upstream Completeness Gate

Architecture sections 14, 15.5, 18, 36, and 44 require hardware-correct
visibility for raster racing and multicolor software. Rescan the preserved
memory-write and ULA display paths, the scheduler ordering contract, fetch
trace schema, and frozen timing evidence. Every scoped same-edge rule must be
implemented, tested, or explicitly assigned to a named later task.

## Upstream Discovery

The preserved reference establishes the legacy display-memory and timing
context, while the current core provides CPU bus requests, machine memory,
ULA fetch events, and deterministic traces. The missing slice is an explicit
same-edge visibility rule connecting those boundaries without program-specific
exceptions or presentation dependencies.

## Disposition

Centralize same-tick arbitration at the deterministic bus/scheduler boundary.
Do not let callers mutate display memory around fetches through private hooks.
Record both competing events in canonical order and make the fetched byte the
value selected by that order. Tasks 082-095 retain ownership of border,
floating bus, sample encoding, raster output, pixel/color/FLASH semantics,
diagnostics, and Phase-4 acceptance.

## Zero-Gap Exit Scan

Before closure, rescan preserved CPU-write and ULA-fetch paths, same-edge
ordering, ROM protection, bitmap/attribute address classes, trace behavior,
and later-task assignments. Confirm no scoped race remains unimplemented or
implicitly dependent on call order.

## Verification Plan

- Local static gates and source scan only; no local build or test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux build/test with bitmap and attribute same-tick fixtures plus the
  complete pinned corpus.
- Hosted platform smoke across the supported matrix.
- Repeat the same-edge trace on supported hosts and compare canonical values,
  event order, and serialized state.
