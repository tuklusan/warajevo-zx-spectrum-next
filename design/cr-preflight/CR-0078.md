# CR-0078 Migration Preflight

Status: CLOSED

## Functional Inventory

- Add a deterministic shared I/O decoder that classifies low-byte-even ports
  as the ULA port-FE path, including partially decoded addresses such as `00fe`
  and `34fe`.
- Route I/O reads and writes through that dedicated boundary without changing
  existing input-provider fallback behavior for other ports.
- Defer keyboard rows, border/beeper/MIC latches, floating bus, contention,
  128K ports, and optional peripheral collisions to their separately scoped
  architecture tasks.

## Upstream Discovery

The preserved Spectrum kernel identifies keyboard input at `256*n+254` and
ULA output at port `254`; its larger legacy dispatch tables are host-specific
reference material rather than a portable decoder contract.

## Zero-Gap Exit Scan

Re-scan every I/O request entry point, address classification, bus observer
ordering, fallback input behavior, and deferred ULA/peripheral paths. Close
only when all low-byte-even ports have the explicit ULA disposition and no
later device behavior is silently implemented.

## Disposition

Implement classification and a dedicated machine-owned ULA dispatch boundary
only. Until the keyboard and output-latch CRs land, that boundary returns the
existing neutral read value and accepts writes without inventing device state.

## Closure Evidence

Closure status: CLOSED

The exit scan found the single shared I/O request entry point, low-byte-even
classification, dedicated ULA read/write boundary, observer ordering, and
provider fallback. The ULA boundary remains neutral until its separately
scoped keyboard and output-latch work lands; no deferred device behavior is
silently implemented.
