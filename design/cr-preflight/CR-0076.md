# CR-0076 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Preserve the loaded 48K ROM contract: addresses `0000-3fff` reject emulated
  writes only after a valid external 16 KiB ROM image is installed.
- Define an explicit unloaded fixture-image state for CPU-only conformance
  vectors; it has no installed ROM and remains writable so the external
  suite can assess CPU semantics without claiming hardware-map validation.
- Require direct ROM-map coverage to install a valid ROM before asserting
  protection, and preserve writable `4000-ffff` behavior in both states.
- Keep the Fuse unresolved baseline empty: the complete corpus must again
  pass rather than classifying fixture-image differences as unresolved CPU
  behavior.

## Upstream Discovery

The preserved Warajevo source remains a reference for CPU semantics and does
not define this project-owned external-ROM licensing boundary. The pinned Fuse
suite is a CPU conformance input whose case images assume writable flat memory;
its ROM-area mutations cannot certify or invalidate Spectrum ROM protection.

## Zero-Gap Exit Scan

Re-scan machine initialization, external-ROM loading, every machine bus memory
read/write path, CPU-vector runner setup, direct ROM-map tests, and all
complete-corpus manifest classifications. Close only when an unloaded fixture
cannot be mistaken for a loaded ROM machine, and when no memory-only Fuse
failure is hidden by the unresolved baseline.

## Disposition

Record ROM installation as machine state. A successful exact-size ROM load
activates read-only protection for `0000-3fff`; initialization without a ROM
retains an explicit fixture-image state used only by deterministic CPU-vector
setup. Tests must prove both states and the hosted corpus must report zero
unresolved, unexpected, and silent-skipped vectors.

## Closure Evidence

Closure status: CANDIDATE
