# CR-0057 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION
Closure status: CLOSED

## Functional Inventory

- Preserve ordinary CB BIT n,(HL) carry, H/N/Z/PV/S flags, MEMPTR value,
  instruction timing, PC/R, and memory read behavior.
- Source ordinary BIT n,(HL) undocumented X/Y from the high byte of MEMPTR.
- Cover cb46, cb46_1 through cb46_4, cb4e, cb56, cb5e, cb66, cb6e, cb76, and
  cb7e. Retain cb46_5 because it passes coincidentally under both sources.

## Upstream Discovery

`upstream/main` dispatches every ordinary CB BIT memory form through
`BIT0MHL` through `BIT7MHL`, each reading `(HL)` and applying the same BIT
flag family. The pinned Fuse vectors vary only the MEMPTR state and establish
the X/Y source independently from the operand and H register.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| BIT (HL) X/Y source | IMPLEMENT_NOW | cb46 family through cb7e |
| BIT documented flags and bus read | RETAINED_EXISTING | shared CB executor and upstream BIT0MHL through BIT7MHL |
| Register BIT and indexed-CB BIT | RECHECK_ONLY | separate executor paths |

## Zero-Gap Exit Scan

Re-scan BIT0MHL through BIT7MHL and both separate CB executor paths. Close
only when the twelve cases pass remotely, the matching baseline entries are
removed, and no unexpected complete-corpus failure appears.
