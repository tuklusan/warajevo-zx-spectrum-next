# CR-0152 Preflight: Canonical Audio Regression Evidence

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Provide byte-order-stable canonical PCM hashing and regression coverage for
timestamped beeper transitions before host device conversion.

## Functional Inventory

- Hash canonical signed PCM with explicit count and byte order.
- Produce identical hashes for repeated deterministic rendering.
- Change the hash when any sample changes.
- Reject invalid null/count combinations.
- Keep hashing independent of host queue, resampler, device rate, and callbacks.
- Preserve existing timestamped beeper and MIC separation coverage.

## Upstream Completeness Gate

Compare preserved speaker transition and sampling behavior against the current
beeper event fixtures. Retain every observable transition while adding stable
WZSN evidence around the canonical PCM boundary.

## Upstream Discovery

The preserved upstream path has no portable canonical PCM hash contract. WZSN
therefore hashes explicit PCM values at the core output boundary, without
including host delivery state or device-specific representation.

## Disposition

Add a core audio evidence hash using FNV-1a over the sample count and signed
64-bit little-endian sample values, plus deterministic repeatability,
sensitivity, and argument-validation tests.

## Zero-Gap Exit Scan

Close only when transition ordering, sample values, count, byte order,
repeatability, sensitivity, invalid inputs, host-state exclusion, and upstream
comparison have no undispositioned gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
