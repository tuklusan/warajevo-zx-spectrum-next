# CR-0188 Z80 v1 Loader

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Parse the exact 30-byte Z80 v1 header for a 48K machine.
- Restore all main and alternate CPU registers, interrupt state, border, and
  the seven-bit-plus-high-bit refresh register.
- Load exactly 48 KiB of uncompressed memory or valid v1 RLE memory.
- Recognize the exact compressed end marker `00 ED ED 00` only at the end of
  a complete 48 KiB output stream.
- Reject v2/v3 headers, truncated or overlong streams, zero RLE counts,
  missing markers, invalid interrupt modes, and zero PC without publishing
  partial snapshot state.

## Upstream Completeness Gate

Read the preserved upstream `SNAPSHOT.PAS` header detection and `load48k` /
`decompsnap` paths line by line. Compare register byte order, compression flag,
literal `ED` handling, RLE bounds, end-marker behavior, and the 48K address
window with the implementation and regression vectors.

## Upstream Discovery

The upstream decoder classifies a nonzero base-header PC as v1, uses the bit-5
compression flag, maps the 30-byte header into the Z80 state, and expands the
48 KiB payload into addresses `0x4000` through `0xffff`. The historical decoder
also recognizes the four-byte `00 ED ED 00` terminator; this implementation
requires it to be exact and terminal rather than accepting trailing data.

## Disposition

- Z80 v1 48K header and memory loading: `IMPLEMENT_NOW`.
- Legacy RLE decoding and exact terminal marker: `IMPLEMENT_NOW`.
- Higher-version headers, 128K pages, canonical writers, and live commit:
  `DEFERRED_WITH_CR` to tasks 175-177.
- Malformed or unrepresentable input: `CONTROLLED_ERROR` with no publication.

## Zero-Gap Exit Scan

Rescan the frozen media matrix, this preflight, the upstream header and
decompression branches, the parser, and tests. Every v1 field and every input
byte disposition must be implemented or explicitly rejected; no v2/v3 behavior
may enter through the v1 path.

## Closure Requirements

- Static repository gates pass; no local build or test is run.
- Exact-SHA CODE and DOCUMENTATION advisory reviews pass with zero findings.
- Linux, Windows 10, Windows 11, and the available Mac lane pass remote smoke.
- The full hosted matrix and publication gate pass on the published candidate.
