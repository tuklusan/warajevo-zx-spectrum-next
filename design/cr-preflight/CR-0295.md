# CR-0295: Snapshot Inspector Metadata Display

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Present the live inspector's format and version provenance.
- Present the implied machine profile, CPU register summary, paging state, AY register state, memory-page inventory, and warning count.
- Keep the projection read-only, bounded, deterministic, and suitable for a later native host view.

## Upstream And Architecture Discovery

The UI architecture sections 13.1-13.3 require a native Snapshot Inspector boundary and list format/version, model, registers, paging, AY state, pages, and warnings as applicable. The core already owns machine profile, debugger snapshot/page projection, AY accessors, and 48K/128K memory ownership. The inspector therefore projects those shared seams and does not parse or duplicate emulator state.

## Upstream Discovery

The upstream reference was checked for the corresponding debugger/state ownership boundaries. No upstream UI metadata contract was found that supersedes the project's existing debugger snapshot seam; no undispositioned upstream behavior is introduced by this live-machine-only display step. File-format-specific parsing remains a later task with its own authority and tests.

## Disposition

Implement a copied metadata view in `wz_snapshot_inspector_t` and a bounded text formatter. Runtime/live provenance is explicit; warnings are zero for a valid live machine, while future file loaders may populate applicable warnings without changing this contract.
