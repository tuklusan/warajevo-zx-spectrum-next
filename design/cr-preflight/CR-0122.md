# CR-0122 Preflight: macOS Host Translation Unit

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Add the macOS host translation unit in the required Objective-C compilation
mode while keeping the deterministic core's public headers Objective-C-free.

## Functional Inventory

- Select the macOS Sokol/Metal host translation unit extension and language mode.
- Keep the C boundary between host lifecycle and deterministic core explicit.
- Preserve the same lifecycle and shutdown contract as other host platforms.
- Keep platform frameworks and types out of core headers.

## Upstream Completeness Gate

Compare the architecture's macOS requirements, pinned Sokol Metal support,
existing host shell, and preserved upstream behavior. Record every framework,
language-mode, and ownership assumption before implementation.

## Upstream Discovery

CR-0119 pins Sokol, CR-0120 freezes Linux X11, and CR-0121 establishes the
cross-platform host lifecycle. This CR adds macOS-specific compilation only.

## Disposition

Add the minimum `.m` translation-unit path and C-compatible core boundary. Do
not add presentation, input, audio, or pacing behavior from later tasks.

## Zero-Gap Exit Scan

Close only when Objective-C mode, Metal/framework linkage, lifecycle parity,
and core header isolation are evidenced on remote and hosted paths.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote macOS lab smoke where available and hosted matrix validation.
- Final upstream zero-gap scan and publication evidence.
