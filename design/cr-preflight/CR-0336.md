# CR-0336: Enforce requirement-linked external review packets

Status: APPROVED_FOR_IMPLEMENTATION
Priority: high
Blocking: workflow gate

## Change Request
Make the permanent normal CODE and DOCUMENTATION review contract transmit only
a minimal-but-complete requirement, the exact directly related code or document
lines, and an exact prior-section/file diff when prior material exists.

## Functional Inventory
- Require an explicit JSON review map for normal CODE and DOCUMENTATION reviews.
- Validate source and target paths, repository containment, UTF-8 content, hashes,
  and one-based line ranges before any reviewer call.
- Read CODE content from immutable Git objects and include only mapped targets.
- Include a per-target prior excerpt and bounded diff when requested.
- Fail closed for missing, stale, malformed, broad, or escaping mappings.
- Preserve reviewer transport, retry, timeout, lock, and verdict behavior.

## Upstream Discovery
- `design/review-gate.md` is the project review authority and currently permits
  complete-file CODE and DOCUMENTATION packets.
- `tools/reviewer/review_gate.py` implements the packet builders and CLI.
- `tests/test_review_gate.py` is the reviewer regression authority.
- The external review gate is advisory; the local gate remains the authority.

## Disposition
`IMPLEMENT_NOW`: add a hash-bound requirement-linked packet path, document its
JSON contract, and add focused regression coverage. Do not modify frozen remote
or hosted harnesses.

## Zero-Gap Exit Scan
Confirm normal CODE and DOCUMENTATION CLI paths cannot transmit complete source
files as a substitute for mapped excerpts, while the independent bootstrap path
remains operational and explicitly documented.

## Exit Gates
- Static repository gates pass with no banned terms or missing headers.
- Remote reviewer regression suite passes.
- CODE and DOCUMENTATION reviews of this change pass using linked packets.
- No product matrix is required for this workflow-only change.
