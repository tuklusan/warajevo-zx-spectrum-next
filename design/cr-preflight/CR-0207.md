# CR-0207 Integrate AY Channels into the Canonical Mixer

Status: CLOSED

## Functional Inventory

- Read the three AY tone output levels and three AY noise output levels at a
  deterministic mixer boundary without advancing either generator from the
  mixer.
- Apply AY register R7 tone/noise enable semantics independently for channels
  A, B, and C: an enabled source contributes its oscillator level and a
  disabled source is logically high according to the AY mixer rule.
- Select each channel's fixed volume register level from R8, R9, and R10,
  including the envelope-enable bit and the current logical envelope level.
- Apply the frozen project-owned 16-level Q16.16 attenuation table with no
  host floating-point dependency.
- Sum the three mono AY channels into a signed 64-bit accumulator using the
  frozen equal-channel policy, then saturate to the signed 32-bit Q16.16
  sample range.
- Provide a core mixer API that can produce one deterministic AY sample from
  the current AY state and a canonical mixer API that combines AY with the
  beeper contribution without coupling to Sokol or host audio callbacks.
- Preserve deterministic behavior for muted, zero, and maximum levels and for
  repeated calls at the same state.
- Keep AY generator timing, PCM sample-rate accumulation, serialized state,
  and Sokol push delivery as explicit follow-on responsibilities.

## Upstream Completeness Gate

Rescan the preserved AY paths for the complete logical mix expression:
tone/noise oscillator outputs, R7 channel-enable inversion, R8-R10 volume and
envelope selection, three-channel summation, scaling, saturation, and the
timing boundary at which a sample is observed. Compare each rule with the new
API and tests. Record that the historical Sound Blaster/AdLib device-specific
conversion and host delivery are not copied into the deterministic core.

## Upstream Discovery

The preserved AY mixer computes each channel from the logical combination of
tone and noise outputs and the inverse R7 enable bits, masks each result by
the channel volume, sums A/B/C, and applies a final scale. The preserved exact
path also uses a deterministic oscillator sample boundary. The architecture
document replaces device-specific byte output with a host-independent signed
Q16.16 policy and retains the logical channel behavior.

## Disposition

- AY logical channel gating, envelope-volume selection, gain lookup, equal
  summation, and saturation: `IMPLEMENT_NOW`.
- Beeper plus AY canonical sample composition: `IMPLEMENT_NOW` where the
  existing beeper state API provides a deterministic level; no host output.
- 44,100 Hz sample-phase accumulation and cross-sample event integration:
  `DEFERRED_WITH_CR` to the canonical PCM task.
- AY state serialization/hash participation: `DEFERRED_WITH_CR` to Task 193.
- Sokol conversion, push buffering, and physical audio-device behavior:
  `DEFERRED_WITH_CR` to the host audio tasks.
- Non-base 128K variants: `CONTROLLED_SCOPE`.
