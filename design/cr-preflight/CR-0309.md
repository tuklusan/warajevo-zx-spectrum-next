## Change Request
CR-0309: Implement the compact toolbar Tape control

Status: CLOSED
Priority: medium

## Functional Inventory
- Expose the compact toolbar Tape control as a stable shared-command surface.
- Show mounted and unmounted state without duplicating machine/media state.
- Provide Insert, Eject, Normal, Instant / Trap, and Open Tape Manager actions.
- Route action activation through the canonical command registry.
- Preserve disabled-state reasons and avoid GUI-toolkit or host-dialog coupling.

## Upstream Discovery
UI Sections 11.1-11.4, 12, 20.1, 45, and 48 define the Tape toolbar control
and its menu. Task 304 is the derived backlog item. The existing layout exposes
a placeholder Tape toolbar entry, while the shared command registry and Tape
workflows provide the boundary needed for state and action routing. No upstream
behavior remains undispositioned for this toolbar task.

## Disposition
`IMPLEMENT_NOW`: extend the layout model with a compact Tape control action
surface whose entries retain canonical command IDs and whose state is supplied
by the owning application state.
