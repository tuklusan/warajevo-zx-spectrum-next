# CR-0346 Preflight: Enforce Internally Consistent Minimal Review Packets

Status: APPROVED_FOR_IMPLEMENTATION

## Scope

The review gate must transmit a minimal but sufficient and accurate packet.
Each review link must keep its requirement excerpt, related implementation or
document excerpt, optional prior excerpt, and bounded diff tied to the same
change intent and immutable source objects. Packet construction must reject
mechanically inconsistent evidence before transport, including stale hashes,
invalid ranges, path mismatches, and unbound or empty diffs.

Functional aspects covered: requirement purpose and acceptance wording; exact
related code/document selection; added, modified, and unchanged ranges; prior
content and diff correspondence; full-source versus excerpt identity; Git base
and head identity; JSON serialization; packet hashing; documentation review;
reviewer error recovery; and regression-test coverage.

## Authority And Upstream Scan

Authorities examined line-by-line:

- `design/review-gate.md`
- `WORKFLOW.md`
- `tools/reviewer/review_gate.py`
- `tests/test_review_gate.py`
- upstream reference repository review-map and immutable-evidence behavior

The scan covered `line_excerpt`, `bounded_git_diff`, `linked_packet`, review
manifest construction, request framing, schema validation, and review retry
ordering. No upstream behavior relevant to this packet-integrity scope remains
undispositioned.

## Dispositions

- Requirement and related excerpts: `IMPLEMENT_NOW` with explicit source and
  excerpt hashes.
- Prior excerpts and diffs: `IMPLEMENT_NOW` with base/head/range binding and
  diff hash.
- Existing transport JSON shape: `REIMPLEMENTED_DIFFERENTLY`; preserve the
  established string fields while adding unambiguous integrity metadata.
- Full-file packet fallback: `NOT_APPLICABLE`; the minimal linked packet is the
  required path.
- Provider, retry, timeout, lock, harness, wrapper, and product behavior:
  `NOT_APPLICABLE`; unchanged by this CR.

## Exit Evidence

The exit scan must show that the builder recomputes every emitted identity from
the selected files or Git objects, that tests cover the metadata and diff
binding, and that `design/review-gate.md` and `WORKFLOW.md` state the same
pre-transport hard gate. Remote unit-test evidence is required; no local build
or test is permitted.
