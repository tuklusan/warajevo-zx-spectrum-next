# CR-0186 SNA 128K Image Scaffolding

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Represent the complete eight 16 KiB RAM pages of a standard SNA 128K image.
- Preserve the 27-byte historical register header and the four-byte 128K
  extension containing PC, `7FFD`, and TR-DOS state.
- Parse and write the exact 131,103-byte uncompressed SNA 128K form.
- Validate the selected page, reserved `7FFD` bits, TR-DOS flag, complete page
  coverage, exact length, and output capacity before publication.
- Keep the image isolated from the current single-64 KiB live machine; live
  paging and machine integration remain Phase-9 work.

## Upstream Completeness Gate

Read the preserved upstream snapshot loader and writer around the 128K page
path, including the visible pages, selected page, remaining-page ordering,
extension fields, and hardware selection behavior. Compare each discovered
field with this preflight and record any behavior that is intentionally deferred
to the Phase-9 live paging CR rather than silently dropping it.

## Upstream Discovery

The upstream path treats the 128K image as the three visible pages (5, 2, and
the page selected by `7FFD`), followed by the PC/`7FFD`/TR-DOS extension and
the five pages not visible in that initial mapping. The preserved code also
contains hardware-specific loading and paging side effects; those are not
portable image representation and are explicitly deferred to Phase 9.

## Disposition

- Exact isolated image representation and round-trip writer: `IMPLEMENT_NOW`.
- Exact-length, page-selection, reserved-bit, and no-partial-publication
  validation: `IMPLEMENT_NOW`.
- Live 128K bank storage, paging register behavior, AY state, and machine
  snapshot commit: `DEFERRED_WITH_CR` to Phase 9.
- Unsupported or ambiguous page selections: `CONTROLLED_ERROR`.

## Zero-Gap Exit Scan

Before closure, rescan the frozen media matrix, this preflight, the complete
upstream SNA 128K load/save branches, the new image APIs, and their tests.
Every byte in the isolated form must have a destination or an explicit
controlled-error/deferred disposition. No live-machine behavior may be implied
by the scaffolding APIs.

## Closure Requirements

- Static repository gates pass; no local build or test is run.
- Exact-SHA CODE and DOCUMENTATION advisory reviews pass with zero confirmed
  findings.
- Linux, Windows 10, Windows 11, and the available Mac lane execute the remote
  smoke and regression suite; unavailable boxes are recorded as unavailable.
- Hosted validation and publication gates pass.
