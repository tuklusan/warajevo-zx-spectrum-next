# CR-0141 Preflight: Integrated Phase-5 Host Smoke Gate

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Run and record the integrated host smoke coverage required before the Phase-5
gate: raster, keyboard, Kempston, runtime speed, pacing, and deterministic
headless-state/hash behavior on Windows and a Unix-like host.

## Functional Inventory

- Compile the shared core and host-facing application modules with warnings enabled.
- Execute the complete deterministic test executable covering raster and keyboard behavior.
- Execute Kempston decode, core integration, host mapping, speed, and pacing contracts.
- Exercise canonical state serialization/hash equivalence independently of host pacing.
- Run the same smoke entry point on Linux and Windows 10 approved remotes.
- Run the hosted platform matrix across all configured available runner classes.
- Keep screenshot/presentation capture host-only and do not treat a headless hash as a GUI-pixel proof.

## Upstream Completeness Gate

Compare the integrated smoke inventory with the preserved upstream execution,
input, raster, and timing responsibilities. Confirm that every applicable
behavior has a deterministic test or an explicit host-only disposition before
the Phase-5 gate is closed.

## Upstream Discovery

The preserved upstream implementation separates machine execution from host
presentation and input dispatch. The existing project smoke entry point covers
the deterministic boundary; GUI screenshot equivalence remains a separate
host-presentation acceptance concern and is not silently inferred here.

## Disposition

Use the existing shared CMake smoke harness and hosted matrix without adding a
second test runner. Bind the run receipts to this CR and record any transport
or platform-specific limitation explicitly.

## Zero-Gap Exit Scan

Close only when Linux and Windows smoke receipts, hosted matrix receipts,
deterministic/hash coverage, input/raster/speed/pacing coverage, and the
presentation boundary disposition have no unresolved gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
