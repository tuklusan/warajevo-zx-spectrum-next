# CR-0127 Preflight: Presentation Effects Separation

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Keep CRT and analog shader effects disabled and ensure any future presentation
effects cannot alter canonical source raster contents.

## Functional Inventory

- Define the default effects state as disabled.
- Keep effect configuration outside deterministic core and raster upload.
- Preserve source raster hashes with effects disabled or absent.
- Provide an explicit separation point for later optional effects.

## Upstream Completeness Gate

Compare the architecture effects contract, current host presentation path,
canonical raster evidence APIs, and preserved upstream behavior. Record every
effect-related assumption before implementation.

## Upstream Discovery

CR-0123 through CR-0126 establish upload, backend, rectangle, and scaling
boundaries. This CR adds only the disabled-effects policy and separation.

## Disposition

Add a host presentation policy with effects disabled by default. Do not add
CRT shaders, analog simulation, or source-raster mutation.

## Zero-Gap Exit Scan

Close only when disabled behavior, policy ownership, and canonical raster
equivalence are explicit and evidenced.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
