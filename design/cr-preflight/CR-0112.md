# CR-0112 Preflight: Interrupt Edge Timing

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Run and strengthen interrupt-entry and edge timing smoke tests at critical
frame positions with canonical event evidence.

## Functional Inventory

- Cover maskable interrupt sampling and acceptance edges.
- Cover NMI entry and timing-sensitive boundary behavior.
- Capture deterministic CPU, bus, interrupt, and master-tick ordering.
- Require first-divergence evidence for every mismatch.
- Preserve headless deterministic-core boundaries.

## Upstream Completeness Gate

Rescan preserved reference interrupt traces and architecture timing tables before
adding cases. Assign every behavior outside this smoke set to a later task.

## Upstream Discovery

events; this CR binds their edge-timing acceptance evidence without host behavior.

## Disposition

replace timing evidence with software-recognition shortcuts.

## Zero-Gap Exit Scan

master ticks, and canonical trace evidence.
