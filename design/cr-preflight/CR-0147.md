# CR-0147 Preflight: Deterministic Beeper PCM Integration

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Integrate timestamped beeper transitions into the frozen canonical PCM timeline
using deterministic rational sample boundaries and fixed-point output.

## Functional Inventory

- Convert master-tick intervals to the frozen internal sample rate without floating point.
- Integrate high/low beeper duration over each sample interval, including edges inside an interval.
- Produce signed Q16.16 samples using the frozen mixer representation.
- Apply deterministic round-to-nearest, ties-away-from-zero and saturation rules.
- Preserve event order, same-tick behavior, and initial level semantics.
- Reject invalid rates, levels, buffers, and overflowing timelines deterministically.
- Keep host callbacks, device rates, and Sokol delivery outside the core.

## Upstream Completeness Gate

Inspect preserved upstream speaker transition and sound-sampling behavior. Compare
edge timing, level polarity, sample integration, clipping, and host output
responsibilities; retain canonical emulated timing while replacing host polling.

## Upstream Discovery

The preserved upstream path drives a host speaker from port-FE changes but does
not provide a portable canonical PCM timeline. The architecture requires
timestamp integration before host delivery, so this CR uses the frozen Q16.16
policy and 44,100 Hz rate.

## Disposition

Add a bounded deterministic beeper-to-PCM renderer using rational tick/sample
accumulation and fixed-point duration averaging. AY mixing and host audio remain
subsequent CRs.

## Zero-Gap Exit Scan

Close only when sample boundaries, edge integration, polarity, initial state,
rounding, saturation, invalid inputs, overflow, and host separation have no gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
