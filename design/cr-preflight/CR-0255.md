# CR-0255 Implement Bounded Debugger Memory Data Tools

Status: CLOSED

## Functional Inventory

- Provide bounded, caller-owned memory copy and search operations over the one
  live machine memory boundary.
- Provide bounded paused-state fill and byte/word write operations with atomic
  validation, ROM protection, address-wrap rejection, and traceability.
- Preserve the existing read-only and paused mutation access policy.
- Keep all operations deterministic and independent of host files, paths,
  sockets, wall-clock time, UI state, and private test media.

## Upstream Discovery

- Re-read the complete `COPYMEM`, `COPYLOOP*`, `FINDMEM`, `FIND*`, `KILLMEM`,
  `KILLLOOP`, `POKE`, `POKEWORD`, `WRTBYTES`, and related validation paths in
  `SPECMON.ASM`.
- Compare each source behavior with the CR-0254 coverage matrix and the
  existing `wz_debugger` APIs.
- Confirm bus/state ownership and ROM/page behavior against Architecture 1
  sections 41, 44, and 49.2 and UI Architecture 2 sections 21 and 45.

## Disposition

| Surface | Disposition | Reason |
|---|---|---|
| Bounded read/copy/search | IMPLEMENT_NOW | Required debugger data tools |
| Paused fill and byte/word writes | IMPLEMENT_NOW | Required controlled mutation |
| Host file import/export | DEFERRED_WITH_CR | Application boundary, not core tool |
| Unbounded or wrapping ranges | REJECT | Explicit safety and determinism rule |
| ROM writes and unpaused mutation | REJECT | Existing machine ownership policy |

## Zero-Gap Exit Scan

Before closure, every named upstream memory-data branch and error condition must
map to an API result and regression case. Repeat the CR-0254 matrix comparison
and record no remaining unclassified copy, search, fill, byte-write, or
word-write behavior within this scope.

## Required Evidence

- Updated Phase-11 coverage matrix with test names for every implemented case.
- Serial CODE, TEST_ARTIFACT, and DOCUMENTATION reviews for the exact commit.
- Remote lab and hosted matrix build/test evidence with inspected manifests.
- Private closure record retaining traces and visual evidence where supported.
