## Change Request
CR-0319: Complete compact MDV 1 toolbar control

Status: CLOSED
Priority: medium

## Functional Inventory
- Preserve the canonical compact `MDV 1` toolbar item and label.
- Dispatch the toolbar item through the shared Microdrive command registry.
- Keep the toolbar shortcut a presentation convenience, not a one-drive-only
  backend or alternate Microdrive state store.
- Preserve eight-slot Microdrive actions and mounted-state presentation.

## Upstream Discovery
UI §14 and §24 require eight Microdrive slots while explicitly defining the
toolbar as a compact `MDV 1` control. Developer task 314 requires that control
to use shared command semantics without creating a one-drive-only backend.
CR-0318 added the complete eight-slot action table and dispatch API. The
existing toolbar table contains `media.microdrive.drive1` but its activation
coverage is not yet proven in `tests/wz_ui_layout_tests.c`.

## Disposition
`IMPLEMENT_NOW`: extend the existing layout contract test to register the
canonical MDV 1 toolbar command and assert that toolbar activation reaches the
shared handler. No production layout or harness change is needed.

## Zero-Gap Exit Scan
Recheck UI §§14, 24, 47, and 48 plus the eight-slot controls from CR-0318.
Confirm the compact control remains exactly `media.microdrive.drive1` / `MDV 1`,
dispatches via the registry, and does not remove or duplicate any slot action.
