# CR-0068 Migration Preflight

Status: APPROVED_FOR_IMPLEMENTATION

## Functional Inventory

- Implement every DD/FD `LD r,IXH/IYH`, `LD r,IXL/IYL`, `LD IXH/IYH,r`,
  and `LD IXL/IYL,r` form in the `40` through `7F` transfer matrix where
  neither operand is indexed memory.
- Substitute the selected index register byte only; preserve flags, MEMPTR,
  all unrelated registers, and the ordinary two-M1 8 T-state DD/FD timing.
- Keep indexed-memory source forms such as `LD r,(IX/IY+d)` and indexed-memory
  destination forms such as `LD (IX/IY+d),r` out of this CR; they require
  signed-address bus cycles and remain a distinct migration slice.
- Retain prefix repetition and ignored-prefix behavior already implemented by
  the shared index-prefix dispatcher.

## Upstream Discovery

The DD table routes `40` through `7F` to `LDBXH`, `LDBXL`, `LDCXH`,
`LDCXL`, `LDDXH`, `LDDXL`, `LDEXH`, `LDEXL`, `LDXH*`, `LDXL*`, `LDAXH`,
and `LDAXL`; the FD table supplies the corresponding YH/YL routines. The
upstream transfer macros define no flag side effects for these register-only
forms. Entries containing `MIX` or `MIY` are indexed-memory routines and are
explicitly deferred.

## Disposition

| Functional aspect | Disposition | Evidence |
| --- | --- | --- |
| Register reads from IXH/IYH and IXL/IYL | IMPLEMENT_NOW | DD/FD transfer tables |
| Register writes to IXH/IYH and IXL/IYL | IMPLEMENT_NOW | LDXH/LDXL/LDYH/LDYL routines |
| Self-transfer and cross-byte transfer semantics | IMPLEMENT_NOW | upstream transfer macro matrix |
| Indexed-memory transfer forms | FOLLOW_ON_CR | MIX/MIY table entries |
| Indexed ALU forms | FOLLOW_ON_CR | DD/FD ALU table entries |

## Zero-Gap Exit Scan

Re-scan all DD/FD `40` through `7F` entries, their byte-transfer helper
routines, and adjacent indexed-memory entries. Close only when every
register-only substitution is remotely validated and every excluded behavior
has an explicit follow-on disposition.
