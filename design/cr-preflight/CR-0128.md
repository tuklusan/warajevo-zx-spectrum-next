# CR-0128 Preflight: Host Input Arbiter

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Implement independent host input-source ownership slots and a normalized
boundary that prevents host key codes from entering the deterministic core.

## Functional Inventory

- Define source identity and independent ownership slots.
- Normalize host events into core-neutral input actions.
- Preserve simultaneous ownership across input sources.
- Define release and focus-loss behavior for later tasks.

## Upstream Completeness Gate

Compare the architecture input contract, existing machine keyboard APIs,
preserved upstream behavior, and later keyboard/Kempston tasks. Record every
source, ownership, normalization, and release assumption.

## Upstream Discovery

The core exposes normalized keyboard state operations; no host key codes or UI
types belong in core headers. This CR establishes only the arbiter boundary.

## Disposition

Add a host-only input arbiter API and deterministic ownership state. Do not
implement the complete keyboard matrix, Kempston mapping, or pacing here.

## Zero-Gap Exit Scan

Close only when source isolation, ownership, normalization, release behavior,
and core boundary are evidenced on remote and hosted paths.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
