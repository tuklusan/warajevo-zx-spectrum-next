# CR-0131 Preflight: Deterministic Input Focus Loss

Status: APPROVED_FOR_IMPLEMENTATION

## Objective

Define and implement deterministic focus-loss handling for the host input
arbiter, preventing stuck local keys while preserving independently owned
Telnet, script, and other source input.

## Functional Inventory

- Identify the local focus-loss transition at the host boundary.
- Release every key owned by the local source exactly once.
- Preserve ownership and key-down state from all independent sources.
- Make repeated focus-loss notifications idempotent.
- Define focus regain behavior without synthesizing key presses.
- Keep window/UI focus objects outside the deterministic core.
- Provide tests for held keys, mixed sources, repeated loss, and regain.

## Upstream Completeness Gate

Inspect preserved upstream focus/input lifecycle, key-release behavior, event
loop transitions, and any safeguards against stuck keys. Compare every finding
with the architecture and current source-ownership arbiter; record behavior
that is retained, intentionally reimplemented, or explicitly out of scope.

## Upstream Discovery

CR-0128 established independent source slots and a source-release operation.
Focus loss must call the local-source release path only; it must not clear
Telnet or script ownership and must not place UI focus state in core state.

## Disposition

Add a host-boundary focus-loss operation using the existing arbiter. Do not
implement GUI toolkit event translation, keyboard ghosting, timestamps, or
Kempston behavior in this CR.

## Zero-Gap Exit Scan

Close only when local release, source isolation, idempotence, regain behavior,
and no-core-UI dependency are evidenced by tests and the upstream comparison
finds no unresolved gap.

## Verification Plan

- Local activity: static gates and source inspection only; no local build/test.
- CODE and DOCUMENTATION advisory reviews against this preflight.
- Remote Linux and Windows smoke validation.
- Hosted platform matrix validation.
- Final upstream zero-gap scan and publication evidence.
