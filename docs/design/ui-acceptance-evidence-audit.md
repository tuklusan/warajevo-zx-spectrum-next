# UI acceptance evidence audit

Task 451 and Task 359 evaluations are complete; UI acceptance is not. Current status: 35 PASS, 28 PARTIAL, 1 OPEN, and 3 OUT OF SCOPE. PASS requires direct evidence for the full criterion; PARTIAL records narrower evidence; OPEN means required in-scope evidence is missing; OUT OF SCOPE identifies the three Ear+Mic implementation criteria excluded from Architectures 1 and 2. The four-runner DIZZY4K proof exercised the GUI application through its Telnet surface and captured a Spectrum screenshot (run 35890238325). The latest nine-case application-command boundary proof covers stable-ID uniqueness and label independence, shared GUI menu, toolbar, test, and Telnet dispatch, host-only state preservation, and registry ownership; run `39381322146` at commit `4eff3f0` adds Section 35 record and Recent-path privacy coverage. The live model-switch proof adds reset connection preservation and idempotent pause/resume evidence; GUI interaction equivalence remains open (run `36409807983`, source `6a3fa6c`). The latest four-runner discovery regression covers registry discovery, argument validation, all denied permission classes, and path-free status output (run `36409807952`). The protocol suite covers the 1024-byte line boundary, overflow recovery, negotiation, and response framing on four runners (run `36395933999`); exact-source production Telnet DO parsing passed the five-target 14-assertion contract in run `39611425782` ([telnet-do-parser.json](../../test-results/telnet-do-parser.json)). Canonical screenshot state/time is now directly verified by the five-target 20-assertion-per-runner contract in run `39632784395` ([screenshot-state-time.json](../../test-results/screenshot-state-time.json)); broader socket integration and remaining Section 47 acceptance checks remain open. Screenshot exact-name and forced-collision/no-overwrite behavior passed on Ubuntu in run `36493878315` (proof: [screenshot-path-contract.json](../../test-results/screenshot-path-contract.json)). The hosted UI networking-mode contract passed all 16 assertions in run `36596854806`; criteria 60 and 65 pass from hosted Networking radio-group, registry, remote-permission, dispatch, and dirty-media proofs. Control Port state contract `36598938370` verifies unavailable-state projection and that preference serialization excludes the session port; criterion 59 passes and criterion 57 passes with available and unavailable UI projection plus exhaustion evidence. The contract does not close the Architecture #3 Ear+Mic behavior criteria. `Open / Run...` is implemented with native file dialogs, media routing, and controlled unsupported-format handling; hosted GUI run `38335968352` at `a37d760` directly opened the production chooser, selected a checksummed TAP, and showed Tape Stopped/loaded on macOS Intel and ARM64. The proof and screenshots are pinned under [open-run-ui](../../test-results/open-run-ui/); Current-source run `39377276900` passed production chooser selection on all four desktop runners; proofs and screenshots are pinned under [open-run-ui](../../test-results/open-run-ui/). The Windows ARM64 image contains a WSL update overlay, so its visible loaded state is unverified; criterion 11 stays PARTIAL pending broader supported-format acceptance. Task 359 reviewed all 67 criteria against the Phase-12 milestone: the P12-relevant PASS/PARTIAL/OPEN evidence is recorded row by row; transport-dependent Telnet criteria (7–10, 27–40, 43, 51, 53–54, 57–59, and 65, plus the Telnet portion of 64) are deferred to Phase 15, and Architecture-#3-specific criteria 62, 66, and 67 are excluded from the Architectures 1 and 2 acceptance count, as required by the project scope. The applicable P12 list still has open UI-runtime gaps, including Windows native Open/Run interaction and end-to-end Debugger integration.
