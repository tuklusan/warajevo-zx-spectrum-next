# Core/System acceptance evidence audit

Task 450 audit is complete; architecture acceptance is not. `PASS` means the cited evidence directly covers the full criterion; `PARTIAL` records narrower evidence; `OPEN` means no adequate tracked proof was found. Source inspection and general builds do not count as behavioral proof. On source commit `e891fec`, all 1,356 cases in the pinned Fuse Z80 suite passed on hosted run `35918957994`; the proof is tracked in `test-results/fuse-z80-conformance.json`. The test-ledger gate passed with that proof on commit `2782319` (run `35919046699`), and the pathname check passed (run `35919046665`). The ledger also contains `canonical-core-regression`; neither suite establishes every behavioral criterion below. The tape-loading comparison closes criteria 36 and 37 on the existing normal-fallback path; no accelerated trap path is claimed. Remaining OPEN criteria are unresolved proof or implementation gaps, not implied passes.

Four-runner baseline and determinism evidence: run `35894280373`. Four-runner clean Release build evidence: run `35894280436`. Four-runner GUI/Telnet DIZZY4K smoke evidence: run `35890238325`. Latest headless canonical core proof: run `35955514192`, pinned at `test-results/canonical-core-regression.json` for source commit `0aa7958`; all eight compiler/platform variants passed on run `35955514187`.
