# UI menu registry inventory

The hosted Release/Sokol production-host check parses the canonical Section
7.1 ID inventory, compares it with live `MENU TREE` and `DESCRIBE` responses,
and validates the frozen record fields for all registered actions. It retains
no dynamic Recent-file paths and terminates the application after inspection.
